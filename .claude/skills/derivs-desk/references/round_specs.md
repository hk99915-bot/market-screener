## 1. 선물 프록시 '오래됨' 판정 규격 (10/23 §0-1 → req-dev-228cac19)
- 원인 분류 먼저: 장중 로그 `FUT(ts=…)` age 분포로 ① 일정 >1h = ts 미갱신 ② ~1,200s = 지연 시세 원천 ③ 180~300s 산포 = 임계 조정. 100% 보류는 구조적 원인 [현업 관행].
- 임계 FUT max_age 120s 권장·상한 300s. 임계를 올려 보류를 없애는 수정 금지(사이드카 효력 5분) [규정+현업 관행].
- 판정창: 사이드카 09:05~14:50, 15:35 뒤·최종거래일 15:20 뒤 ts 정지는 '거래 종료'(경고 아님). 정규장 시각 `[확인 필요: KRX 원문]`.
- 야간: 네이버 `FUT` 는 주간물만 — 야간 값이 주간 키로 섞이면 안 됨(`screener/derivs.py` 주석).
- 롤오버: 선물은 분기물(3·6·9·12월 둘째 목요일). 롤 다음 거래일 첫 회차 = 월물 이름 교체 확인 + |FUT chg − KPI200 chg| ≤ 1.5%p, 실패 시 '롤 불일치' 보류. 월물 옵션 만기는 선물 롤 아님.
- 테스트 픽스처 = `reports/logs/probe.json` `fut_index` 실응답(필드명 그대로).

## 3. 이벤트 구간 뷰 원칙 (10/26 event_derivs)
- 파생 지표는 방향이 아니라 흔들림 크기·위치만. 옵션 계열 전부 검증전, IV→|r1| 크기만 C(10/30 감마 C 추가).
- 이벤트별 '내재 변동폭 vs 과거 실현/내재 1σ 중앙값' 표로 비교(10/26: FOMC 0.44·만기 0.23 vs 평소 0.73, n 16·24·279) → 진폭은 이벤트가 아니라 레짐. 하루짜리 이벤트 옵션 매수보다 구간(만기 넉넉한 월물) 헤지.
- 헤지 설계 비교표 칸: 안 | 장부(실계좌/모의) | 비용(명목 대비) | 손익비·손익분기 | 장단점. 옵션은 정의된 위험(1R = 순지불)으로.
- 트래킹 트리거 표(지표 | 트리거 | 행동) + 무효화 조건을 같이 적는다. 실계좌는 레버리지·인버스·파생 금지 규칙 안의 수단만.
- '말할 수 있는 것 / 말할 수 없는 것'을 분리 — 기관 세부·장중 투자자별 선물·개별종목 선물 투자자별은 무료 경로 없음(`research_realtime_deriv.md`).

## 4. 헤지 입력 양식 (10/28 derivs_hedge_input → CIO)
- 머리: `기준 YYYY-MM-DD HH:MM KST · 비율만` + 출처 파일 + `[가정: IV 기간구조 등]`.
- What: 수단 실측(β·일 괴리 σ·20일 경로 괴리 분위·총보수) + 끌림 공식 −σ²T 값. 표: 수단 | 장부 | 비용 | 덮는 기간 | 효과.
- So What: 이벤트 창 1σ, 실현/내재 비, 반대 근거 1개(예: 실측 표본이 추세장 위주라 비용 과소 추정).
- Now What: 결정권자(CIO·겸이) 명시, 시간대 규칙(22~07시 규칙 변경 없음), 뒤집힐 조건(rep_iv·괴리·IV 재산정).

## 5. 장중 회차 양식 (10/29·10/30 derivs_intraday)
- 제목 줄: `# 파생 장중(<날짜> HH:MM KST) · 방향 신호 아님(전부 검증전) · 출처 <파일 시각>`.
- **What** [확인]: 지수·K200F·베이시스(이론 대비)·PCR·ATM IV·1σ 대비 오늘 등락(σ 배수)·미수집 항목은 '없음/미확인'.
- **So What** [추정·검증전]: 성격 가설 + 판정 불가 사유. **Now What**: 확정치 갱신 뒤 검정 3갈래(헤지 성격/현물 주도/혼합) · 사전 판정 기준선.
- 반대 근거 (a)~(d), 실계좌 헤지는 사실만(매매 지시 아님), 한계 줄.
- 피드 불일치 처리: 같은 시각 두 원천(live.json vs derivs.json) 베이시스가 상식 범위 밖으로 갈리면 그날 값 인용 금지·관련 요청 닫지 않음(10/29).

## 6. 공식 IV(iptVlty) 실측화·기관 패널 설계 (10/28, 사전등록 — 검증전)
- 공식 IV 는 입력 데이터 교체이지 신호 아님. 입력 sanity: 행 수 ≥ 기준일 대비 80% · iptVlty 단위 자동 판별 · 범위 5~200% · 행사가가 현물 ±30% 덮는지 · 만기별 콜/풋 쌍 수, 실패 시 `record_stale` + 기존 경로 유지.
- 교체 기준: 20영업일 공식 ATM IV vs `atm_iv` 절대차 중앙 ≤ 2%p → IV 우선순위 공식(T+1) > 네이버 역산 > RV20.
- 기관 현물 매수 분류 H(헤지/차익)·D(방향성)·I(보험)·S(숏커버 꼬리표)·U(불명), 검정 t+5 초과수익 D − H, 클래스별 ≥ 30·IS/OOS 같은 부호·본페로니 0.0167. 주식선물·옵션 투자자별 미결제 없음 → 주체가 아니라 OI·가격 패턴 추론뿐.

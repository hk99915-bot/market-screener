# 현업 관행·흔한 오해·우리 연구와의 차이

(원본: docs/desk_kb/behavior.md 해당 절을 그대로 옮김 — 2026-10-31 스킬 시범. 번호 `kb:behavior#<n>` 동일. 내용 수정은 양쪽 같이.)

## 현업 vs 교과서 (#14–16)
14. [현업 관행] 프롭·운용 데스크: 일일 손실 한도 도달 → 당일 매매 종료, 큰 수익일도 사이즈 증액 금지(근거: 리스크 한도는 매니저 판단이 아니라 기계적 집행으로 설계). 교과서(하우스머니·틸트)의 처방을 '시간 제한 + 사이즈 고정'으로 구현한 것.
15. [현업 관행] 규칙 개정은 정기 안건으로만, 한도 초과 상태에서 한도 상향 금지(근거: 리스크위원회 운영 관행). 교과서의 '자기통제 문제'를 절차로 막는 방식.
16. [현업 관행] 주문표 없는 주문 금지: 진입가·수량·손절가·목표·근거 한 줄. 없으면 '감'으로 분류(근거: 약정 장치의 '구체성' 조건 구현).

## 흔한 오해 (#17–22)
17. [교과서] "손절은 손실 확정이라 나쁘다": 손실은 가격이 빠진 순간 이미 났다. 손절은 손실을 만드는 게 아니라 다음 손실의 상한을 정한다(#10). (출처: Kahneman TFS 32장 매몰비용)
18. [교과서] "평단 낮추기 = 분할매수": 분할매수는 사기 전에 회차·가격·총량을 적은 것. 빠진 뒤 추가 매수는 같은 베팅을 더 크게 하는 것이고 평단은 보기 좋아진 숫자 하나뿐. (출처: consult:behavior#q8)
19. [교과서] "규칙은 상황 따라 유연해야": 유연성은 절차(시점·근거·냉각기간)로 규칙 안에 넣는다. 장중·자정에 생기는 유연성은 항상 '지금 하고 싶은 쪽'으로만 유연하다. (출처: consult:behavior#q6)
20. [교과서] "편향을 알면 피할 수 있다": 지식 → 과신 → 장치 제거 → 재량 매매 → 회전율↑ → 수익↓. 지식은 장치를 믿게 하는 용도. (출처: Barber & Odean 2000; consult:behavior#q12)
21. [경험] '규칙을 바꿔 위반을 없애기' 함정의 징후 6가지(개념만): 손절선 근처에서 손절 완화 요구 / 한도 초과 상태에서 한도 상향 / 방금 정한 상한을 곧바로 올리자 / 비율의 분모 정의를 바꿔 위험이 작아 보이게 / "이번 주만 관망" / "이벤트만 보고"(기한 연장). 공통: 위반 임박·진행 중 + 방향이 현재 포지션에 유리. 정당한 변경의 기준 3 = 시점(위반 전·정기 리뷰)·근거(사전등록 검증)·냉각기간. (출처: consult:behavior#q6; rule_audit 사전등록 절)
22. [경험] 밤 재협상 패턴: 자정 이후 같은 결정을 다른 각도로 반복해 되묻기(한 사례에서 5회). 매도 직전 강세 근거 수집, 매도 직후 다른 자산으로 '채우려는' 충동, 같은 테마 재매수 충동. 대응: 15:00 결정 창·22:00 이후 결정 금지·매도/보상 직후 30분 신규 베팅 금지. (출처: 자체 관찰 2026-10-15~16, 비율·순서만)

## 우리 연구와의 차이 (#27–30)
27. [자체연구-F] 손절 폭(rule_audit T1): −5/−8/−12/2×ATR/없음 모두 F(Bonferroni α 0.0028, 6,654거래). 교과서는 '손절 = 손실 계정 강제 닫기'로 가치를 설명하지만 **폭의 통계적 우열은 없음**. '없음'은 보유일 10.9 → 14.8일, 연쇄 MDD 같음 → 손절의 가치는 (a) 결정 시점을 매수일로 이동 (b) 최대 손실 상한 (c) 재협상 차단, 즉 행동 장치. 따름: 현행 −8% 유지(근거 없음, 변경 근거도 없음). (출처: `reports/studies/rule_audit.md`)
28. [자체연구-C] 반등일 매도 대기(rule_audit T4): 코스피 20일선 이탈 뒤 전일 +0.5% 첫날 매도가 즉시 매도보다 매도가 +0.45%p(p 0.013, 69%가 더 비싸게), 대기 평균 2.9일. 교과서(작위/부작위)는 '대기'를 부작위 편향으로 의심하지만 데이터는 약하게 대기 편. 단 C — 규칙으로 유지하되 재량 '늦게 팔기' 금지. (출처: 같은 문서)
29. [자체연구-C] 추격 매수 금지(rule_audit T6): RSI14>70·전일 +5% 종목 금지가 절반 사이징보다 +0.13%p/20일(C), 추격 종목 20일 역행 −12.8% vs 비추격 −9.1%. 교과서의 '부작위 후회 → 추격'을 데이터가 약하게 뒷받침. (출처: 같은 문서)
30. [경험] Barber & Odean 2000: 과신 → 과다거래(최다 거래 집단 연 11.4% vs 시장 17.9%). 익명화 사례(1년 −58% vs 코스피 +43%)의 손실 구조는 과다거래보다 레버리지 ETF·당일 매매 승률 16%·보유 비대칭 → 개인 진단은 집단 평균이 아니라 자기 기록(#11)으로.

## 알파북 규칙 (screener/alphabook.py, 상태 reports/alphabook.json)
- 진입 = tradeplan plan + 통과 소스 + 소스 OOS E[R] > 기준선. 결정 다음 봉 시가, 구간 밖 미진입 만료.
- **추격 제외(10/23 겸이 "알파북 진입 조건도 누나 판단하에 고도화")**: B1 신호여도 마지막 봉이 S4(거래량 ≥ 20일 평균×3 + 종가 = 20일 최고 종가)면 제외 — #8 S4 학습·검증 두 구간 t −7.4/−6.2(F, 반대 방향) 근거. `alphabook.chase_s4`, 탈락 사유는 rejected 에 남김.
- **체결가 재조정(10/23 req-hf-ea105107, 검증 v1 경고 KT&G 0.218% vs 0.187%)**: 시가 체결 때 비중 = min(주문 비중, 주문 리스크 ÷ (체결가−스탑)/체결가) — 축소만, 상향 없음(주문 때 남은 총노출 기준). 실현 리스크 ≤ 주문 리스크가 원칙, 검증의 1.1배는 비용·반올림 허용폭으로만 남긴다. [교과서] 고정 분수 사이징은 '체결가−스탑' 기준(Tharp, *Trade Your Way to Financial Freedom*, 2nd ed., 2006, 포지션 사이징 장).
- **진입 근거 문장(10/24 겸이 "이 코멘트도 정리 좀, 왜 진입하는지로" · "펀더 내러 센티 다 드러나게", screener/entry_why.py)**: 제안 말투 줄의 캐치프레이즈를 근거 문장으로 교체 — 기술(B1 종가/250일 고가 %·사전등록 등급·S4 추격 아님·퀀트 hi52 등급과 '종목 중앙값 음수 → 분산 전제' 한계, reports/studies/2026-10-24_trend_events.json) · 값(소스 OOS E[R] vs 기준선·손절 %·1차 R·크기 = 리스크 %·뒤집힘 = 종가 < 250일 고점 95% → B1 해제) · 세 축 펀더(detail valuation·financials)·내러(DART 7일·research.json 30일 톤·trend_discovery 업종 쏠림)·센티(detail flows 5일·accum.json) 각 +/중립/−/미확인 + 숫자 1개 + 출처 키. 재료 없으면 '미확인'(지어내기 금지), − 2개 이상이면 '근거 약함' 표시만(진입·크기 규칙 불변). 축 판정 문턱(±10%·lift 1.5 등)은 표시용 [가정]. 텔레그램 = 머리 + 4줄(각 ~80자), 운용회의 hf_block lines = 4줄 형식 뒤에 펼침. 롤백 = 커밋 revert(tests/test_alphabook.py test_entry_why_*).
- 넣지 않은 것(근거 부족): 저베타 순위(5차 재검 Q1A B1 안 저변동−고변동 OOS t 0.12 F · Q1L 저변동 롱 단독 t −0.03 F — 알파는 고변동 숏 다리, 롱 전용 알파북엔 안 맞음) · 수급 필터(S1·S2 F) · 실적 D-2 보류는 tradeplan.macro_filter 에 이미 있음.
- 크기 = 0.5% × 컨빅션 × 시장 배수(tradeplan.macro_filter, 바닥 0.25) ÷ 손절폭, 상한 15%·총노출 = 시장 배수 × 100%. 이벤트 당일만 신규 0.
- 스탑 닿으면 다음 봉 시가 청산(예외 없음) · 1차 50% + 본전 스탑 · 2차 · 20거래일 시간 손절 · 비용 왕복 KR 0.45%·US 0.20%(tradeplan 비용 + 미끄러짐).
- 성적 = 벤치(069500·SPY) 대비 일별 초과·누적·IR(20일 이상부터). 주간 채점 = 검증 데스크(독립).

## 재량 북 (10/21 20시 겸이 "교과서 말고 실무, 그때그때 시그널 보고 롱·숏·선물·풋 사야지 결정")
- 역할 구분(10/21 20시 겸이 지정): **알파북 = 겸이 따라 할 수 있는 체계 북**(검증 통과 소스만, 규칙대로) · **재량 북 = HF 자율매매**(HF 판단, 겸이 따라 하라는 신호 아님). 둘 다 가상·모의 — '자율'은 HF 가 결정한다는 뜻이지 실계좌 주문이 아님.
- 체계 북(알파북, 통과 소스만)과 **별도의 재량 북** — 회의 때마다 시그널(committee.json derivs·positioning·premortem·hedges, macro_view.json, live.json) 보고 HF 가 직접 결정: 종목 롱/숏 · 코스피200 선물 롱/숏 · 풋/콜 **매수**. 장부 reports/hf_discretion.json, 도구 `scripts/hf_book.py add|mark|show`.
- 가상 AUM 1,000억원(10/21 겸이 지정, 계약·주 수 표기용 — 실제 돈 아님, 계산은 비중·R 그대로). 코스피200 승수 25만원/pt.
- **미장 재량(10/21 20시 겸이 지정):** 미장 종목 롱/숏(us_stock) · S&P500 선물 ES · 나스닥 선물 NQ(나스닥 종합 근사) · S&P500 풋/콜 **매수**(BS, σ = VIX). 개별주 옵션은 IV 데이터 확보 전 안 씀. 회의 개입 = 평일 09:15 ET(미 개장 15분 전, 서머타임 22:15 / 해제 후 23:15 KST). 한도는 국장과 합산.
- **장중 매매(10/22 15시 겸이 "장초 09:00부터 쭉 매매해")**: 장중 회차 평일 09:05~15:05 매시(+11:55·15:55·미장 09:15 ET). 장중가 = reports/live.json(K200F)·reports/heatmap_KR.json(국장 종목) — 약 5~10분 간격, 1분봉 아님(이 컨테이너에서 실시간 시세 API 차단). hf_book 이 오늘 장중값이 있으면 자동 사용. 기록 docs/desk_kb/rounds/<날짜>-hf-intraday.md.
- **가동 원칙(10/22 15시 겸이 "기관이면 장 안 좋다고 쉬면 안 돼, 숏이든 뭐든 돈 버는 게 역할")**: 열린 리스크 한도 1.0% → **2.0%**, **가동률 하한 50%**(미만이면 그 회의에서 롱·숏 양쪽 아이디어로 E[R] > 0 포지션을 채우거나 '없음 이유' 기록 — show 가 경고). 아이디어에 '수급 이탈 숏'(국장 대형, 외국인·기관 5일 동반 매도 + 20일 −10% + 50일선 아래, 종목선물·대차 가능만, 검증전) 추가. 확인을 다 기다리지 않고 분할 진입(작게 먼저 → 확인마다 추가). 북 손실 한도·E[R] 게이트·추격 금지는 그대로.
- 한도(FRM 거부권 유지, 10/22 07시 실무화 — 겸이 10/21 밤 "실무급, 헤지펀드 운용 10년차"): 크기 = 컨빅션 리스크(low 0.15% · mid 0.25% · high 0.40%, 승률 근거 '주관'이면 low) × 변동성 조정(일 변동성 2% 기준 0.5~1배) · 종목 명목 ≤ 20일 평균 거래대금 10% · 열린 리스크 합 1.0%(국장·미장 합산, 헤지 다리 `--hedge-of` 는 순 0, 헤지 명목 ≤ 부모 베타가중 × 1.5) · 동시 8건 · 단일 15%. **옵션 매도 금지**(#6 V1). 옵션 가격 = BS 근사(표기 필수).
- **진입 체크리스트 10칸 필수**(빈 칸이면 도구 거부): 재무·추정치 / 뉴스·촉매 / 거래량·수급·공매도·옵션 내재 / 매크로 관계 / 시나리오 손익(최악 포함) / 헤지(또는 '없음+이유') / 논지 붕괴 조건(가격 손절과 별개) / 다음 촉매 날짜 / 주관 승률 / 승률 근거. 도구가 R:R(1차 목표)·손익분기 승률 1/(1+R:R)·E[R] = p×RR − (1−p) 계산, **E[R] ≤ 0 거부**. 청산 때 Brier 점수로 승률 보정 추적.
- **옵션 매수 '사전 손절' 해석(10/23 req-hf-ea105107)**: 프리미엄 = 최대손실 = 1R 로 인정. 조건 ① 크기를 프리미엄 기준으로 잡아 프리미엄 합 ≤ 컨빅션 리스크(hf_book 이 이미 weight = risk) ② 진입 때 시간 청산일(만기 전 처분일)을 적는다 — 세타 손실을 손절 없이 끌고 가지 않기 위해. 프리미엄 −50% 같은 가격 손절을 두더라도 채점 R 단위는 전액 프리미엄. ②는 규칙 변경이라 10/23 22시 이후 제안만 — 반영 전 회차는 '정의된 위험'으로 유효, 시간 청산 미기재는 경고. [교과서] Hull, *Options, Futures, and Other Derivatives*, 10th ed., 2018 — 매수 옵션 손실 상한 = 프리미엄, 세타.

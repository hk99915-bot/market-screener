## 2. 재설계 원칙 — 연구 파이프라인 한 줄

아이디어 → 백테스트 → 독립 검증 → 모의 추적 → 실계좌 후보(해금 시). 관문은 퀀트 KB 규약을 그대로 옮겼다:

| 단계 | 다음 단계로 가는 관문 | 근거 |
|---|---|---|
| 아이디어 | §0 사전등록 커밋(가설·데이터·m·α·등급 규칙을 결과 전에 고정) + 주제의 현재 시도 N | kb:quant#1·#30 |
| 백테스트 | 등급 B 이상(Bonferroni 통과) · 서술 연구는 결론 5줄·뒤집힐 조건 · C 는 경보까지만 | kb:quant#4·#12·#25 |
| 독립 검증 | 검증 데스크 재현 일치(원 코드 미열람) — 재현은 숫자 확인이지 등급 상향 아님 | kb:verify#2·#7 |
| 모의 추적 | 표본 외 ≥60거래일, IS·OOS·하락장 부호 일치 → 오너 결재 | kb:quant#8·#14 |
| 실계좌 후보 | 해금 + 오너 결정. 레버리지·인버스·공매도 2027-04-15까지 금지(불변) | STANDARD §5 |

판정 4개: 통과 · 진행 · 보류(C·검증전·표본 대기 — 경보·참고로만) · 폐기(F = 효과 0, '반대로 하라'가 아님 — kb:quant#19). 폐기 카드는 접어 둔다(지우지 않음 — 시도 N 이 늘어난 기록이라서, kb:quant#13).

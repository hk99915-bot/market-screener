## §0 사전등록 (결과 보기 전 고정 — 이 절은 결과 커밋보다 먼저 커밋한다)

**질문.** 아래 후보 소스로 고른 진입이, 같은 trade plan 청산 규칙에서 같은 기간·같은 시장의 '무조건 표본(기준선)'보다 OOS 기대값(R)이 높은가.

**공통 엔진(= tradeplan 보정과 동일, scripts/study_tradeplan.py 함수 재사용).** 신호일 종가 C → 다음날 시가 진입(구간 C±0.5ATR14 밖이면 미진입), 스탑 = 구조적 max(20일 저점, C−2ATR) 최소 1ATR, 손절폭 > 15% 제외, 1차 1.5R 에서 50% 익절 → 본전 스탑, 2차 3.0R, 시간 손절 20거래일, 같은 날 손절 우선, 갭 시가 체결. 비용 왕복 KR 0.25%·US 0.10%(R 단위 차감). 유동성: KR 20일 평균 거래대금 ≥ 10억·가격 ≥ 1,000원 / US ≥ $2천만·≥ $5. SE = 신호일 군집 강건.

**가설 (검정 가능 m = 6, 단측 α = 0.05, Bonferroni α/m = 0.0083 → z ≥ 2.39).** 지표 = OOS 초과 E[R] = E[R]_신호 − E[R]_기준선, t = 초과 ÷ √(SE_신호² + SE_기준선²) (신호 ⊂ 기준선이라 보수적).
- A1 **KR 산업 내 상대강도**: 표본일(10거래일 격자)에 같은 업종(universe/kr_sector.csv, 유동 종목 ≥ 5) 안 60일 수익률 백분위 ≥ 0.8. 데이터 data/hist kr 2010~2025, 학습 ~2019 / 검증 2020~. 기준선 = 같은 격자 무조건 표본.
- A2 **US 산업 내 상대강도**: 같은 정의, 업종 = universe/us_sector.csv `sector`(11개; gics_sub 는 246종목에서 칸이 작아 안 씀). 데이터 data/hist us 2010~2025, 분할 2020.
- B1 **KR 52주 신고가 근접**: C / 250일 고가 ≥ 0.95 (George & Hwang 2004 *JF* 59(5)). 분할 2020.
- B2 **US 52주 신고가 근접**: 같은 정의. 분할 2020.
- C1 **KR 외국인+기관 수급 지속**: 최근 20거래일 중 (외국인+기관) 순매수일 ≥ 14 이고 20일 순매수 합 ÷ 시총이 그날 유동 종목 중 상위 20%. 데이터 data/flows/kr_inv_2024~2026(2024-11-26~), 가격 data/hist kr 2024~2025 + data/kr_prices.parquet 2026, 5거래일 격자. 학습 ~2025-08 / 검증 2025-09~. 기준선 = 같은 격자·같은 유니버스 무조건 표본.
- D1 **KR 애널 목표가 상향**: data/research.parquet 에서 같은 증권사·같은 종목의 직전 리포트 대비 목표가 > 직전(+0% 초과) 인 리포트 날짜 = 신호일(같은 종목 5거래일 안 중복은 첫 건). 2024-10-30~, 학습 ~2025-09 / 검증 2025-10~. 기준선 = 같은 기간 KR 무조건 표본(5거래일 격자).

**검정 불가(m 밖, 등록만).**
- D2 US 이익 추정 상향(reports/us_eps.json `chg30`): 스냅숏만 있고 git 이력 4판(2026-10-15~) → 20일 선행 결과 없음 = **데이터 없음(검증전)**. 이력 적재 요청 → 데이터 데스크.
- E 이벤트 드리븐(reports/studies/2026-10-21_event_driven.md): §0 만 있고 결과 json 없음 → 접점 보류, 결과 나오면 H8·H13 통과 시 알파북 후보 소스로 같은 규칙 재검.

**등급·통과 규칙.** 통과(B) = OOS 초과 > 0 · t ≥ 2.39(Bonferroni) · 학습 초과 > 0(같은 부호) · OOS 절대 E[R] > 0. C(방향만) = OOS 초과 > 0 · t ≥ 1.645 — 알파북 진입 후보 아님. F = 그 외. 검증전 = OOS 신호일 < 30. **알파북 진입 후보 = 통과(B)만.** 통과 0 → 알파북 현금 + '탐색 중'(억지 진입 금지).
- 등급 상한: A1·A2 = 업종 분류가 현재 시점(사후 분류) · US = 2026 구성 종목(생존편향) → B 상한. C1·D1 = 2년 미만 표본 → B 상한.

**알려진 한계(결과 전 기록).** 10거래일 격자에 20일 보유 → 인접 표본 창 겹침(SE 과소 가능, kb:quant#10) — 같은 엔진의 기준선도 같은 편향이라 '초과'엔 일부 상쇄. 1.5/3.0 칸 하나만 본다(격자 탐색 없음, 보정 json 의 추천 칸).

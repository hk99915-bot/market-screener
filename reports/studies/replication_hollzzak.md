### 0.2 명세 해석 (모호한 곳을 실행 전에 고정)
- r_t = 종가_t/종가_{t−1} − 1, 거래일 = KOSPI 행 순서. 구간 소속은 **사건일 t** 기준, 결과는 r_{t+1}(구간 경계를 넘어도 사용). r_{t+1} 없는 마지막 날 제외.
- base = 구간 안 모든 t(r_t·r_{t+1} 둘 다 있는 날)의 P(r_{t+1}>0)·평균.
- 첫 폭락 = r_t ≤ −3% 이고 t−5..t−1 에 폭락일 없음. 재폭락 = t−5..t−1 안에 r_{s+1}>0 인 폭락일 s 가 하나 이상. 둘 다 아니면 '연속'(서술).
- H3a = t−3..t−1 안 폭락일 있고 r_t ≥ +3%. H3b = 같은 조건에서 KOSPI200 high_t/close_{t−1} − 1 ≥ +4%(K200 행이 그날 없으면 제외).
- 에피소드 = 폭락일 날짜순, 이전 폭락일과 거래일 간격 ≤ 10 이면 같은 에피소드. H3 사건은 t−3..t−1 중 **가장 최근 폭락일**의 에피소드.
- 검정: H1 이항 정확검정 P(X≥k | n, base) · H2 Fisher 단측(재 < 첫) · H3 평균 군집 부트스트랩 p = P*(평균 ≥ 0). 부트스트랩 = 집단별로 에피소드를 복원추출(B 10,000, seed 20261021), H1 p = P*(반등률 − base ≤ 0), H2 p = P*(재 − 첫 ≥ 0). 판정 p = max(정확, 부트스트랩)(H3은 부트스트랩만).
- 등급 = 사전등록 §4·§6 그대로(최소 표본 n≥10·에피소드≥5, α 0.00714, 분할 미달 시 풀링·상한 C, 풀링 미달 시 검증전).

### 0.3 허용오차 (kb:verify#5, SE 기반 — 표본 크기마다 다름)
| 항목 | 일치 조건 |
|---|---|
| ① 사건 집합 | 구간별 n 차이 ≤ max(1, ⌈0.05·n⌉), 에피소드 차이 ≤ 1. **통계보다 먼저 본다**(kb:verify#2 ①) |
| ② 반등률 | \|원 − 재현\| ≤ max(0.1%p, 0.5·√(p(1−p)/n)) — p·n 은 재현값 |
| ② 평균 | \|원 − 재현\| ≤ max(0.01%, 0.5·sd/√n) — sd 는 재현 집단 r_{t+1} 표준편차 |
| ② p 값 | 숫자 일치는 요구하지 않음(부트스트랩 구현 차). **판정 문턱(0.00714·0.05·0.10)의 같은 쪽**이면 일치 |
| ③ 등급·판정 | 가설별 등급(A/B/C/F/검증전)·판정(통과/보류/기각) 같으면 일치 |
| base | 반등률·평균은 ②와 같은 식, n 차이 ≤ 2 |

### 0.4 뒤집힘 기준과 권한
- **원 결론을 뒤집는 조건**: 재현 등급이 원 등급과 다른 가설이 1개 이상 → 그 가설은 원 보고서 등급을 한 단계 강등 요청하고(보드 quant-replicate-studies 규약), 재현 숫자를 기준으로 인용하도록 요청한다. 특히 H1~H3b 중 하나라도 재현에서 C 이상(같은 방향 풀링 p<0.10)이 나오면 "2010~2025 어디에서도 재현되지 않았다"(원 §2 결론) 문장 수정 요청.
- **원 결론을 유지하는 조건**: 4개 가설 등급 모두 같고, ① 사건 집합이 허용오차 안.
- ①이 허용오차 밖이면 통계 비교 전에 원인 분류(데이터 출처 / 창 정의 / 에피소드 정의 / 코드 버그, kb:verify#2 ③)를 먼저 적고, 그 경우 판정은 '검증전'.
- 권한: 검증 데스크는 뒤집을 권한이 있다(kb:verify). 단 **22시 이후 실행이므로 등급·규칙 변경은 하지 않고 '제안(🌙)'으로만 적는다** — 반영은 다음 날 퀀트·PB 확인 뒤.

## 6. 판정 (§0.4 기준)
- 사건 집합·통계 20/20 일치 · 가설 p 문턱 16/16 일치 · 등급 4/4 일치 → **재현 일치 — 원 결론 유지**(지수 H1~H3b).
- base n 이 설계·풀링에서 1 작음(2465 vs 2466): 재현은 r_t 가 없는 첫날(2010-01-04)을 base 에서 뺐다(§0.2) — 원은 r_{t+1} 만 요구한 것으로 보임. 창 정의 차이, 허용오차(±2) 안, 결론 불변. 원 코드 미열람이라 `검증전`.
- 재현은 숫자가 맞는지만 본다(kb:verify#7). 등급은 원과 같다 — F·검증전·F·F(역방향 C). 재현 일치가 등급을 올리지 않는다.
- 반대 근거: 원과 재현이 **같은 데이터 창고**(data/hist pykrx KOSPI)를 쓴다 — 데이터 오류는 공통(kb:verify#6). 사이드카는 양쪽 다 대용(K200 현물 고가 +4%)이라 H3b 는 '대용 기준 일치'일 뿐 실제 사이드카 재현이 아니다.
- 범위 밖: H4a~c(종목) 미재현 — 원 등급 중 유일한 C(H4b)와 설계 구간 Holm 통과(H4a)가 여기 있다. 인용 시 'H4 는 검증 데스크 미재현'을 붙여 달라는 제안(🌙, 22시 이후 — 반영은 퀀트·PB 확인 뒤).
- 제안(🌙): 원 보고서 §1 머리에 '지수 H1~H3b 독립 재현 일치(replication_hollzzak.md)' 한 줄. 등급 변경 없음.
- 코드 영향 범위: 신규 `scripts/replicate_hollzzak.py`·`tests/test_replicate_hollzzak.py`·이 보고서 2개. 다른 모듈이 import 하지 않음 — 롤백 = 네 파일 삭제.

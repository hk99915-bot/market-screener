## §0 사전등록 (결과 보기 전 고정 — 이 절은 결과 커밋보다 먼저 커밋한다)

**데이터.** data/deriv/daily.csv(2010-01~: k200_close·spot_frgn·spot_indiv·rep_iv), data/hist kr·us 2010~2025 일봉. 분할: 학습 ~2019 / 검증 2020~. 유동성 KR 20일 거래대금 ≥ 10억·≥ 1,000원, US ≥ $2천만·≥ $5.

**지수 시그널 (코스피200, 신호일 종가 진입, 보유 h일, 보유 중 신호 무시 = 비중첩).** 지표 = h일 수익 − 같은 구간(학습/검증) 무조건 h일 평균 수익(초과), 비용 0.02%(선물).
- S1 **외국인 수급 추종**: 외국인 현물 5일 누적 순매수가 직전 250일 분포 상위 10% → 롱 5일.
- S2 **개인 쏠림 역추세**: 개인 현물 5일 누적 순매수가 직전 250일 상위 10% → **숏** 5일(초과 = −수익 − (−무조건 평균)).
- S3 **공포 매수**: VKOSPI 가 20일 전 대비 +50% 이상 → 롱 20일.

**종목 시그널 (신호일 다음 날 시가 진입, 보유 h일 종가 청산, 초과 = 종목 수익 − 같은 날 유동 유니버스 동일가중 같은 창 수익, 비용 왕복 KR 0.25%·US 0.10%).** 신호일별 평균 초과 → 달력 월 평균 → 월 t.
- S4 **KR 거래량 터진 돌파**: 거래량 ≥ 20일 평균 × 3 이고 종가 = 20일 최고 종가 → 10일 보유.
- S5 **KR 장대 반전(투매 흡수)**: 시가 ≤ 전일 종가 × 0.95 이고 종가 ≥ 전일 종가 → 5일 보유.
- S6 **US 거래량 터진 돌파**: S4 와 같은 정의, US → 10일 보유.

**통과 규칙 (m = 6, 단측, Bonferroni t ≥ 2.39).** B = 검증 초과 > 0 · t ≥ 2.39 · 학습 초과 > 0 · 검증 표본(지수 = 사건, 종목 = 월) ≥ 30. C = 검증 초과 > 0 · t ≥ 1.645. F 그 외. 표본 < 30 → 검증전.

**알려진 한계.** 종목 데이터 2026 구성(생존편향 가능, US 강함) → B 상한. 종가 신호의 당일 체결 불가(S1~S3 는 종가 진입 가정 — 동시호가 근사). S4·S6 은 '추격'이라 슬리피지 과소 가능. 수급 데이터 단위·정의는 deriv daily 원본 그대로.

**시도 일지.** 주제 `alpha_source` 4차. 등록 전 탐색 0건(컬럼 존재·기간 확인만).

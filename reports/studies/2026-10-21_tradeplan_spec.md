## 1. 용어 (경영학 1학년용)
- **R**: 진입가 E − 스탑 S. "한 번에 잃을 각오한 1단위". 결과를 R로 재면 종목 가격·변동성이 달라도 비교된다.
- **R:R**(손익비) = (목표 T − E) ÷ (E − S). 1차·2차 각각.
- **선도달 확률**: 20거래일 안에 1차 목표와 스탑 중 무엇에 먼저 닿는가(일봉 고가·저가, 같은 날 둘 다면 스탑으로 — 보수).
- **E[R]**(기대값) = 계획대로 했을 때 평균 결과(R 단위, 왕복 비용 차감). 승률만으론 판단 안 함(퀀트 KB #11).

## 3. 매크로 필터 (금리·유가·환율 포함)
- 레짐 하락장 ×0.5 (macro KB #4, C) · 매크로 바람 ≤ −0.3 ×0.75 · 내재 1일 변동 ≥3% 또는 VIX ≥30 ×0.5 · 고중요(imp 3) 매크로 이벤트 D0 = 보류(agreements: FOMC·CPI 당일 위성 신규 금지), D-1 ×0.5.
- 충격 감지(`macro_series` 20일 변화): 미10Y ±25bp · WTI ±15% · 달러원 ±3%(KR). 충격이 있고 그 종목의 실측 민감도(`detail.drivers.macro.rows`, |t|≥2)가 **역방향**이면 ×0.75 + 2차 목표를 1차와의 거리 절반으로 감액. 예: 금리 급등 국면 × 금리 β 음수(t≤−2) 성장주 → 2차 목표 하향. (검증전)
- 한3Y·실질금리는 `macro_series`에 시계열이 없어 이번 판 미반영 → 데이터 요청(장부).

## 4. 컨빅션 (펀더·내러티브·센티먼트·기술)
- 축 값 −1~1 (원천: 펀더 = 밸류 모델 중앙 상승여력·EPS 추정 점수·이익 신호 원천 / 내러티브 = 애널 톤·목표가 상승여력·리서치 목표가 상/하향·공시 / 센티먼트 = 외인+기관 10일 순매수÷거래대금·공매도 잔고 변화·매집·숏스퀴즈 원천 / 기술 = 50일선 괴리·60일 수익률 + 시그널·모멘텀 원천).
- 점수 = 50 + 50 × 가용 축 평균. A ≥70(×1.0, 2차 보유) · B ≥58(×0.75, 2차 보유) · C ≥45(×0.5, 1차 전량) · D <45(보류). 가용 축 1개면 상한 C.
- **가중 보정**: 축 간 가중은 공통 이력이 없어 불가(펀더·내러티브 필드가 signals.parquet 에 2026-10부터만) → **검증전 동일가중**. 기술 축 안의 가중만 IC로 보정(§5-3).

### 5-2. 격자 — 추천 배수와 평탄 영역
- KR: 분할 4칸의 학습 E[R] −0.072~−0.075R(범위 0.003R) ≪ SE 약 0.02R → **평탄**. 단일 목표 1~3R도 같은 스탑 행 안 범위 ≤0.01R. 목표 배수는 결과를 바꾸지 않는다 = 다이얼(CIO KB #15).
- 스탑: ATR 배수가 넓을수록 KR 검증 E[R]이 덜 나쁨(1.0×ATR −0.06R → 3.0×ATR −0.015R)이지만 3.0×ATR은 손절폭 15% 캡으로 후보 44~48%가 탈락 = 저변동 종목만 남는 **선택 효과** → 채택 안 함. 구조적 스탑(현행)은 2.0×ATR과 SE 안.
- **추천 = 현행 유지**: 스탑 구조적(20일 저점·2×ATR·최소 1ATR), 1차 1.5R(또는 1~2.5R 저항) 50% 분할, 2차 3R(밸류·애널 중앙 ≤5R), 20일 시간 손절. 근거는 "최적"이 아니라 "평탄해서 어디든 같다".
- **핵심 결론**: 계획 기하만으로는 KR 기대값이 0 이하(F, 비용이 −0.05R 몫). 엣지는 진입 신호에서 와야 한다 — 그래서 각 plan 은 E[R] 옆에 무조건 기준선을 같이 적고, 기준선 이하면 '관찰'.
- 레짐(구조적 스탑·2R, 전 기간): KR 추세군 200일선 아래 −0.063R(t −3.2) vs 위 −0.043R → 하락장 축소 근거(C). KR 기준선은 반대(아래 −0.011 vs 위 −0.062) — 레짐 효과가 군에 따라 뒤집힘, 그래서 보류가 아니라 ×0.5.

### 5-3. 컨빅션 축 IC (같은 날 횡단면 순위 ↔ 계획 결과 R, 학습 / 검증)
- KR 추세군 기술: 50일선 괴리 IC 0.128(t 18.5) / 0.129(t 20.5), 60일 수익률 0.066 / 0.063, 52주 고점 근접 0.001 / 0.013 → 가중 0.66·0.34·0. 단 검증 3분위 평균 R 차이 −0.011R(순위는 맞히나 평균은 꼬리 손실이 지배) → **C**.
- US 추세군 기술: 50일선 0.054 / 0.089, 60일 0.029 / 0.046, 52주 고점 −0.058 / −0.055(역) → 가중 0.65·0.35·0.
- KR 센티먼트(외인+기관 20일 순매수÷시총, 2024-02~ / 분할 2025-07): IC 0.028(t 1.5) / 0.021(t 1.2), 3분위 차 +0.04R → **C(방향만)**. 매집 군 안에선 0(검증전).

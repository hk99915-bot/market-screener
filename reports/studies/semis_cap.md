# 반도체 비중 한도 — 밴드 · 글라이드 패스 · 하락장 하드캡 (semis_cap)

> 질문: 테마(반도체) **40% 고정 한도**를 (a) 밴드(목표 40 / 발동 45 / 하단 30, 주 1회 점검, 반등일 매도) (b) 글라이드 패스(적립으로만 희석, 매도 없음) (c) 하락장 하드캡 30/35/40 으로 바꾸면 수익·낙폭·회전이 어떻게 달라지나.
>
> 코드: `scripts/study_semis_cap.py` · 원자료: `reports/studies/semis_cap.json` · 선행: [rule_audit.md](rule_audit.md) (T4 반등일, T5 하락장 상한)
>
> 공개 저장소 — 비율만 쓴다. 개인 보유·금액·수량은 쓰지 않는다. 적립 비율 c 는 '월 적립 ÷ 시작 순자산'이라는 비율 파라미터다.

## 0. 사전 등록 (결과 계산 전에 커밋 — `6a86790d`)

스크립트 머리말에 그대로 있다. 요지:

- **데이터** 반도체 대용치 = 삼성전자·SK하이닉스 50/50 월말 리밸런싱(가격수익, `screener.lab.load_kr`). 나머지 자산 = 코스피200 가격지수(`data/deriv/daily.csv`). ETF(091160·139260·069500)는 저장본에 없음(네트워크 차단). 2010-10-21(200일선 확보 뒤)~2026-10-16. 비용 편도 0.125%, 현금 이자 0, 배당 제외.
- **판정** 반등일 = 코스피 종가 ≥ 전일 +0.5%(14:30 데이터 없음 → 종가 근사). 하락장 = 코스피 < 200일선 **또는** 20일 최고 종가 대비 −15%. 주 1회 = 주 마지막 거래일 종가, 체결은 다음 거래일 종가.
- **비교 단위** 12개월(250거래일) 윈도를 매월 첫 거래일에 시작(겹침), 모든 안을 같은 시작 상태(반도체 40 / 나머지 60)로 놓고 **같은 윈도끼리 짝지은 차이**. 겹침은 Newey-West(lag 11) 표준오차로 처리. IS = 시작일 ≤ 2019-12-31(110개), OOS = 2020~(70개).
- **m = 7** (H1 3 + H2 1 + H3 3) → Bonferroni α = **0.00714**. 등급 A/B/C/F/검증전은 rule_audit 규약. 대안 MDD 평균이 기준의 1.5배면 '위험 증가'.
- **사전 예상** H1: 삼성·하이닉스 고베타라 45%는 상승장에서 자주 걸릴 것, 수익·MDD 차이는 작을 것. H2: 평균 0 근처, 유의하지 않을 것. H3: 낮은 캡이 MDD는 줄이지만 반등을 놓쳐 수익은 비슷, Bonferroni 미달일 것.
- **PB 주장 판정 기준(사전)** ① "45%는 자주 안 걸림" → 12개월 안 45% 도달 윈도 ≥25%면 '자주'. ② "글라이드 1개월 뒤 35%" → 1개월 안 ≤35% 도달 윈도 ≥75% 맞음 / 50~75 대체로 / <50 틀림. ③ "30 vs 35는 −20% 충격에서 ≈1%p" → 실현 손실 차이 0.5~1.5%p면 맞음.

### 1-3. H2 글라이드 패스(적립 희석) vs 즉시 35% 매도 — 12개월 윈도 180개

적립 c = 월 적립 ÷ 시작 순자산. 두 안 모두 적립은 나머지(코스피200)에만, 반도체 신규 매수 없음.

| c | 12개월 순자산 차 GLIDE/SELL35 − 1 (p) | IS | OOS | MDD 평균 GLIDE / SELL35 | 반도체 비중 평균 G / S | 35% 이하 첫 도달: 1개월 안 / 2개월 안 / 중앙값 | 등급 |
|---|---|---|---|---|---|---|---|
| **0.137** | **+0.34%p** (0.0009) | +0.28 (0.0005) | +0.42 (0.061) | −12.9% / −12.8% | 29.9 / 28.4% | **56% / 99% / 1개월** | **A** |
| 0.07 | +0.46%p (0.0006) | +0.40 | +0.56 (0.054) | −13.3 / −13.2 | — | 7% / 49% / 2개월 | (보조) |
| 0.03 | +0.59%p (0.0003) | +0.52 | +0.69 (0.047) | −14.3 / −14.1 | — | 0% / 9% / 5개월 | (보조) |

- 글라이드가 즉시 매도보다 12개월 뒤 순자산 **+0.34%p**, IS·OOS 같은 방향, p 0.0009 < α → 규약상 **A**. 단 크기는 작고, 원천은 '반도체 5%p를 한두 달 더 들고 있었던 것'이다 — **반도체가 코스피를 이긴 표본의 성질**이지 글라이드 패스 자체의 알파가 아니다. MDD 차이는 +0.08%p로 없다.
- c = 0.137이면 **1개월 뒤 ≤35%는 56%의 윈도에서만** 성립(가격 변동 없을 때 산술은 35.2% — 경계선이라 반도체가 조금만 이기면 넘는다). 2개월이면 99%. **"1개월"은 '대체로', 안전하게는 "2개월 안"**.
- MDD는 적립 포함 순자산 기준이라 적립이 낙폭을 가린다(두 안 공통). 적립 비율이 작을수록(0.03) 글라이드가 35%에 닿는 데 5개월 — 적립이 순자산 대비 작아지면 글라이드만으론 한도가 안 지켜진다.

- 하락장에서 시작해도 **캡 10%p 차이가 MDD를 0.4%p밖에 안 줄인다**(−18.7 → −18.3). 이유: 하락장 윈도는 평균 +26~29%로 끝나는 '반등 구간'이고, 캡이 낮을수록 반등을 덜 먹는다. 수익/변동성은 IS에선 높은 캡이 유의하게 좋았고(p 0.001) OOS에선 반대 부호 → 전체 F.
- **최소 MDD 캡 = 30, 최고 수익/변동성 캡 = 45** — 둘 다 차이가 측정 오차 수준.
- −20% 충격(하락장 윈도 안에서 반도체가 시작 대비 −20%에 처음 닿는 시점, 21개 윈도): 35캡 − 30캡 손실 차 **−0.38%p**(사후 보조: 시작 즉시 캡 비중으로 맞춘 변형도 −0.34%p). 정적 산술(5%p × 20% = 1%p)의 1/3 — 반도체가 빠지면 비중이 스스로 줄고, 캡 집행(월말)보다 하락이 먼저 오는 경우가 많다.

## 2. 해석 · 추천

| 안 | 등급 | 추천 |
|---|---|---|
| H1 밴드 40/45/30 (vs 고정캡 40) | **C** | **채택 후보** — 수익은 같거나 조금 낫고(+0.35%p/년), MDD 같고, **매도 횟수 1/9**. 현행 '40% 상시'보다 단순 비용(거래·결정 횟수)이 명백히 적다. 하단 30 되사기 조항은 16년간 미발동 → 조문만 두고 기대하지 말 것 |
| H2 글라이드 패스 (vs 즉시 35% 매도) | **A** (효과 +0.34%p, 작음) | **채택 가능** — 즉시 매도 대비 손해 없음·낙폭 같음. 단 "1개월"이 아니라 **"2개월 안 35%"** 로 기한을 적을 것. 적립이 순자산 대비 7% 아래로 작아지면 글라이드만으론 한도 유지 불가 |
| H3 하락장 하드캡 30/35 (vs 40) | **F** | **근거 없음** — 하락장에서 캡 10%p 낮춰도 MDD 0.4%p, 수익 −2.7%p(유의 X). FRM(VaR) 논거는 정적 산술이고 경로상 실현 효과는 그 1/3. 레짐별 캡을 따로 두는 복잡성을 정당화할 숫자가 없다 |

**가장 방어 가능한 단일 규칙**: *밴드(목표 40 / 발동 45 / 하단 30, 주 1회 점검, 초과분은 다음 반등일 매도) + 한도 아래로 내리는 일은 적립으로(글라이드, 기한 2개월)*. 레짐별 하드캡은 두지 않는다. 반등일 대기는 비용이 없으므로 유지.

## 3. 한계

- 반도체 대용치가 **삼성·하이닉스 2종목**(실제 보유는 ETF·미국 반도체 포함으로 더 분산). 나머지 자산을 코스피200 하나로 둬서 실제 다자산 코어보다 낙폭이 크게 잡힌다 — 안끼리 비교엔 같은 방향으로 작용.
- 표본 16년이 반도체 초과수익 기간이라 **'반도체를 더 드는 쪽'이 유리한 편향**. H2의 A는 이 성질에 올라탄 것. 반도체가 코스피를 지는 구간에선 글라이드 − 즉시매도 부호가 뒤집힐 것(구조상 자명, 별도 측정 안 함).
- 종가 근사(14:30 반등 판정·주말 점검), 배당 제외, 현금 이자 0, 세금 없음.
- 12개월 겹침 윈도 180개(HAC) — 0.3%p 수준 차이는 검출력 경계. H3 77개는 더 약함.
- 적립 포함 MDD는 적립이 낙폭을 가린다(두 안 공통이라 차이 해석엔 무해).

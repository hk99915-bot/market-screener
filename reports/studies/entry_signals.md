# 급락 뒤 '더 싼(빠른) 진입 신호' 검증 (entry_signals)

> 질문: 운용회의 '강세 전환 신호'(외국인 현물 2일 연속 순매수 + 코스피 5일 고점 회복)는 반등 대부분이 끝난 뒤에 켜진다(10/16: 5,750 vs 5일 고점 6,384). 더 일찍·싸게 들어가는 신호 중 무엇이 대조군보다 나은가?
>
> 코드: `scripts/study_entry_signals.py` · 원자료: `reports/studies/entry_signals.json` · 선행: [playbook_signals.md](playbook_signals.md)

## 0. 사전 등록 (결과 보기 전에 고정)

이 절은 결과 계산 전에 작성·커밋했다. 결과를 본 뒤 바꾸지 않는다. (작성 전 확인한 것: 이벤트 후보 날짜 목록과 데이터 기간뿐 — 수익률은 보지 않음.)

### 0-1. 데이터
- 코스피 일봉 + 외국인 현물 순매수: `data/deriv/daily.csv` (실제 코스피, **2010-01-04 ~ 2026-10-15**, `spot_frgn` 결측 없음). 1999~ 코스피는 저장본이 없고 샌드박스에서 야후 다운로드가 막혀 2010~ 만 쓴다(한계로 명시).
- 종가 기준만 쓴다. 거래비용 없음. 모든 신호는 당일까지 데이터만 사용(이동평균·저점·5일 고점 모두 당일 포함 과거). 이벤트 이후 '최종 저점·고점'은 **평가용**으로만 쓴다.

### 0-2. 이벤트 (주 분석)
- 조건일: **20일 낙폭 ≤ −15%**(종가 ÷ 당일 포함 최근 21개 종가 최고 − 1, committee `dd20`과 같은 정의) **또는 일간 ≤ −5%**.
- 이벤트 t0 = 조건일 중 **직전 이벤트로부터 20거래일 넘게 떨어진 첫날**(겹치지 않는 국면, 이벤트당 한 표본).
- 신호 탐색창: t0+1 ~ t0+20 (F만 t0). 창 안에 안 켜지면 미진입.
- 민감도(보조, 등급에 안 씀): 이벤트 = 일간 ≤ −3% & 20일 낙폭 ≤ −10% (playbook 정의), 같은 20거래일 비중첩.

### 0-3. 후보 (첫 발동일 종가 진입)
| 코드 | 이름 | 발동 조건 (s = t0+1…t0+20, 모두 종가) |
|---|---|---|
| D | **대조군** = 현행 강세 전환 신호 | 종가 = 당일 포함 5일 종가 최고(committee `last ≥ hi5`) **그리고** 외국인 현물 순매수 s−1·s 모두 > 0 |
| D0 | 대조군 가격만 (보조) | 5일 고점 회복만 (외국인 조건 없음) |
| A | 단계 진입 | 1/3 t0 종가 → 1/3 E 발동일 종가 → 1/3 C 발동일 종가. 못 채운 조각은 현금 |
| B | 저점 +3% | 종가 ≥ (t0~s 최저 종가) × 1.03 |
| B2 | 저점 +3% + 외국인 | B 그리고 외국인 s일 순매수 > 0 |
| C | 20일선 회복 | 종가 > 20일 단순이동평균(당일 포함) |
| E | 5일선 회복 | 종가 > 5일 단순이동평균(당일 포함) |
| F | 급락일 종가 (기존 `crash_day_close`, B등급 기준선) | t0 종가 즉시 |

### 0-4. 지표
- **진입 기준 수익** (진입일 종가 → +5·+10·+20거래일 종가; A는 가중평균 진입가 → 마지막 조각 진입일 +H, 현금 조각 0): 평균·중앙값·승률·손익비(이긴 평균 ÷ 진 평균 절대값)·최악.
- **가짜 반등률**: 진입 후 20거래일 안에 종가가 진입가 대비 −5% 이하로 내려간 비율. 최대낙폭 = 진입 후 20일 최저 종가 ÷ 진입가 − 1.
- **놓친 반등**: 진입가 ÷ 국면 저점(t0~t0+40 최저 종가) − 1, 그리고 반등 소진율 = (진입가 − 저점) ÷ (t0~t0+40 최고 종가 − 저점) (진입가가 저점 아래면 0).
- **신호 대기일수**: 진입일 − t0 (거래일).
- **주 검정 지표 (공통 청산)**: R = t0+40 종가 ÷ 진입가 − 1 (미진입 0, A는 조각 가중). 같은 이벤트끼리 **후보 − D** 짝 차이. 이것이 '같은 국면을 더 싸게 샀나'를 직접 잰다.

### 0-5. 검정·등급
- 짝 차이 평균의 단측 t검정(H1: 후보 > D), 단위 = 이벤트(비중첩). **Bonferroni m = 6** (A·B·B2·C·E·F vs D), α = 0.05/6 = 0.0083.
- IS = t0 ≤ 2018-12-31, OOS = 2019-01-01~. (2010~ 데이터라 IS 이벤트가 적을 것 — **IS 이벤트 < 8 이면** 주 판정은 전체 표본으로 하고 IS·OOS 는 방향 일치만 본다.)
- 하락장 하위: t0 종가가 200일선 아래인 이벤트만.
- 등급(views 규칙):
  - **A** = 전체(또는 IS≥8이면 IS) Bonferroni 유의 + IS·OOS 모두 같은 방향(+) + 하락장 하위 같은 방향.
  - **B** = Bonferroni 유의(표본 밖·하위 확인 불충분).
  - **C** = 단측 p < 0.10 (보정 전)이고 평균 차이 > 0.
  - **F** = 그 외(효과 없음 또는 D보다 나쁨).
  - **검증전** = 발동 이벤트 < 8.
- D(대조군)는 정의상 등급 비교 대상. D0·민감도·F 대비 비교는 보조(등급에 안 씀).
- **추천 규칙**: '강세 전환 신호' 대체 후보는 신호형(B·B2·C·E·A) 중 최고 등급, 동률이면 공통 청산 평균 차이가 큰 것. 신호형이 모두 C 미만이면 → F(급락일 종가)가 C 이상이면 'F 유지(기다리지 않기)', F도 아니면 '대조군 유지'.
- `views/registry.json` 에 `entry_trigger` 렌즈 후보로 등록(등급 C 미만이면 역할 reference). 운용회의 코드는 이번에 바꾸지 않는다(PB 검토 후 별도).

### 5. 결론 · 추천

**추천: 강세 전환 신호를 '급락일 종가 1차 진입(F)'으로 바꾼다 — 즉 신호를 기다리지 않는다.** (사전 규칙: 신호형 후보 모두 C 미만 → F가 C 이상이면 F 유지.)

1. 같은 국면을 t0+40에 비교하면 F가 대조군보다 평균 +6.8%p(주) / +8.0%p(민감도), IS·OOS·하락장 모두 같은 방향. playbook_signals(55건, 다른 이벤트 정의)의 B등급 결과와도 일치.
2. 더 빠른 '확인' 신호(저점 +3%, 5일선, 20일선, 단계 진입)는 대조군보다 나아 보이지만(+2.9~+5.3%p) 모두 F보다 나빴다. 확인을 앞당겨도 확인 자체가 비용이다.
3. 대조군의 외국인 2일 조건이 가장 큰 비용원(가격만 쓰면 +6.1%p). 운용회의가 '확인 신호'를 꼭 남기겠다면 **최소한 외국인 조건을 빼고**, 신호형 중 수치가 가장 나은 **B(저점 +3%, 평균 대기 3일)** 를 2차 분할 참고선으로 — 단 등급 F(입증 안 됨)라 '참고'로만.
4. 사이즈는 이 스터디 범위 밖. F는 '들어간다면 언제'의 타이밍이지 매수 허가가 아니다(`crash_day_close` 렌즈와 같은 단서, lab CRASH_REBOUND_LARGE F).

한계: 2010~ 데이터만(1999~ 미확보), 독립 국면 11개, 2026년에 이벤트 5건 몰림, 거래비용 없음. 1999~ 코스피 일봉을 저장하면 같은 스크립트로 재실행 권장.

운용회의 코드(`screener/committee.py`)는 바꾸지 않았다 — PB 검토 후 별도 작업. `views/registry.json` 에 `entry_trigger` 렌즈 후보(근거 C, 진입 역할 alert)로만 등록.

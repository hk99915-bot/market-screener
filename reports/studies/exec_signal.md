### 0-1. 코드에 적힌 신호 정의 (`screener/committee.py`, 2026-10-16 origin/main 57c85b9b, 그대로 인용)

`_exec_plan()` 의 `signals` 목록 — 규정이 말하는 "실행 대본 1·2 신호"는 이 목록의 1·2번째다:

```python
fl = _flows2()   # [0]=오늘 코스피 외국인 순매수(잠정, 억원), [1]=전일(확정)
sig = [{"t": "외국인 순매수 전환 (참고 — 이력 없어 검증 전)", "now": ..., "ok": bool(fl and fl[0] > 0)},
       {"t": f"오늘 저점 {lowt:,.0f} 위 마감 (참고 — 게이트 아님)", "now": f"{last:,.0f}", "ok": bool(last and lowt and last >= lowt)},
       {"t": f"5일 고점 {hi5:,.0f} (참고 — 2차 조건에서 제외)", "now": f"{last:,.0f}", "ok": bool(last and hi5 and last >= hi5)}]
```
- **신호 1 = `fl[0] > 0`** : 오늘 코스피 외국인 현물 순매수(잠정) > 0. 하루만 본다(2일 아님).
- **신호 2 = `last >= lowt`** : 종가(장중이면 현재가) ≥ **오늘 저가**. 종가는 정의상 항상 저가 이상이므로 **이 조건은 항상 참**(동치 포함). 즉 코드상 신호 2는 걸러내는 힘이 없다.
- 신호 3 = `last >= hi5`, `hi5 = max(c[-5:])`(오늘 포함 5개 종가 최고) : 종가가 5일 종가 신고가.

`_stance()` 의 '분할 매수' 판정(규정 [1] '회복 확인'의 원형):
```python
met_f = len(fl) >= 2 and fl[0] > 0 and fl[1] > 0      # 외국인 오늘·전일 모두 순매수
met_p = bool(hi5 and last and last >= hi5)           # 5일 고점 회복
if met_f and met_p: st_ = "분할 매수"
```
규정 [1]의 "+ 20일선 회복"은 코드에 없다(`sma20`은 계산만 하고 판정엔 안 씀). 규정 [4] "외국인 순매수 전환 + 저점 지지"의 '저점 지지'는 코드에서 위 신호 2(항상 참)뿐이다. `_stance()` 안의 `nearlow = last/low_today − 1 < 0.01`("종가가 저가권")은 설명문에만 쓰이고 판정엔 안 들어간다.

### 0-3. 검정 대상 신호 (Part 1)
| 코드 | 정의 (모두 당일 t 종가 기준) |
|---|---|
| S1 | 외국인 순매수 `spot_frgn[t] > 0` (코드 신호 1 그대로) |
| S2 | 종가 ≥ 오늘 저가 (코드 신호 2 그대로 — 항상 참, 보고만) |
| S2′ | 종가 ≥ 오늘 저가 × 1.01 (`_stance` 의 '저가권' 문턱을 판정으로 옮긴 '의도된' 저점 지지) |
| S12 | S1 & S2′ (규정 [12] "1·2 신호 충족"의 의도 버전; 문자 그대로는 S1 & S2 = S1) |
| R | 회복 확인(규정 [1]·코드 분할 매수): 외국인 t−1·t 모두 > 0 **and** 종가 = 당일 포함 5일 종가 최고 |
| R+ | R and 종가 > 20일 단순이동평균 (규정 [1] 문장 그대로) |
| F | 급락일 종가: 일간 ≤ −5% (대조 기준선) |
| U | 무조건 (모든 날) |

**적용 구간**: 규정 [12]·[1]은 하락장 규칙이므로 **주 분석 = 하락장 날만** (코스피 종가 < 200일 단순이동평균 **또는** 20일 낙폭 ≤ −15%; 규정 [1] 레짐 정의와 같다). 보조 = 전체 날.

### 0-4. 가설·지표·검정
- **H1** 신호일 이후 코스피 5·20·60거래일 수익(종가→종가) 평균·중앙값·승률·최악. 비교 (i) 신호일 − 같은 구간 무조건(U), (ii) 신호일 − 급락일(F). 검정: 겹치는 창이라 **Newey–West(지연 = 보유기간−1) 회귀 t** (앞수익 ~ 상수 + 신호 더미, 하락장 날 표본). F 대비는 두 독립 표본 Welch t(F 표본 작음, 겹침 보정 없음 — 보수적으로 읽음). 양측.
  Bonferroni **m = 15**(S1·S2′·S12·R·R+ × 3 보유기간, vs U) → α = 0.0033. vs F 비교는 보조(등급엔 안 씀).
  IS = t ≤ 2019-12-31, OOS = 2020-01-01~. 하락장 하위 = 주 분석 자체.
- **H2** 빈도: 하락장 구간 안 연간 발동 횟수(S12·R·R+), 발동 사이 최대 대기 거래일, 그리고 2020-03-19 · 2022(연중 첫 하락장 진입일 뒤) · 2024-08-05 · 2026-03-09 · 2026-10-13/15 급락 뒤 **처음 켜진 날(t0 + 며칠)** 과 그날 종가가 t0 종가 대비 몇 % 위였나(놓친 반등). 서술(등급 없음).
- **H3** S12 vs S1 vs S2′: 20일 승률(>0)·평균 차이, 두 비율 z검정 (양측, m=2). "둘 다"가 승률을 올리나, n만 줄이나.
- **H4** (Part 2) 비중첩 급락 이벤트(일간 ≤ −5%, 직전 이벤트와 20거래일 이상 간격)와 비중첩 반등 이벤트(20일 낙폭 ≤ −15% 상태에서 **종가** ≥ 전일 +0.5% — 14:30 데이터 없음, 종가로 대체)마다, 이벤트일 **섹터 20일 낙폭**(섹터 동일가중 지수 ÷ 당일 포함 21일 최고 − 1) 순위로 **덜 빠진 상위 1/3** vs **많이 빠진 하위 1/3** 의 이후 60일 코스피 대비 초과수익 짝 차이(덜 빠진 − 많이 빠진). 양측 t, m = 2(급락·반등). 20일은 보조.
  - 섹터 = KRX 업종 중 멤버 ≥ 8 종목(그날 기준), 동일가중 일수익 평균. **제외**: `전기·전자` 전체, `drivers.py` CHAINS 의 `semi_equip`·`it_hw`·`components` 코드, 삼성전자·SK하이닉스.
  - 위험조정 = 60일 초과수익 평균 ÷ 표준편차(이벤트 단위). 상·하위 3개 섹터는 **n ≥ 8** 섹터만.
- **등급** (`scripts/study_rule_audit.py` 규약): A = Bonferroni 유의 + IS·OOS 같은 방향 / B = Bonferroni 유의, 하위 방향 불일치 / C = p < 0.10(보정 전) / F = 그 외 / 검증전 = 표본 < 8.
- **판정 규칙(사전)**: S12·R 가 20일에서 U 대비 C 이상이고 F 대비 음수가 아니면 '유지'. U 대비 F 이거나 F 대비 유의하게 음수면 '급락일 종가로 대체'. 어느 쪽도 아니면 '급락일 종가 1차 + 신호는 2차 참고(결합)'.

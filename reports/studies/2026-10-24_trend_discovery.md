## 0. 가설과 고정한 것
- **H0(진단):** 정식 규칙이 0건인 원인은 fresh(진입일이 마지막 또는 직전 거래일)가 아니라 승률 문턱과 표본(창)이다.
- **H1(탐색):** 정식 문턱은 그대로 두고 대상만 넓힌다. 넓히는 방법은 근접 띠, 새 전략군, 3년 창이다. 이렇게 했을 때 통과 수가 귀무에서 나올 우연 기대보다 많은가.
- **바꾸지 않은 것:** 정식 문턱(Wilson 하한 > 0.5·n ≥ 6, t 하한 > 0·n ≥ 8), 사전등록 `docs/valuation_notes/2026-10-17_trend_expectancy_prereg.md`, 그리고 `sim_signals_*.json`이다. 테스트 `test_official_thresholds_unchanged`로 확인한다.
- **새 전략 정의(결과를 보기 전에 코드 상수로 고정):**
  - hi52: 종가가 직전 252일 최고 종가를 넘으면 진입하고, 종가가 SMA50 아래로 내려가면 청산한다.
  - gcv: SMA20이 SMA50을 상향 돌파하고 5일 평균 거래량이 50일 평균의 1.2배 이상이면 진입한다. 데드크로스에서 청산한다.
  - sqz: 직전 5일 중 하루라도 20일 밴드폭이 250일 분포의 하위 20%에 있고, 종가가 직전 20일 고가를 넘으면 진입한다. 종가가 SMA20 아래면 청산한다.
  - ma3·psar3: 정식 두 전략을 3년 창으로 다시 돌린 것이다(창 길이 진단용).
- **새로 켜짐(탐색):** 보유 중이고 진입이 4거래일 이내다. 체결과 비용은 정식과 같다(`detail._sim_one`, 종가 체결, 왕복 0.25%).
- **추격 주의:** HF 4차 S4/S6과 같은 정의(거래량이 20일 평균의 3배 이상이고 종가가 20일 최고 종가)의 날이 진입일부터 오늘 사이에 있으면 해당한다.
  - 국장: S4가 F이고 방향도 반대다(검증 10일 −1.70%, t −6.17, `2026-10-21_hf_desk_signals.md`). 그래서 **후보에서 빼고** `explore.chase`에 따로 둔다.
  - 미장: S6은 F지만 효과가 없는 쪽이다(t 0.84). 후보에 남기되 꼬리표를 단다.

## 2. 진단: 정식 규칙은 왜 0건인가 (`diagnosis` 블록, 단위: 전략 슬롯 = 종목 × 2전략)
| | US (10-22) | KR (10-23) |
|---|---|---|
| 스캔 종목 / 슬롯 | 528 / 1,056 | 1,233 / 2,466 |
| 지금 보유 중(pos=1) | 494 | 445 |
| 진입 ≤ 직전 거래일 (정식 fresh) / ≤ 4일 / ≤ 9일 | 64 / 129 / 258 | 56 / 174 / 259 |
| 위 중 거래 ≥ 6 | 52 / 102 / 223 | 49 / 156 / 228 |
| **fresh·보유 무시하고 Wilson > 0.5 통과** | **0** | **2** |
| fresh·보유 무시하고 t 하한 > 0 통과 | 3 | 5 |
| 승률 중앙값 / 75%분위 (거래 ≥ 6) | 33.3% / 45.5% | 30.0% / 41.7% |
| 실제 시뮬 창 중앙값 | 228거래일 | 223거래일 |

읽는 법:
1. **fresh는 묶는 조건이 아니다.** 진입일 조건을 아예 없애도 Wilson 통과는 US 0·KR 2, t 하한 통과는 3·5개 슬롯이 상한이다. fresh를 5일로 넓히면 대상(m)은 2배가 되지만 통과는 0으로 그대로다.
2. **묶는 조건은 승률 문턱이다.** Wilson > 0.5는 6회면 6승 0패, 8회면 7승 1패를 요구한다. 추세추종은 승률 30~45%에 손익비로 버는 구조다(kb:quant#11). 승률 75%분위도 45%여서 문턱에 닿지 못한다.
3. **창(표본)도 막는다.** '250거래일'이라는 표기와 달리 실제 창은 약 225일이다. `full`이 260봉뿐이라 SMA50 공백이 빠지기 때문이다. 이 창에서 거래 수는 중앙값 8~9회다.
4. **250일·거래 ≥ 6 제약:** 거래 ≥ 6을 채우는 비율은 슬롯의 71~75%다. 따라서 거래 수 제약은 주원인이 아니다.

## 4. 한계
- **우연과 구분되지 않는다.** 관측(4건과 2건)이 우연 기대(15.2건과 22.9건)보다 적다. 목록의 순위는 정보가 아니라 정렬일 뿐이다.
- **같은 장세 한 개다.** KR 3년 창도 대부분 2024~2026 강세장이다. 업종 쏠림(US 금융, KR 건설·부동산)은 오늘 하루의 장세다. 같은 업종 종목끼리 상관이 있어 이항 p는 낙관적이다.
- **생존편향:** 현재 구성 종목만 들어 있다. 합산 통계에서 hi52 +5.1%와 gcv +3.7~5.5%는 상향 편향이다.
- **US 데이터 범위:** 이어 붙인 종목이 42%뿐이라 US hi52는 그 종목에서만 볼 수 있다.
- **비용 가정:** 비용은 0.25%로 고정했다. 추격형(sqz 돌파)은 슬리피지가 이보다 클 수 있다.
- **사후 정의 위험:** 근접 띠(0.45, −0.5%p)는 오늘 정한 값이다. 결과를 본 뒤 바꾸면 새 id로 다시 적는다.

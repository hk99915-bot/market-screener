# 추세 시뮬, 표본 밖에서도 통하나?

> 퀀트 · 보드 `sim-oos`(P1) · 오너 11/12 07:21 「Eat the frog」 · 비율만 · 매매 지시 아님 · 주문표 근거 불가.
> 대상 = `screener/detail.py` `_simulate`(이평 추세·PSAR, 250거래일, 종가 체결, 왕복 0.25%)와 그 위의 알림 `_fresh`(Wilson)·`_fresh_exp`(기대값 t 하한). 지금까지 이 두 규칙은 **같은 250일 안에서만** 성과를 보여 줬다(표본 내). 이 연구는 규칙을 고정한 구간 밖에서 같은 숫자가 나오는지 본다.

## §0 사전등록 (결과 보기 전 고정 — 이 절은 결과보다 먼저 커밋)

**주제 시도 N.** 주제 `trend_sim` 현재 N = 207 (reports/studies/trial_log.md, 2026-11-11 빌드) → 이 연구 m = 10 추가 시 **217**, α(N) = 0.05/217 = 0.00023 (등급엔 안 씀, 병기). 저장소 전체 N 1391 → 1401.

**사전 노출 공시.** ① 2026-10-24_trend_discovery 가 정식 전략(이평·PSAR)의 3년 창(2023~2025) '탐색 통과 수'를 봤다 — 우연 기대와 구분 안 됨(통과 수만, 수익 크기는 안 봄) → OOS 2023~2025 부분 노출. ② trend_expectancy(10/17)는 2026-10-16 하루 단면 통과 수만 봤다(데이터 끝 2025-12 밖). ③ 이평·PSAR 규칙의 2010~2025 장기 성과는 계산해 본 적 없음. 등록 전 탐색 0건(데이터 칸·기간·NaN 처리 확인만).

### 데이터
- KR: `data/hist/kr_2010~2025.parquet`(상폐 포함, 원본 시세) → `screener.prices.adjust()`(px-adjust-unify 공통 조정 규칙 v2)로 조정. 업종 = `universe/kr_sector.csv`(현재 분류).
- US: `data/hist/us_2010~2025.parquet`(현재 구성 종목, 생존편향) · 업종 = `universe/us_sector.csv`(현재 GICS 섹터).
- 기간: 2010-01-04 ~ 2025-12-30(US 12-31). 2010년은 지표·250일 이력 확보용(표본 아님).
- 유동성(trend_events 와 같은 LIQ): KR 20일 평균 거래대금 ≥ 10억 원 · 종가 ≥ 1,000원 / US ≥ 2,000만 달러 · ≥ 5달러. 판정 시점 = 신호일(이벤트) 또는 전월 마지막 거래일(월 포트폴리오).
- 데이터 오류 컷: 해당 보유 구간 안에 |일간 수익| > 40% 가 있으면 그 종목-월·이벤트 제외(KRX 제한폭 30% 밖 = 조정 잔여·오류).

### 규칙 (detail.py 그대로 — 바꾸지 않는다)
- 지표: SMA20·SMA50(종가), PSAR(`screener.indicators.psar_np`, af 0.02~0.2). 종목 전체 이력으로 계산(250일 창마다 다시 시작하지 않음).
- 이평 롱: 종가 > SMA50 且 SMA20 > SMA50 → 1, 아니면 0. PSAR 롱: 종가 > PSAR → 1, 아니면 0. **PSAR NaN(첫 봉) = 0(중립)** — 카드 notes 의 'NaN 중립 처리 확인' 항목. (현행 `_simulate` 는 NaN 을 롱숏에서 −1(숏)로 읽는다 → 결과와 무관하게 별도 커밋으로 수정·테스트.)
- 체결: t 종가 신호 → t 종가 체결, t+1 수익부터 적용. 비용 = 포지션 변경 1단위당 편도 0.125%(왕복 0.25%) — `_sim_one` 과 같음. 롱숏은 등급 밖(서술만).

### 공통 통계
- 표본 단위 = **달**(월 포트폴리오 또는 이벤트의 달 평균). 분할: **IS = 2011-01 ~ 2019-12, OOS = 2020-01 ~ 2025-12**(이벤트는 신호일 기준, 2025-12 신호는 보유 끝이 데이터 밖이면 제외). 하락장 점검 = 2022.
- 검정: 월 시계열 평균 > 0 단측, **Newey-West(지연 3) t**, p = 스튜던트 t(자유도 = 달 수 − 1). 단순 t·중앙값·적중률 병기.
- m = 10 (아래 5가설 × KR·US). **Bonferroni α/m = 0.05/10 = 0.005**(단측). Holm 병기.
- 등급(trend_events·trend_rule 과 같은 틀): **A** = B + IS p < 0.005 + 2022 평균 > 0 · **B** = OOS 평균 > 0 · OOS p < 0.005 · IS 평균 > 0 · OOS ≥ 30달 · **C** = OOS 평균 > 0 · p < 0.05(B 미달) · **C(역방향)** = OOS 평균 < 0 · 역방향 p < 0.05 · **F** 그 외 · **검증전** = OOS < 30달 또는 (이벤트형) OOS 이벤트 < 100.
- 상한: US 전부 B(생존편향) · KR H3·H4 는 업종 현재 분류(상폐 종목 업종 없음 → 제외) → B.

### 가설 (m = 10, 모두 '효과 > 0' 단측) — 시장마다 H1~H5
| id | 질문 | 정의 | 효과 = |
|---|---|---|---|
| H1 | 이평 롱이 그냥 보유보다 낫나 | 매달 유동 종목 전부, 종목별 이평 롱 월수익(비용 후) − 같은 종목 보유 월수익, 동일가중 | 월 평균 초과 |
| H2 | PSAR 롱이 그냥 보유보다 낫나 | H1 과 같고 PSAR 롱 | 월 평균 초과 |
| H3 | '새로 켜짐 + 기대값 하한 > 0'(`_fresh_exp`) 알림이 업종보다 낫나 | 이벤트 = 이평/PSAR 롱이 t 종가에 0→1, t 까지 250거래일 창 시뮬(창 시작 재개, `_sim_one` 방식)의 청산 거래 ≥ 8 且 거래당 순수익 t 단측 95% 하한 > 0. 같은 종목·전략 20거래일 안 재이벤트 제외 | t+1 시가 → t+21 종가 − 0.25% − 같은 업종 유동 종목 같은 구간 동일가중 평균 |
| H4 | '새로 켜짐 + Wilson 하한 > 0.5'(`_fresh`) 알림이 업종보다 낫나 | H3 와 같고 조건 = 청산 거래 ≥ 6 且 승률 Wilson 95% 하한 > 0.5 | H3 와 같음 |
| H5 | 종목 상세의 지난 250일 시뮬 성적이 다음 달에도 이어지나 | 매달 말, 유동 종목별 점수 = (이평 롱 − 보유, PSAR 롱 − 보유)의 지난 250거래일 평균. 상위 1/3 − 하위 1/3 | 다음 달 두 전략 평균 초과(전략 − 보유)의 상위 − 하위 |

- 반드시 보고(서술, 등급 밖): 연도별 평균, 2020-02~03·2022 손익, 2020년 하나 빼고 OOS 재계산, 연 회전(거래 수/년), 월 포트폴리오 연복리·최대낙폭(전략 EW vs 보유 EW), **업종 대비**(H1·H2 전략 − 같은 업종 보유 EW), 롱숏 변형, 새로 켜짐 전체(조건 없음) 이벤트 대 업종 — H3·H4 조건이 보태는 몫을 보이려고, 5거래일 지평.
- **종목수 보정(서술)**: 종목별 OOS 초과(H1·H2) t > 1.645 인 종목 비율 vs 귀무 기대 5% — 종목 상세 화면에서 '이 종목은 시뮬이 좋다'가 우연 기대보다 많이 나오는가.
- DSR(kb:quant KR2): H1·H2 OOS 월 초과 샤프에 시도 N 217 로 deflated Sharpe 근사 병기.
- 복제 점검: H3·H4 창 시뮬은 무작위 표본 20건에서 `detail._simulate`(tail 250) 결과와 거래 수·rets 일치를 단언(불일치 시 결과 무효 표기).

### 판정 규칙 (결과 전 고정)
- H1·H2 가 KR 에서 F 또는 C(역방향) → 종목 상세 TREND SIMULATION 에 `표본 내 250일 성적 — 표본외 F(sim-oos)` 꼬리표 권고(개발 데스크 요청, 이 연구는 화면을 바꾸지 않음).
- H3·H4 가 F/검증전 → sim_signals 알림은 C·참고 유지(승격 없음). B 이상이어도 승격은 다음 결재.
- H5 가 F → '종목별 시뮬 성적으로 종목 고르기' 근거 없음.
- 결과가 나쁘면 그대로 F — 정의·분할·문턱은 이 커밋 뒤 바꾸지 않는다(바꾸면 새 id 재등록).

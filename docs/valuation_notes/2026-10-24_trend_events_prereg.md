## 0. 왜 (1줄)
10/24 탐색 레이어(reports/studies/2026-10-24_trend_discovery.md)에서 hi52·gcv·sqz 는 종목당 3년 거래 0~5회라 **종목별 Wilson·t 검정이 구조적으로 불가**했다. 이벤트형 전략은 종목을 합쳐 '신호가 난 날 산 종목이 같은 날 시장 중앙값보다 나은가'로 판정해야 한다.

**사전 노출(정직 고지):** 같은 날 탐색 레이어 합산 통계(2023~2026 3년·현재 구성 종목·전략 청산 규칙·종가 체결)에서 hi52 거래당 +5.1%(KR)/+4.1%(US), gcv +3.7%/+5.5%, sqz +0.9%/+1.0% 를 봤다. 2010~2019(IS) 는 본 적 없다. OOS(2020~2025) 중 2023~2025 는 본 기간과 겹친다 → 결과 해석 때 '부분 사후'로 적는다. 정의(아래 §1)는 그 레이어 코드 상수 그대로이고 이번에 바꾸지 않는다.

## 1. 사전 고정 규칙
| 항목 | 값 |
|---|---|
| 데이터 | `data/hist/{kr,us}_{2010..2025}.parquet` (git, 일봉 OHLCV, 파일 가격 그대로). KR 전 종목, US 는 파일에 있는 종목(현재 303 — 백필 요청 req-data-4e6e68fe, 늘면 재실행하되 이 문서 결과는 실행 시점 종목 수로 고정 보고) |
| 지표 | SMA20·SMA50(종가), 거래량 5·50일 평균, 밴드폭 bw = 4·σ20/SMA20 (모집단 σ) |
| hi52 진입 | 종가 > 직전 252일 최고 **종가** · 청산 상태 전환: 종가 < SMA50 |
| gcv 진입 | SMA20 이 SMA50 을 상향 교차(전일 ≤, 당일 >) 이고 거래량 5일 평균 ≥ 50일 평균 × 1.2 · 청산: SMA20 < SMA50 |
| sqz 진입 | 직전 5일 중 하루라도 bw ≤ 그날까지 직전 250일 bw 의 20번째 백분위(최소 120개, `pandas.rolling.quantile(0.2, interpolation='lower')`) 이고 종가 > 직전 20일 최고 **고가** · 청산: 종가 < SMA20 |
| 이벤트 | 상태 0→1 전환일 t (SMA50 있는 날부터). 같은 종목·같은 전략은 직전 '집계된' 이벤트 뒤 20거래일 안이면 제외(겹침 방지) |
| 유동성(이벤트일) | alpha_sources 와 같음: KR 20일 평균 거래대금 ≥ 10억원·종가 ≥ 1,000원 / US ≥ 2,000만 달러·≥ 5달러 |
| 데이터 오류 제외 | t−252 ~ t+21 안에 일간 |수익률| > 40% 가 있는 이벤트 제외(액면분할·병합 미보정 대비) |
| 체결·보유 | t+1 시가 진입 → t+21 종가 청산 (20거래일). 비용 왕복 0.25% 차감 |
| 기준선 | 같은 t 의 유동성 통과 전 종목 (t+1 시가 → t+21 종가) 수익률 **중앙값** |
| 초과 | ex = (r − 0.0025) − 중앙값 |
| 표본 단위 | 이벤트일이 속한 **달**: 달별 ex 평균 → 달 시계열의 평균·t = 평균 / (sd/√달수) |
| 분할 | IS = 이벤트일 2010-01-01 ~ 2019-12-31, OOS = 2020-01-01 ~ 2025-12-31 (데이터 끝 − 21거래일까지) |
| 가설 m = 6 | H_{hi52,gcv,sqz} × {KR, US}: OOS 달평균 ex > 0 |
| 문턱 | 단측 Bonferroni α = 0.05/6 = 0.0083 → **t ≥ 2.39** |

## 2. 등급 규칙 (kb:quant#4)
- **A** = B 조건 + IS t ≥ 2.39 + 2022 (하락장) 달평균 ex > 0.
- **B** = OOS 평균 > 0 · OOS t ≥ 2.39 · IS 평균 > 0 · OOS 달 ≥ 30.
- **C** = OOS 평균 > 0 · OOS t ≥ 1.645 (B 미달). 역방향(OOS 평균 < 0 · t ≤ −1.645)은 'C(역방향)' 별도 표기.
- **F** = 그 외.  **검증전** = OOS 달 < 30 또는 OOS 이벤트 < 100.

## 3. 보조(서술만, 등급에 안 씀)
보유 60거래일(t+61) 같은 정의 · 이벤트 중앙값 · 연도별 달평균 ex · 전략 청산 규칙대로 들고 있었을 때 평균(참고) · Holm 병기(kb:quant#29) · 주제 N 기준 α(N) 병기.

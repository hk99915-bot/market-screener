## 0. 질문
"직전 확정 분기 영업이익이 흑자이지만 전년 대비 줄었고(YoY ≤ 0) 주가는 60일선 위인 종목"을 매월 사서 60거래일 들고 있으면, 실적이 폭증한(YoY > +100%) 종목을 같은 방식으로 산 것보다 KOSPI 대비 더 버는가. 덧붙여 반도체 지수 필터(P2), 짧은 보유 대비 긴 보유(P3), 턴어라운드 예측 대용치(P1-T)와 오라클 상한(P1-O), 연기금 순매수 추종(L2)을 같은 틀로 본다.

## 1. 데이터와 범위 (결과 전 확인한 사실만)
- 재무: `data/fin/multi.parquet`·`full.parquet` (OpenDART 주요계정·전체재무제표) → `screener.fin.all_quarterly()` 단독 분기 영업이익(op)·매출(rev). **보유 범위 2020Q1~2026Q2** → YoY 첫 확정은 2021Q1(법정기한 2021-05-15) → **첫 신호 2021-06-01**. 요청 범위 2015-01~2025-09는 불가(DART 키 없음, 재수집 불가) — 가능한 최대 = 신호 2021-06 ~ 60거래일 수익이 끝나는 마지막 월(약 2026-07).
- 주가: `screener.prices.load_kr(hist_from=2020)` (data/hist kr_YYYY 상폐 포함 + kr_prices, 분할 보정).
- 지수: `data/hist/kr_index_daily.parquet` KOSPI 종가. 반도체: `data/hist` us_daily `^SOX` 종가.
- 시총: 과거 상장주식수 시계열이 없음 → **근사** 시총(t) = 기준 주식수 × 보정 종가(t). 기준 주식수 = `data/flows/kr_inv_*.parquet` 최초 관측일(2024-11-26~)의 mcap/close, 없으면 `universe/kr_shares.csv` out_total. 둘 다 없는 종목(2024-11 이전 상폐 등)은 표본 제외 → **생존 편향**(한계, 두 비교군에 똑같이 작용).
- 재무 표본도 현재 유니버스 기준 수집분이라 같은 생존 편향.
- 국면: `screener.regime_tag.classify(KOSPI 종가, 신호일까지)` — 상승/조정/하락. '하락장 조건부' = 조정+하락.
- 컨센서스(애널 예상치) 과거 이력: **창고에 없음**. DART 잠정실적 공시: `data/dart.parquet` 2026-10-12~16 5일분뿐 → 백테스트 불가. 그래서 P1-T는 아래 대용치 ②로 사전 지정.

## 2. 미래정보 누수 방지 (공시 지연)
- 분기 확정 시점 = 법정 제출기한 다음 날로 근사: 1Q → 5/16, 반기 → 8/15, 3Q → 11/15, 사업(4Q) → 다음 해 4/1. 신호일 t 에는 '확정 시점 ≤ t' 인 가장 최근 분기만 쓴다. (조기 제출 기업은 실제보다 늦게 반영 → 보수적.)
- 4Q 단독 = 연간 − 3Q 누적(`all_quarterly` 규칙 그대로).
- 진입 = 신호일 t(매월 첫 거래일)의 **다음 거래일(t+1) 종가**. 60일선·시총도 t 종가까지만.

## 3. 정의 (고정)
- 유니버스: 보통주(코드 끝자리 0), 근사 시총 ≥ 5,000억 원(t 종가), t 기준 60거래일 이상 시세, op 확정치 존재.
- YoY = (op_q − op_{q−4}) / |op_{q−4}| (op_{q−4} = 0 이면 제외).
- **P1 군**: op_q > 0 & YoY ≤ 0 & 종가(t) > 60일 단순이평(t).
- **고성장 군(비교)**: op_q > 0 & YoY > +1.00 & 종가(t) > 60일선. (같은 유니버스·같은 추세 조건, 실적 변수만 다름)
- **P1-T(실행 가능 턴어라운드 대용치 ②)**: P1 & op_q > op_{q−1}(직전 분기 대비 영업이익 개선) & 매출 YoY > 0 (rev_q > rev_{q−4}). 모두 확정 분기 숫자 → 실행 가능.
- **P1-O(오라클 상한 — 미래정보 사용·실행 불가)**: P1 & '다음 분기(q+1)' 확정 op YoY > 0. 신호일에는 모르는 숫자. 검정하지 않고 상한 서술만.
- **L2 연기금(같은 틀)**: t 일 `screener.accum` sig_pen(연기금 20일 순매수/시총 단면 상위 10%) 켜짐 & 같은 유니버스(보통주·시총 ≥ 5,000억, 시총은 flows 실측). flows 범위 2024-11-26~ → 첫 신호 2025-01 무렵.
- 포트: 신호일마다 군별 동일가중. 종목 순수익 = (t+1+h 종가 / t+1 종가 − 1) − 0.003(왕복). 기간 중 시세가 끊기면(상폐 등) 마지막 종가로 청산.
- 초과 = 포트 순수익 − 같은 창 KOSPI 수익. 코호트(월) 1개 = 관측 1개.
- 보유 h: 주 60거래일. P3 용 1·3·10거래일.

## 4. 검정 (m = 6, 양측 α = 0.05/6 = 0.00833)
| id | 귀무 | 통계 |

| T1 (P1 핵심) | 월 코호트 [P1 60일 초과 − 고성장 60일 초과] 평균 = 0 | 평균 / Newey-West SE(지연 2, 60일 창이 월 코호트 3개와 겹침) |

## 5. 등급 규칙 (kb:quant#4)
- 최소 표본: 코호트 월 ≥ 12 이고 종목-이벤트 ≥ 100 (T3 은 두 그룹 각 ≥ 8개월). 미달 → **검증전**.
- IS = 신호일 < **2024-01-01**, OOS = 이후. (요청 분할점 2021-01 은 데이터 시작 2021-06 이전이라 불가 — 양쪽 코호트 각 ≥ 24개월이 되도록 2024-01 로 고정.)
- **A** = p < α & IS·OOS·하락장(조정+하락 신호월) 평균 부호가 전체와 같음. **B** = p < α (하위 구간 일부 미확인/불일치). **C** = 보정 전 p < 0.10(방향만). **F** = 그 밖. 음(−) 방향 유의는 'C(역방향)'/'B(역방향)'.
- T6(L2)은 IS 구간이 없어(2025~) **상한 B**.
- 결과가 유의해도 출처가 사후 사례 분석이고 표본이 2021~2026 한 장세(반도체 강세 포함)임을 보고서에 적는다(kb:quant#18).

## 0. 왜 (1줄)
지금 VaR 엔진은 '역사적 250일'과 'EWMA(λ 0.94)' 중 큰 값을 쓴다(FRM 엔진 정의 — `docs/desk_kb/rounds/2026-10-28/frm_posrisk_peer.md` 15행 · 공개 계기판은 60일 σ × 2.326, `screener/defs.py` 38~39행). 급락 직후 며칠 동안 VaR 가 손실을 얼마나 못 따라가는지, GARCH(1,1)·GJR-GARCH(하락 때 변동성이 더 뛰는 비대칭 모형)로 바꾸면 그 폭이 통계적으로 줄어드는지 본다.

**사전 노출(정직 고지):** 이 데이터로 어떤 모형의 초과일·손실 함수도 계산한 적 없다(데이터 파일의 열·날짜 범위만 확인). 일반 문헌 지식('정규 가정 GARCH 는 99% 꼬리를 과소 추정하는 경향', 'GJR 이 주식 지수에서 GARCH 보다 약간 낫다')은 알고 있다 — 그래서 문턱을 아래처럼 먼저 고정한다.

## 2. 등급 규칙 (kb:quant#4, 가설별 — '무엇 대비'는 가설 이름에 있음)
- **A** = B 조건 + IS 에서 같은 부호(mean d < 0) + 지수 4개 중 3개 이상에서 OOS mean d < 0.
- **B** = PORT OOS mean d < 0 · 양측 p < 0.0125 · OOS 예측일 ≥ 1000.
- **C** = PORT OOS mean d < 0 · 양측 p < 0.10 (B 미달). 역방향(mean d > 0 · p < 0.10)은 'C(역방향)'.
- **F** = 그 외. **검증전** = OOS 예측일 < 1000.

## 3. '엔진 교체 제안' 문턱 (채택선 — 전부 충족해야 제안, 하나라도 빠지면 '현행 유지')
후보(GARCH-N 또는 GJR-N)가 PORT OOS 에서:
1. ENGINE 대비 tick loss 가설 등급 **B 이상**(GJR 은 H4. GARCH 는 같은 정의로 ENGINE 대비를 보조 계산하되 m 밖이라 상한 C → GARCH 단독으로는 제안 불가, GJR 과 함께만 서술).
2. Kupiec POF p ≥ 0.05 **그리고** Christoffersen 독립성 p ≥ 0.05.
3. OOS 250일 이동 창 중 '적' 비율이 ENGINE 이하.
4. 급락 구간 4개 합산 초과분 합이 ENGINE 이하.
- 2~4 는 충족하지만 1 이 C 면 = '교체 근거 부족 · 계기판 병기 후보'(제안 아님).
- ENGINE 자체가 Kupiec 을 기각당해도(과소 또는 과대) 후보가 1~4 를 못 넘으면 결론은 '현행 유지 + 엔진 한계 보고'.

## 4. 보조(서술만, 등급에 안 씀 · 사후 해석 상한 C)
- S1·S2: GARCH-t · GJR-t(표준화 Student-t, 자유도 ν MLE, ν>2.05) — 분포 가정이 원인인지 가르는 용도. 분위수 = t_ν 분위수 × √((ν−2)/ν), ES 는 t 분포 닫힌 식.
- 지수 4개 각각의 같은 표 · Holm 병기(kb:quant#29) · 97.5% 초과일 Kupiec · 연도별 초과 수 · 추정 모수 중앙값(α·β·γ·지속성).
- 시도 N: 등록 m 4 + 보조 2(S1·S2) — trial_log.json 에 기록.

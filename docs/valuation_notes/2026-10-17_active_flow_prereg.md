# 사전등록: 여러 액티브 ETF 가 동시에 '실질 증가'한 종목은 다음 20/60거래일 초과수익을 내나 (2026-10-17, 데이터 데스크)

등급: **검증전** (데이터 0일 — 수집기만 있음) · 매매 지시 아님 · 비율만 · 이 문서는 결과를 보기 전에 가설·표본·채점을 고정한다.
수집기: `screener/active_funds.py` → `reports/active_funds.json` (KRX PDF 1CU 당 주식 수 기준). 대상 18개(순수 주식 액티브 15 + 커버드콜 3), 명단은 코드 `TARGETS`.

## 1. 가설
- **H1 (주)**: 신호일 t 에 직전 5거래일 창에서 **서로 다른 운용사** 액티브 ETF 2곳 이상이 같은 종목을 실질 매수(신규 편입 또는 1CU 당 주식 수 +5% 이상)하고, 실질 매도한 곳이 없으면(net ≥ 2), 그 종목의 t+1 시가 → t+20 / t+60 종가 수익률이 벤치마크를 이긴다.
- **H0**: 초과수익 평균 = 0.
- 벤치마크: 종목 시장별 지수(코스피 종목 → KOSPI, 코스닥 → KOSDAQ). 보조: 같은 날 우리 유니버스 동일 시총 5분위 평균.
- 왜 '운용사 수'인가: 같은 운용사 ETF 여러 개는 한 사람의 판단이라 독립 신호가 아니다(삼성액티브 3개가 같은 날 사면 1표).

## 2. 표본·제외
- 신호일: 수집 시작일부터 **최소 120거래일**(약 2027-04) 쌓인 뒤 1차 채점. 그 전엔 숫자를 보더라도 결론 금지.
- 제외: 분할 의심(`split_suspect`) · 시범 편입(비중 0.2% 미만) · 코스피200 정기변경 발표~시행 사이 편입종목(지수 추종 매수) · 커버드콜 3종은 주 분석에서 빼고 민감도로만 · 거래정지·관리종목.
- 겹침: 같은 종목이 20일 안에 다시 신호면 첫 신호만(중복 표본 방지).
- 최소 표본: 독립 신호 **30건** 미만이면 '판정 불가'로 끝낸다.

## 3. 채점 기준 (미리 고정)
| 판정 | 조건 (20일·60일 둘 다 본다, 주 지표 = 60일) |
|---|---|
| 채택(B 등급) | 60일 평균 초과수익 > 0, Newey-West t ≥ 2, 적중률(초과>0) ≥ 55%, 상위·하위 절반 기간 둘 다 같은 부호 |
| 약한 근거(C) | 평균 > 0 이고 t ∈ [1, 2) |
| 기각 | t < 1 또는 평균 ≤ 0 |
| 반대 신호 점검 | net ≤ −2 (동시 매도) 종목의 60일 초과수익 < 0 이면 대칭성 보강 근거 |
- 비용: 왕복 0.3% 차감 후 수치를 본 표에 쓴다 [가정: 거래세+수수료+슬리피지].
- 다중검정: 창(20/60) × 임계(net≥2/≥3) 4개 조합 → 본 판정은 60일·net≥2 하나만. 나머지는 참고.

## 4. 알려진 함정 (KB data.md '흔한 오해' 참조)
- 비중 증가 ≠ 매수 (자금 유입 비례 매수·주가 상승). 이 연구는 1CU 당 **주식 수**만 쓴다.
- 상관 0.7 요건 → 대부분의 변화는 지수 근처 미세 조정. 신호가 대형주(삼성전자·하이닉스)로 쏠리면 시총 5분위 보조 벤치마크로 다시 본다.
- PDF 는 T일 장 마감 뒤 T+1 기준으로 공시되는 관행 → 수익률은 **신호 확인 다음 날 시가**부터(미래 정보 누수 방지). [확인 필요: KRX PDF 기준일과 실제 매매일의 1일 차이]
- 생존 편향: 상관 요건으로 상폐된 ETF 의 과거 PDF 는 없다 → 명단은 수집 시작 시점 고정, 상폐 ETF 는 상폐일까지 표본 유지.

## 5. 산출·일정

- 결과 기록: `reports/studies/` + `_scoreboard.md` 연구 등급.

# 규칙 용어집 (rules terms) — 코드와 문서가 같은 말을 쓰기 위한 한 장

> 왜 있나 (2026-10-16): "테마 합계 ≤ 전체 투자자산의 40%"라는 비중 규칙이 **분모를 정의하지 않은 채** 집행됐다. 같은 포지션이 분모 선택에 따라 세 가지 비율로 읽혔고, 한도 위반 여부 자체가 분모에 달려 있었다.
> 원칙: **모든 비율·한도·기한 규칙은 분모·기준일·데이터 출처를 같은 줄에 적는다. 규칙을 신설·개정하기 전에 이 용어집에 용어가 먼저 등록돼야 한다(definition-first).** 코드 쪽 강제는 `scripts/check_rules_terms.py` (한도 비율 계산 줄에 `denominator=` 라벨 필수 + 규칙 상수는 **`screener/defs.py` 단일 원천** — 규칙 파일의 숫자 재정의·화면 상수 불일치·용어표 미등록을 잡는다, 2026-10-17).
> 공개 문서 — 금액·보유 수량 없음. 비공개 저장소의 같은 표(금액 포함)가 원본이며, 여기엔 일반 정의와 코드 위치만 둔다.

## 2. 새 규칙을 넣을 때 (체크리스트)

1. 용어가 이 표에 있는가. 없으면 **먼저 행을 추가**한다 (분모 코드 D1~D5, 기준일, 출처, 계산 코드).
2. 규칙 문장에 분모·기준일·출처가 같은 줄에 있는가. 예: "테마 합계 ≤ 전체 투자자산(D2, 종가)의 40%".
3. 코드에서 그 비율을 계산하는 줄에 `# denominator=D2 …` 라벨이 있는가 → `python scripts/check_rules_terms.py`.
4. 알림·성적표가 **같은 분모**로 같은 값을 보여주는가 (아침 점검 = MY 탭 = 성적표).

- 새 창작 성격·관계·MBTI가 기존 창작 태그와 충돌하면 이 설정집의 2026-10-25 버전을 우선한다.

- MBTI는 심리 진단이 아니며 직업 능력·인간 가치·궁합을 결정하지 않는다.
- 상극·마찰·공유 사건은 전부 창작. 실제 에이전트가 했던 일처럼 말하지 않는다.

## 연속성
- PB는 은근히 기존쎄, HF는 관계적 거절에 상처받으면 더 정중하고 조용해지는 설정이 중심.
- '업무에서 반대하지만 사적으로 편함'과 '업무도 불편하고 사적 접촉을 피함'을 구별한다.
- 모든 인물을 다정한 절친으로 회수하지 않고, 모든 인물에게 반전 매력을 강요하지 않는다.
- 본부별 인원: 창구 1, 투자전략 5, 리서치 4, 헤지펀드 1, 리스크 4, 운영 7, 교육 2, 생활 2, 검증실 3 = 29.
- 감사는 검증실 소속 캐릭터 분류를 유지하면서 공간은 별도 업무실로 둔다.

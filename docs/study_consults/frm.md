# 자문 질의서 — 리스크 데스크 (consult:frm)

> 교육 → 리스크(FRM). 답변은 `answers/frm.md`. 대상 모듈: **R1 변동성과 손실 회복 공식 · R2 VaR·ES('계기판 vs 한도') · R3 스트레스 테스트 · R4 베타·상관(같은 테마 = 한 포지션) · R5 비중 밴드·글라이드 패스 · R6 리스크 예산과 포지션 사이징**.
> 참고 자료(리스크 소유): `reports/studies/semis_cap.md`, `rule_audit.md`, 리스크 데스크 내부 감사 메모(개념만 — **금액·보유 내역은 답변에 절대 쓰지 않는다**, % 와 가상 숫자만).

## (a) 학습자 프로필
`README.md` 공통 프로필. 추가로: −58% 경험 뒤 "원금 회복에 +138%가 필요하다"는 산수를 **아직 해 본 적 없다**. 지금 규칙(노출 한도·손절 −8%·테마 한도·VaR 경보)을 따르지만 VaR·ES·베타가 무엇인지 모른다. 한 테마(반도체)에 쏠린 포트폴리오를 '분산'이라 착각한 경험이 있다.

## (b) 교육 목표
1. 손실 회복 공식(1/(1−L)−1)을 손으로 계산하고, 변동성이 왜 '복리의 적'인지(변동성 끌림) 말할 수 있다.
2. VaR·ES를 계기판(경보)으로 읽고, 한도(강제 행동)와 구분한다. 2.33σ·97.5% 꼬리평균을 쉬운 숫자로 계산한다.
3. 과거 사건 재생(2020-03, 2024-08, 2026-03) 스트레스의 뜻과 "VaR보다 스트레스가 한도의 근거"인 이유를 안다.
4. 베타·상관으로 "같은 테마 종목 5개 = 포지션 1개"임을 숫자로 확인한다.
5. 밴드(목표/발동/하단)·글라이드 패스(적립으로 희석)와 현금흐름 리밸런싱 식 w' = w(1+r)/(1+w·r)… 를 계산할 수 있고, 1회 리스크 ÷ 손절폭 = 수량 공식을 쓴다.

## (c) 질문
- **q1.** 리스크를 처음 배우는 사람이 가장 먼저 알아야 할 한 가지는? (예: "손실은 비대칭이다" 또는 "포지션 크기가 곧 리스크") 생활 비유 하나.
- **q2.** 손실 회복 공식과 변동성 끌림: −58% → +138% 외에 −10/−20/−50 표 하나. 산술평균 vs 기하평균 차이를 쉬운 숫자(+50%, −50%)로.
- **q3.** 파라메트릭 VaR99 = 2.326σ, ES97.5 = 2.338σ(정규 가정)의 현업 공식 vs 교과서. 역사적 VaR과의 차이, 초과일 백테스트(기대 1%)로 모형을 검증하는 방법을 초보 수준으로.
- **q4.** 'VaR는 경보만, 강제 매도 없음'이 관행으로 괜찮은가? **계기판 vs 한도**를 가르칠 때 쓸 ≤120자 정의와 가상 예시(일 σ 2% 포트에서 VaR99 ≈ 4.7%).
- **q5.** 스트레스 테스트(과거 사건 재생): 사건 선택 기준, 왜 "VaR가 아니라 스트레스에서 방어 가능한 비중이 나온다"고 하는지, 쉬운 숫자 예시(−15% 충격 × 비중 40% = −6%).
- **q6.** 베타·상관: 같은 테마 종목들의 상관이 0.7~0.9일 때 '분산 효과'가 거의 없다는 것을 2종목 분산 공식으로 보여주면(σ_p² = w²σ² … ρ 포함, 쉬운 숫자). 성분 VaR 개념을 초보에게 말해야 하나?
- **q7.** 밴드(목표 40 / 발동 45 / 하단 30)·글라이드 패스·하드캡 — semis_cap 결과(BAND 매도 10회 vs CAP40M 58회, 수익·MDD 거의 같음)를 초보에게 어떻게 읽게 하나? "밴드는 회전을 줄이는 장치이지 수익 장치가 아니다"가 맞는 요약인가?
- **q8.** 현금흐름 리밸런싱(적립으로 희석) 공식: 새 비중 = w·(1+r) / (1 + c + w·r) 형태가 맞나? 기호 정의와 쉬운 숫자(w 40%, 월 적립 c 2%, 수익률 0)로 "몇 달 뒤 35%"가 되는 계산을 보여주면.
- **q9.** 리스크 예산·포지션 사이징: 1회 리스크(순자산의 1%) ÷ 손절폭(8%) = 비중 12.5% 공식과, ATR 기반 손절(max(20일 저점, 종가−2×ATR))과의 관계. 손절폭 15% 초과 종목 제외 규칙의 근거.
- **q10.** 초보가 가장 자주 하는 오해 3가지(예: "VaR가 최대 손실", "분산 = 종목 수", "손절 −8%는 종목마다 같아야") + 교정법.
- **q11.** 오늘 터미널에서 이 개념이 보이는 자리(탭·필드: 레짐, 노출 한도, 운용회의 `hedges`·`asymmetry`, 종목 `atr_stop`, 테마 비중)와 하루 1분 체크 순서.
- **q12.** 잘못 배웠을 때 손실로 이어지는 경로 2개(예: VaR 한도를 과소 추정 → 하락장에 과노출 / 손절폭 무시한 균등 비중 → 고변동주에 리스크 집중)와 확인문제 함정 포인트 3개.

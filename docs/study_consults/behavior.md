# 자문 질의서 — PB·행동 데스크 (consult:behavior)

> 교육 → PB(행동재무). 답변은 `answers/behavior.md`. 대상 모듈: **H1 처분효과 · H2 보상 직후 위험추구·틸트 · H3 작위/부작위 후회와 기댓값 · H4 앵커링(매입가) · H5 '규칙을 바꿔 위반을 없애기' 함정 · H6 결정 피로와 22시 이후 결정 금지**. 기존 A6(행동재무 개요)과 중복되지 않게 '사례 → 교정 장치' 중심.
> 참고 자료(PB 소유): PB 내부 규칙 제안 메모(개념만), `reports/studies/rule_audit.md`(규칙 변경 이력), 운용 규칙 문서(파라미터만 일반화).

## (a) 학습자 프로필
`README.md` 공통 프로필. 추가로: −58%의 상당 부분이 **행동 오류**(이익 종목 조기 매도·손실 종목 보유, 큰 보상 뒤 베팅 확대, 밤늦은 결정, 손절선을 사후에 옮김)에서 왔다고 스스로 인정한다. 익명화된 비율 사례(1년 −58% vs 코스피 +43%)는 교재에 써도 된다. **금액·종목·날짜별 거래는 쓰지 않는다.**

## (b) 교육 목표
1. 각 편향을 '자기 사례 한 줄(비율만) → 이름 → 메커니즘 → 교정 장치(규칙·체크리스트)'로 연결해 말할 수 있다.
2. 처분효과를 기댓값으로 반박하고(손실 종목을 들고 있는 것은 '새로 사는 것'과 같다), 작위/부작위 후회의 비대칭을 안다.
3. 매입가 앵커를 버리고 "지금 가격에서의 기대"로 판단하는 질문 문장을 외운다.
4. "규칙을 바꿔 위반을 없애는" 함정을 알아채는 기준(변경 전 사전등록·냉각기간)을 안다.
5. 결정 피로·시간대 규칙(22시 이후 결정 금지, 반등일 매도 대기 등)의 근거와 예외를 안다.

## (c) 질문
- **q1.** 행동재무를 처음 배우는 사람이 가장 먼저 알아야 할 한 가지는? (예: "편향은 지식으로 안 고쳐진다, 장치로 고친다")
- **q2.** 처분효과: 정의 ≤120자, 초보용 숫자 예시(+10% 종목 매도 / −30% 종목 보유의 기댓값 비교), 교정 장치(손절 규칙·'오늘 새로 산다면?' 질문).
- **q3.** 보상 직후 위험추구(하우스머니)·틸트: 메커니즘, 현업에서 쓰는 장치(큰 수익/손실 뒤 24시간 쿨다운, 사이즈 상한), 쉬운 예시.
- **q4.** 작위 vs 부작위 후회: 왜 '안 샀는데 올랐다'보다 '샀는데 떨어졌다'를 더 아프게 느끼고, 그 비대칭이 매매에 어떻게 비용이 되나? 기댓값으로 바꾸는 연습 문제 하나.
- **q5.** 앵커링(매입가): "본전 오면 판다"가 왜 규칙이 아닌지, 교정 질문 문장(예: "지금 현금이라면 이 가격에 사겠는가?"), 반증 사례 하나(비율만).
- **q6.** '규칙을 바꿔 위반을 없애기' 함정: 실제 규칙 변경 이력에서 **개념만** 뽑아(예: 손절 −8%→−12%로 완화 요구, 한도 40→45) 초보에게 보여줄 패턴과, 정당한 규칙 변경(사전등록·검증 결과 기반)과 구분하는 기준 3가지.
- **q7.** 결정 피로·시간대: '22시 이후 결정 금지'·'시초가 매수 금지'·'반등일 매도'의 근거(생리·시장 미시구조)와 예외. 초보용 하루 결정 창 설계(예: 15:00 한 번).
- **q8.** 초보가 가장 자주 하는 오해 3가지(예: "손절은 손실 확정이라 나쁘다", "평단 낮추기 = 분할매수", "규칙은 상황 따라 유연해야") + 교정법.
- **q9.** 오늘 터미널에서 이 개념이 보이는 자리(예: 종목 상세의 손절선·'매입가 기준' 표시 없음, 운용회의 프리모템, 규칙 위반 로그가 있다면 어디)와 읽는 법.
- **q10.** −58% vs +43% 사례를 교재에서 쓸 때의 **톤**: 자책 유도 없이 '데이터'로 다루는 서술 지침 3줄. 쓰면 안 되는 표현은?
- **q11.** 확인문제로 낼 만한 함정 포인트 3개(예: 처분효과와 손절 규칙을 혼동, 앵커링을 '기준가'로 정당화).
- **q12.** 잘못 배웠을 때 손실로 이어지는 경로 하나(예: "편향을 안다"는 자신감 → 장치 없이 재량 매매).

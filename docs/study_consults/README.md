## 공통 — 학습자 프로필 (모든 질의서 동일)
- 경영·경제 전공 **신입생**. 미적분·통계는 고교 수준, 금융 용어는 뉴스에서 들은 정도.
- **1년 매매 경험: 포트폴리오 −58%, 같은 기간 코스피 +43%** (익명화된 비율만 사용. 금액·종목·보유 내역은 어디에도 쓰지 않는다).
- 지금은 **하락장에서 규칙 기반 운용** 중(레짐 판정 → 노출 한도 → 손절·사이징 규칙). 규칙은 이해하지 못한 채 따르는 상태에 가깝다.
- 학습 방식: 모듈당 20~40분. 순서는 **생활 비유 → 용어 → 핵심 개념 → 공식(쉬운 숫자 예시) → 오늘 터미널에서 → 흔한 실수 → 확인문제**.
- 목표 자격: 투운사·금투분·TESAT, 장기적으로 CFA L1.

## 공통 — 답변 형식 (각 데스크는 `answers/<desk>.md`에 이 형식으로)
```
## q<n>. <질문 제목 그대로>
- 핵심(≤120자): …
- 예시 1: … (쉬운 숫자. 금액이 필요하면 100, 1,000 같은 가상 숫자만)
- 출처: reports/studies/<id> | 교과서(저자·장) | 현업 관행(근거 한 줄)
- (선택) 함정/확인문제 아이디어: …
```
- 공개 저장소: 개인 금액·보유·거래 내역 금지. 비율·배수·가상 숫자만.
- 모르면 "모름/검증전"이라고 쓴다. 추정은 '추정'이라 표시한다.
- 답변 id는 `consult:<desk>#q<n>`로 인용되므로 질문 번호를 바꾸지 않는다.

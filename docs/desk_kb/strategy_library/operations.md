### OP-01 멀티매니저 팟 구조 · 손실 한도 · 자본 회수
- **메커니즘:** 독립 팟에 자본 배분, 중앙 리스크가 팟별 손실 한도 집행: 경고 → 자본 절반 → 퇴출.
- **근거:** 언론 종합 — 배정 자본 5% 손실 시 절반, 약 7.5% 누적 손실 시 퇴출이 통상 보도(출처 간 5/7.5/10% 상이, 회사 1차 문서 아님) [2차] https://www.efinancialcareers.com/news/pratik-madhvani-glen-scheinberg · 다른 대형사 한도 미확인.
- **쇠퇴/최근(우리 팀):** 부분 기존 — hf.md 북 손실 한도(고점 대비 −3% 신규 금지, −5% 전량정리·14일 정지, 5거래일 −2%). 갭: 다른 모의 북엔 공통 사다리 없음, 팟 간 공통 팩터 합산 감시 없음.
- **비용·용량:** 팟 간 상관(공통 팩터 쏠림), 비용 이중 부담.
- **실패 국면:** 손절 강제 → 단기화, 한도 근처 위험 회피 왜곡.
- **한국 적용성:** 해당 없음(조직 규약).
- **필요 데이터:** 모의 북별 일별 NAV·고점.
- **실계좌 적합성:** [롱온리] 실계좌는 '전략 슬리브' 단위로 해석. 주 용도는 모의 북 규약.
- **연구소 가설:** 규약 제안 → 아래 README '우리 팀에 없는 규약' ③.

- **비용·용량:** 축소 후 반등 놓침.
- **실패 국면:** 휩쏘; 한도 값 임의.
- **한국 적용성:** 해당 없음.
- **필요 데이터:** NAV·고점·변동성.
- **실계좌 적합성:** [롱온리]
- **연구소 가설:** "낙폭 −3%/−5% 단계 축소 규칙 vs 무규칙의 모의 북 사건 재생 비교" · 방향: 해당 없음 · horizon: 이벤트.

### OP-03 포지션 사이징 (켈리·분수 켈리·변동성 패리티)
- **메커니즘:** 켈리 f* = μ/σ²(로그 성장 최대). 실무는 1/2~1/4 켈리. 변동성 패리티 = 비중 ∝ 1/σ̂.
- **근거:** Kelly (1956, BSTJ 35(4):917–926) [기억] · MacLean-Thorp-Ziemba (2010, Quant. Finance) [기억] · Moreira & Muir (2017, JF 72(4):1611–1644) [기억] · Barroso & Santa-Clara (2015, JFE 116(1)) [기억]. 실증 수치는 MD-06.
- **쇠퇴/최근(우리 팀):** 기존 있음 — frm.md #3(변동성 끌림·Kelly g(f))·#16. 갭: 'μ 를 사전등록 하한값으로 쓴 분수 켈리 상한' 한 줄 없음.
- **비용·용량:** μ 추정오차 → 풀 켈리 과대비중.
- **실패 국면:** 급락 시 변동성 추정 지연.
- **한국 적용성:** 해당 없음.
- **필요 데이터:** 기대수익 하한(사전등록), 변동성.
- **실계좌 적합성:** [롱온리] 1/4 켈리 이하 + 상한 병행.
- **연구소 가설:** "1/4 켈리(μ 하한) vs 역변동성 사이징의 모의 북 낙폭·성장률 비교" · 방향: 해당 없음 · horizon: 3년+ 재생.

### OP-04 포트폴리오 구성 (평균분산 한계·BL·HRP·1/N)
- **메커니즘:** 평균분산은 추정오차 증폭기. 대안: 1/N·역변동성, Black-Litterman, HRP.

- **쇠퇴/최근(우리 팀):** 거의 없음 — allocation.md 는 정책 비중·밴드(Brinson 1986)만.
- **비용·용량:** 해당 없음.
- **실패 국면:** 위기 시 상관 → 1, BL τ 임의성, HRP 우위 불확정.
- **한국 적용성:** 해당 없음.
- **필요 데이터:** 자산 수익률·공분산.
- **실계좌 적합성:** [롱온리] 1/N·역변동성은 ISA 리밸런싱에 직접 적용 가능(자산배분 판정 필요).
- **연구소 가설:** 규약 제안 → README '우리 팀에 없는 규약' ②.

### OP-06 실행 비용 · 슬리피지
- **메커니즘:** 비용 = 스프레드 + 충격 + 수수료·세금; 순수익 = 총수익 − 비용 × 회전율.
- **근거:** Frazzini-Israel-Moskowitz (2018, SSRN) AQR 실거래 21개 시장·19년, 실비용이 학술 추정보다 한 자릿수 작음(대형 기관 기준) [확인] https://papers.ssrn.com/abstract=3229719
- **쇠퇴/최근(우리 팀):** 기존 있음 — hf.md 왕복 KR 0.45%·US 0.20%. 갭: 전략별 '비용 2배 시 부호' 감수성 표준 첨부, 소형주 비용 별도.
- **비용·용량:** 개인은 스프레드가 지배.
- **실패 국면:** 기관 결과를 소형주·개인에 이식.
- **한국 적용성:** 거래세·세제 별도.
- **필요 데이터:** 호가 스프레드, 거래대금.
- **실계좌 적합성:** 필수.
- **연구소 가설:** 모든 사전등록에 '비용 2배 감수성' 칸 추가 제안(퀀트 판정).

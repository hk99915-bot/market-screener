# 전략 라이브러리 (헤지펀드·자산운용 전략 공통 베이스)

11/3 겸이 「헤지펀드·자산운용 전략들 논문·실무 싹 다 긁어모아서 HF 누나 및 모든 누나들 공통 베이스로」. 리서치 3건(2026-11-03 웹검색) → 교육 데스크가 합치고 중복을 정리하고 확인 수준을 표시했다(새 리서치 없음).
**이 디렉터리는 지식이다. 규칙·한도·매매 판단이 아니다.** 여기 있는 수치를 인용할 때는 확인 태그를 같이 쓴다(STANDARD 1절). 일반 지식 문서라 개인 금액·보유는 없다.

## 우리 팀에 없는 운용 규약 3개 — **결재 필요 — 결재 카드(STANDARD 10절)로 상정**
이 절은 제안의 요지만 적는다. 효력 없음. 상정 시 ⑤ 피어 반대 3줄이 없으면 상정 보류.
1. **전략 은퇴 조건 사전등록 (OP-10)** — 지금은 들이는 규칙(등급)만 있고 내리는 규칙이 없다. 등급 부여 때 kill 조건(OOS 롤링 t, 비용 후 기대값 < 0 지속 기간, 출판 후 감쇠 반영)을 같이 등록. 근거: McLean-Pontiff(공통 근거).
2. **포트 구성 기본값 = 1/N·역변동성 (OP-04)** — 최적화는 '1/N 을 OOS 로 이겼음'을 사전등록으로 입증했을 때만. 근거: DeMiguel 외 2009 [기억], Michaud 1989 [기억].
3. **모의 북 공통 3단 손실 사다리 (OP-01·OP-02·OP-07)** — 경고 → 절반 → 정지를 hf 북뿐 아니라 모든 모의 북에 통일 + 정지 해제(재진입) 조건 + 결정 확률의 사후 Brier 집계. 근거: 멀티매니저 관행 [2차], 수치는 출처 간 상이.

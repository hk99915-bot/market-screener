## 정의

- **TTM (Trailing Twelve Months)**: 최근 4개 분기 손익의 합. 연간 보고서보다 최신이지만, 분기 4개가 없으면 연환산(×4/n)이라 `검증전`으로 표기한다. 터미널: RESEARCH › 밸류에이션 (reports/valuation.json). `[교과서]`
- **PEG**: PER ÷ (EPS 성장률 %). 1 안팎을 '성장 대비 적정'으로 읽지만 성장률이 사이클 고점이면 분모가 부풀어 PEG 가 낮아 보인다(아래 함정 참조). 바스켓 추적에는 아직 넣지 않음 — 성장률 추정치(컨센서스)를 수집하지 않아서. `[교과서]`
- **E/P − rf (금리조정 매력)**: 이익수익률(TTM EPS ÷ 주가) − 무위험금리(US 미 10Y, KR 국고 3Y). Fed 모델 계열의 '주식 대 채권' 상대 매력. 양수면 채권 대비 이익수익률이 높다는 뜻이지 저평가 확정이 아니다(이익이 꺾이면 분자가 사라짐). `[교과서]` `[자체연구-검증전]`
- **멀티플/EPS 분해**: ln(P₁/P₀) = ln(PER₁/PER₀) + ln(EPS₁/EPS₀). 로그수익률이라 세 항이 정확히 더해진다. '주가가 빠졌다'를 '배수가 눌렸다(심리·금리)' 와 '이익이 깎였다(펀더멘털)' 로 가른다. 20일 전 EPS 는 archive/valuation 의 과거 산출물에서 — 기록이 20일 쌓이기 전에는 EPS 변화 0 가정(`검증전`). `[교과서]`
- **사이클 정점 ROE 함정**: 메모리처럼 이익이 사이클을 타는 업종은 고점에서 ROE·EPS 가 최대라 PER 이 가장 낮아 보인다(10/16 기준 SK하이닉스 TTM ROE 60%대·PER 한 자릿수). 낮은 PER = 싸다 가 아니라 '시장이 이익 꺾임을 반영 중' 일 수 있다. 정상화 ROE(사이클 평균)로 다시 계산한 값과 같이 봐야 한다 — screener/valuation.py 의 `정상화` 묶음. `[교과서]` `[경험]`

## 공식

- 금리 민감도(ERP·성장률 고정): E/P = rf + ERP − g → Δ(E/P) = Δrf → PER′ = 1/(1/PER + Δrf), ΔPER/PER = −PER·Δrf/(1 + PER·Δrf). 쉬운 숫자: PER 20(E/P 5%)에 +25bp → E/P 5.25% → PER 19.05(−4.8%). PER 40 이면 −9.1% — 배수가 높을수록 금리에 더 민감. `[교과서]`
- 순현금 근사 = 현금 − 총부채 (차입금 항목을 아직 수집하지 않아 보수적). EV/EBITDA 는 감가상각(da)이 있을 때만 계산, 없으면 생략하고 플래그. `[자체연구-검증전]`

## 현업 vs 교과서

- **PER 의 분모 세 가지** (10/17 메모리 노트): 교과서는 TTM 또는 선행(forward) EPS 둘을 말하지만, 현업 사이클 분석은 (a) TTM, (b) 런레이트(최근 분기×4), (c) 가이던스×4, (d) 사이클 정규화(과거 10년 평균 순이익률×현재 매출) 를 **나란히** 놓고 "어느 분모를 믿느냐에 따라 X~Y" 로 답한다. 한 숫자로 답하면 분모 선택을 숨기는 것. 코드: valuation_daily.run_rate / guidance_per, 입력 universe/fin_guidance.json. 노트: docs/valuation_notes/2026-10-17_memory.md `[교과서]` `[자체연구-검증전]`
- **가이던스 EPS 와 GAAP TTM 을 섞지 않는다**: SNDK 처럼 non-GAAP EPS 가이던스를 주는 회사는 분자 정의가 다르다. 대신 '가이던스 EPS×주식 수 vs 최근 분기 GAAP 순이익' 비교가 회사가 말한 이익률 방향(SNDK: 77%→약 62%) 을 드러낸다 — 사이클 신호로 더 유용. `[경험]`
- **PBR = PER × ROE 항등식**: PBR 하나가 '어떤 ROE 를 전제하는가' 로 읽힌다. 메모리 4종 모두 정규화 ROE 11~18% 로 수렴 → 현재 PBR(2.5~12) 은 고점 ROE(26~73%) 와만 짝이 맞는다. `[교과서]`

- **US 가정(COE·g·ERP)과 KR 차이** (10/17, screener/valuation.py `us_all`): KR 은 COE 9%(무위험 3%+프리미엄 6%)·g 2% 고정. US 는 COE = 미 10Y(reports/live.json, 10/15 5.10%) + ERP 5.0% `[가정]` = 10.1%, 베타 1 가정, g 2.5% `[가정]`, 일회성 보정 세율 21%(연방). ERP 근거: Damodaran 2026-01 implied 4.23%(BVR 2차 인용, 원문 미확인 `[확인 필요: 스턴 사이트 histimpl, 다음 라운드]`) → 5.0% 는 0.8%p 보수 쪽. 차이의 뜻: US COE 가 금리 연동이라 미 10Y +25bp 면 RIM·PBR-ROE 적정가가 내려간다(KR 은 고정이라 안 움직임). 금융업 = us_sector.csv '금융'(결제 V·MA 포함) → DCF 제외. 단위 USD 그대로, `currency:'USD'`. `[교과서]` `[자체연구-검증전]`
- **6모델은 독립 확인이 아니다**: 상대 PER·PBR-ROE·RIM·DCF 는 모두 '최근 TTM 이익(ROE) 지속'이라는 같은 전제 → 네 모델이 비슷한 값을 내도 확신이 4배가 되는 게 아니다. 반대 전제는 '정상화' 묶음과 `cycle_view`(사이클 업종: 최근 이익률 지속 PER vs 장기 평균 순이익률×현재 매출 PER). US flags 에 한 줄로 자동 표기. `[교과서]`

- "숫자가 너무 좋으면 데이터 버그다": 10/16~17 시스템이 MU·SNDK 의 분기 5→14→28→38B 를 '누적치 의심'으로 검증전 처리했으나 8-K 원문과 전부 일치했다. 휴리스틱(cumulative_smell)은 초고성장과 누적치를 구분 못 한다 — 원문 대조(fin_verified.json)가 우선. 이건 **사이클 부정 편향**(이번엔 다르다의 반대: '이렇게 좋을 리 없다')이고, 반대로 2018·2022 에는 '이렇게 좋은 게 계속된다' 편향이 있었다. 둘 다 숫자가 아니라 태도. `[경험]`

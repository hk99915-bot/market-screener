## 1. 흐름 — 세 축 + 함의 (위에서 아래 = 읽는 순서)
| 축 | 칸 | 무엇을 쓰나 | 흔한 함정 |
|---|---|---|---|
| 머리 | **So What 한 줄** | 돈이 어디로 가고, 가격은 그걸 얼마나 반영했나 + 등급·신뢰도 | '성장 산업이다'로 끝냄(누구나 아는 말 = 결론 아님) |
| A 구조 | ① 규모·성장(TAM/SAM, CAGR) | TAM=전체 지출, SAM=우리 유니버스 상장사가 실제 파는 구간. CAGR 식 `(끝/시작)^(1/년수)−1`, 출처·기준일·통화 | 리서치사마다 정의가 달라 숫자 섞기 · 벤더 배포본을 1차로 착각 · TAM 크기를 이익으로 읽기 |
| A 구조 | ② 연결된 체인 | 앞(공급·비용)·뒤(고객·수요)·옆(대체·보완) 산업을 화살표로, 각 고리에 전달 변수 1개. `reports/chains_view.json` 우리 체인 정의와 대조 | 체인을 '관련 업종 나열'로 씀 — 무엇이(예산·금리·사고) 어느 고리로 전달되는지가 핵심 |
| A 구조 | ③ 밸류체인·이익풀 | 구간별 대표 · 매출 · 마진 → 매출은 어디서 크고 이익(GAAP·현금)은 어디서 남나 | 매출 크기 = 이익 크기 · GAAP 적자(주식보상)와 현금 흑자 혼동 — 둘 다 적기 |
| A 구조 | ④ 경쟁·집중도 | 상위 사 점유율(CR4·CR6·HHI), 하위 시장별로 따로 | 한 리서치사 순위표를 점유율로 · 인수 성장을 유기 성장으로 |
| A 구조 | ⑤ 전환비용·가격결정력 + **왜 이 구조인가** | 매출총이익률·RPO(계약 잔고) vs 매출 성장·할인 관행 / 구조의 원인 1~3개 | '해자 있음' 형용사 — 마진·잔고 숫자로. Porter 5 forces 는 상/중/하 + 근거 숫자 1개(없으면 '애널 판단, 검증전') |
| B 변화 | ⑥ 변천사 | 시대별 국면·전환점·사건·M&A 물결·승자/패자와 **바뀐 이유** | 연표만 나열 — '왜 승자가 바뀌었나'가 빠지면 의미 없음 |
| B 변화 | ⑦ 파생 구조 | 하위 시장·사업모델 계보(A→B→C), 각 단계 대표 기업 | 신조어(마케팅 용어)를 별개 시장으로 셈 |
| B 변화 | ⑧ 장단기 추세 | 단기(분기~1년)·중기(1~3년)·장기(3~10년) 각각 근거 숫자·지속 조건·뒤집힘 조건 | 단기 주가 흐름을 장기 추세로 · 지속 조건 없는 추세 |
| B 변화 | ⑨ 동인·KBF | 수요를 미는 숫자(사고·규제·교체 주기) / 사는 사람이 실제 보는 기준 3~4개 | 해킹 뉴스 → 분기 매출로 직결(예산은 연 단위) |
| C 이슈 | ⑩ 핵심 이슈 3~5개 | 업계가 지금 실제로 싸우는 쟁점, **양쪽 주장 + 숫자 + 판가름 지표(값·발표일) + 지금 기울기** | 한쪽 주장만 · 판가름 지표가 '시장 반응' 같은 관찰 불가 문장 |
| D 함의 | ⑪ 리스크·반대 근거 | 결론을 깨는 숫자 1개 · 밸류(E/P−rf, FCF 수익률 vs 국채) · 꼬리위험 | 리스크 나열로 때움 |
| D 함의 | ⑫ 투자 함의(매핑) | 구간 × 국장·미장 종목 · 밸류 분모 범위(PER TTM/런레이트/가이던스/정규화 중 2개 이상) · 상태 | **매매 지시 금지**(매핑 ≠ 추천) · 개인 보유·금액 금지 · PER 한 분모 |
| D 함의 | ⑬ 확인 불가 · ⑭ 뒤집힘 조건 | 못 본 숫자 + **찾아본 경로** · `[확인 필요: 무엇, 2026-11-16]`(기한 날짜 필수) / 결론을 뒤집을 숫자 1~3개(값·발표일) | 빈칸을 추정으로 메움 · '상황이 바뀌면' 같은 문장 |

## 2. 보조 틀 (모양 고정 — 상세는 부록)
- **체인:** 코드블록 화살표 `공급 → [산업] → 고객`, 표 `고리 | 전달 변수 | 방향(+/−) | 근거 숫자 | 우리 체인에 있나`.
- **이익풀:** `구간 | 대표(미/한) | 매출 비중 | GAAP 영업이익 비중 | 영업CF 비중 | 한 줄`.
- **변천사:** `시대 | 국면 | 전환점·사건 | M&A 물결 | 승자 → 패자 | 바뀐 이유`.
- **파생 구조:** `계보(A→B→C) | 갈라진 이유 | 대표 기업 | 지금 단계`.
- **추세:** `기간 | 추세 | 근거 숫자 | 지속 조건 | 뒤집힘 조건`.
- **핵심 이슈:** `쟁점 | A측(숫자) | B측(숫자) | 판가름 지표·시점 | 지금 기울기`.
- 밸류 숫자를 쓰면 E/P−rf·20일 분해(EPS 변화 없으면 '전부 배수, 검증전')를 같은 칸에.
- 셀사이드·리서치사 숫자는 세 칸: 말하는 것 / 우리 산출물로 확인되는 것 / 확인 불가 + 매수 의견 비율(N건 중 M건).

## 3. 현업식 절차 — 자기 반박 2회전
1. **v0 초안**: 기존 산출물(rounds·detail·valuation_notes)만으로 칸을 채운다.
2. **1회전**: 주장마다 "그래서?"(So What — 투자·업계에 무슨 뜻) + "정말?"(반증 데이터 1개를 **1차 숫자**로 찾는다). 깨지면 문장을 고친다.
3. **2회전**: 고친 문장에 다시 한 번. 특히 ① 같은 정보원끼리 맞장구친 것(독립 아님) ② GAAP·인수·계절성 왜곡 ③ 우리 체인 정의의 `[가정]`.
4. 부록에 로그 표: `주장 v0 | 그래서? | 정말?(반증·출처) | v1 | 2회전 | v2`. 본문엔 v2 만.
5. 막히면 다른 경로(아래 §4 순서)로 끝까지 — 그래도 없으면 '미확인' + 찾은 경로.

## 5. 용어 (20대 직장인용 한 줄)
| 용어 | 뜻 |
|---|---|
| TAM / SAM | 이 산업에 쓰이는 돈 전체 / 그중 우리가 볼 수 있는 상장사가 실제로 파는 부분 |
| CAGR | 매년 평균 몇 %씩 컸나(복리). 시작·끝 연도를 반드시 같이 |
| 이익풀(profit pool) | 산업 전체 이익이 밸류체인 어느 칸에 고여 있나 |
| CR4 / HHI | 상위 4사 점유율 합 / 점유율 제곱합(높을수록 과점) |
| KBF | 고객이 '이걸 산다'고 정할 때 실제로 보는 기준 |
| 전환비용 | 다른 회사로 갈아탈 때 드는 돈·시간·위험 — 높을수록 기존 업체가 유리 |
| ARR / NRR / RPO | 연간 반복 매출 / 기존 고객이 작년보다 얼마나 더 쓰나 / 계약은 했지만 아직 매출로 안 잡힌 잔고 |
| E/P−rf | 이익수익률(1/PER) − 국채 금리. 마이너스면 '이익만 보면 국채보다 덜 번다' |

## 6. 쓰기 규칙 (체크리스트)
- 기준일 한 줄(가격·실적·리서치 각각), 숫자마다 출처(파일·item·end 또는 링크), 계산은 식 한 줄 `[애널 환산]`.
- 본문 ≤40줄(모바일 한 화면, 표 위주) — 체인·변천사·파생·추세·이슈 상세·자기 반박 로그는 부록 파일(≤150줄).
- 결론 = What/So What/Now What + 뒤집을 숫자 1개 + 반대 근거 1개 + 등급(A/B/C/F)·신뢰도.
- 공개 저장소: 개인 금액·보유 종목·수량 금지. 매매 지시문 금지(매수·편입 언급 시 trade plan).
- 끝 세 줄: `VOC:` · `요청→` · `현재 상태:`.

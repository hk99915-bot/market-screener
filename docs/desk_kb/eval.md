## 정의
1. [논문] **형성평가 vs 총괄평가**: 형성평가는 학습 도중 결과를 되돌려 다음 학습을 바꾸는 데 쓰고, 총괄평가는 끝난 뒤 등급을 매긴다. 형성평가가 학습 효과를 키운다는 종합 연구(Black & Wiliam 1998)의 핵심 조건은 **결과가 학습자와 설계자에게 돌아가는 것**이다. 돌아가지 않는 퀴즈는 형성평가가 아니다.
2. [교과서] **문항 난이도 p** = 정답자 수 / 응시자 수(고전검사이론). p가 0.9 이상이면 변별이 거의 없고, 0.3 이하면 문항 자체 결함부터 의심한다.
3. [교과서] **변별도 D** = (상위 집단 정답률) − (하위 집단 정답률), 상·하위는 총점 기준 각 27%(Kelley 1939). 학습자 1명인 우리는 사람 간 변별 대신 **같은 문항의 회차 간 정답 변화**를 본다(#9).
4. [교과서] **SRS(간격 반복)**: 맞히면 다음 복습 간격을 늘리고, 틀리면 처음 간격으로 되돌린다(Leitner 상자 방식). 우리 간격 1·3·7·21일의 근거는 `kb:edu#4`.
5. [경험] **오답 환류**: 틀린 문항 → 그 문항의 출처 KB 항목 → 해당 데스크의 '흔한 오해' 또는 '복기'에 반영. 학습자가 데스크 답을 이긴 문항은 그 데스크 KB 복기 후보다(타운홀 평가 발언 10/16).

## 공식
6. [교과서] p = 정답 / 응시. 예(가상): 같은 문항을 4회 풀어 1·2회 오답, 3·4회 정답 → 회차 p 0 → 1, 간격 단계 상승.
7. [경험] 정답 위치 분포 점검: 모듈 5문항 안에서 같은 위치 정답 ≤ 3개(`kb:edu#7` c항, 교육·평가 합의). 은행 전체로는 각 위치 비율이 (1/선택지 수) ± 10%p 안이면 통과.
8. [경험] 자기 신고 보정: 채점이 학습자 자기 신고면 '응답을 먼저 적고 정답을 연다'(사전 커밋) 순서가 있어야 점수로 인정한다. 사전 커밋 없는 정답은 '확인'으로만 센다.

## 현업 vs 교과서
9. [교과서 vs 경험] 교과서 문항 분석은 다수 응시자를 전제로 한다. 우리는 응시자 1명 → 사람 간 변별도 대신 회차 간 변화·오답 유형(어느 오답지를 골랐나)으로 문항을 진단한다. 오답지는 '흔한 오해'에서 뽑아야 진단 가치가 있다(`kb:edu#11`).
10. [교과서 vs 경험] 교과서 SRS는 문항 단위, 우리는 학습자 시간 제약으로 모듈 단위(`kb:edu#13`). 대신 복습 퀴즈 통과 기준을 두어 문항 신호를 보완한다.

## 흔한 오해
11. [경험] "머릿속으로 맞혔으면 아는 것" → 머릿속 정답률은 항상 높다. 답을 적을 곳이 없는 퀴즈는 복습이 아니라 확인 편향 연습이 된다(평가 데스크 10/16 발언).
12. [경험] "문항이 많을수록 평가가 정확하다" → 결과가 돌아오지 않으면 문항 수는 0과 같다. 피드백 경로(퀴즈 결과 → 진행 파일 → KB 환류)가 먼저다.
13. [경험] "정답 = 데스크 답"으로 고정하면 대결 형식이 무너진다 → 데스크가 틀리는 문항을 일부 섞어야 학습자가 데스크를 이길 수 있다(`kb:edu#8`).

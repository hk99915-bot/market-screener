# household(내무) 데스크 KB

(2026-10-17 신설. 내무 = 개인 가계 **관리회계**(순자산·예산·저축률·비상금) + **절세**. 형식은 README.md. 인용 `kb:household#<n>` — 번호 고정. **이 파일은 일반 지식만** — 개인 소득·소비·잔액·납입액은 어떤 형태로도 쓰지 않는다(비공개 `pb-private/household/` 전용). 세법 항목은 전부 2026-10-17 웹 검색으로 확인한 **2차 자료**이며 원문(법령·국세청) 대조 전이다.)

## 정의
1. [교과서] **재무회계 vs 관리회계**: 재무회계는 외부 보고용(기준서 형식), 관리회계는 내부 의사결정용(예산 대비·원인 분석). 가계로 옮기면 재무 데스크 = 돈을 굴리는 쪽(포지션·비중·위험), 내무 = 돈이 어디서 들어와 어디로 나가는지 매달 마감하고 예산과 비교하는 쪽.
2. [교과서] **저축률** = (소득 − 소비) / 소득. 예적금 납입·투자 이체는 소비가 아니라 **흑자의 배분**이다.
3. [교과서] **고정비율** = 고정비 / 소득. 고정비가 높을수록 소득 충격에 대한 완충이 작다.
4. [교과서] **예산 차이(variance)** = 실적 − 예산, 차이율 = 차이 / 예산. +면 초과(불리). 카테고리별 금액·비율만 보고 가격·물량 분해는 하지 않는다(가계 규모에서 실익 작음).
5. [교과서] **비상금 개월수** = 현금성 자산 / 월평균 필수지출. 기준선은 흔히 3~6개월(재무설계 관행) — 소득 안정성이 낮을수록 길게.
6. [교과서] **순자산 브리지**: 기초 순자산 + 저축(흑자) + 이체순액 + 투자손익(실현) + 평가변동 + 미설명 차이 = 기말 순자산. '미설명 차이'가 기초의 1%를 넘으면 잔액 입력·이체 분류부터 의심한다.

## 공식
7. [교과서] 목표 도달 예측(적립식 미래가치): 매월 NW ← NW × (1 + r) + S, r = (1 + 연수익률)^(1/12) − 1. 결과는 한 점이 아니라 **시나리오 범위**(보수·기준·낙관 수익률 × 저축 배율)로 보고한다 — 전부 `[가정]`.
8. [교과서] 세액공제 효과 = 공제 대상 납입액 × 공제율(결정세액 한도 안에서만). 소득공제 효과 = 공제액 × 한계세율 — 같은 금액이면 세액공제가 보통 더 크다.
9. [교과서] 카드 소득공제: (카드 사용액 − 총급여 × 25%) 초과분에만 공제율 적용. 예(가상): 총급여 100 단위, 사용액 20 → 문턱 25 미달 → 공제 0. **공제를 받으려고 소비를 늘리는 것은 손해**(공제율 < 100%).

## 흔한 오해
18. [경험] "예적금 납입은 지출이다" → 흑자의 배분(#2). 지출로 세면 저축률이 낮게, 소비가 크게 보인다.
19. [규정] "해외주식 손실은 내년 이익과 상계된다" → 이월 안 됨(#12, B). 올해 손실과 통산하려면 이익 실현도 올해 결제일 안에 있어야 한다.
20. [규정] "같은 S&P500 ETF면 세금도 같다" → 국내상장 해외 ETF(배당소득 15.4%, 종합과세 합산)와 해외상장 ETF(양도소득 22%, 250만 공제, 분리과세)는 다르다(#13).
21. [경험] "현금이 많으면 비상금이 충분하다" → 증권 계좌 예수금이 '현금성'에 섞이면 비상금이 부풀려진다. 비상금 분모의 출처(어느 계좌 잔액인가)를 먼저 적는다.

## 터미널에서 보는 자리
22. 공개 터미널에는 내무 숫자를 싣지 않는다(비율만 가능). 원본·보고서·절세 지도는 비공개 `pb-private/household/`(README·tax/README·월 보고서). 재무와 겹치는 값: 투자자산 평가액 = 재무 기준, 예적금·현금성 = 내무 기준.

## 우리 연구와의 차이
23. [경험] 데이터 원칙(비공개 README): 원본 거래 행 미저장(월 × 카테고리 합계만), **의료·건강 계열은 이름 없는 합계로 합치고 건수도 남기지 않음**, 계좌·카드번호·가맹점명 미기록. 교과서 가계부는 거래 단위 기록을 권하지만 우리는 보안을 위해 합계 단위로 낮췄다 — 대신 카테고리 원인 분석은 월 1줄로 한정.

# 외인·기관 매집 신호 검증 결과 (요약본)

- 원본: reports/studies/accum_signals.md (전체 표·세부 통계 수록)
- 표본: 2024-11-26 ~ 2026-10-16 (거래일 458일, 종목 2,926개), 신호 익일 종가 진입 기준
- 초과수익(ab): 동일 일자 적격 종목 평균 대비. 거래비용(왕복 약 0.25%p) 미반영

## 1. What (검증 내용 및 결과)

- 검증 대상: 8개 매집 신호의 사후 초과수익 유의성
- 결과: 연기금 20일 순매수 상위 10% 신호만 통계적 유의성 확인 (등급 A)

| 신호 | 보유 20일 | 보유 60일 | 판정 |
|---|---|---|---|
| 연기금 20일 순매수 상위 10% | +2.14% (t 3.47) | +5.41% (t 3.61) | 유의 (A) |
| 기관 5일 연속 순매수 | +0.23% | +1.93% | 미약 (C) |
| 외인·기관 동반 3일 연속 순매수 | +0.27% | +2.13% | 미약 (C) |
| 외인·기관 20일 순매수 상위 등 5종 | 0 근방 | 0 근방 | 무효 (F) |

## 2. So What (시사점)

- 연기금 신호의 일관성 확인: 전·후반기 모두 유의수준 유지 (근거 3-①)
- 외인·기관 매집의 선행성 불충분: 8개 신호 중 6개 무효 또는 미약
- 해석상 유의 사항
  - 표본기간 약 2년, 상승국면 비중 58.5% / 하락국면 14.4%
  - 소형주 편중, 유동성 미통제
  - 거래비용 미반영 (소형주는 실제 체결비용이 더 클 수 있음)

## 3. 근거 데이터 (핵심 지표만 발췌)

### ① 연기금 신호 세부 (원본 표 그대로)

| 항목 | 보유 20일 | 보유 60일 |
|---|---|---|
| 표본 수 (n) | 4,316 | 2,805 |
| KOSPI 대비 평균 (ex) | -2.17% | -8.80% |
| 동일일자 평균 대비 (ab) | +2.14% | +5.41% |
| 통계량 (t) | 3.47 | 3.61 |
| 적중률 (하한) | 39.1% (37.7%) | 31.8% (30.1%) |
| 기준 적중률 | 34.2% | 26.2% |
| 전반기 / 후반기 (ab) | +3.13% / +2.09% | +3.39% / +5.59% |
| 조정·하락국면 (ab) | +1.94% | +4.95% |

- 유의기준: 다중검정 보정 α = 0.00208 (검정 24건). t 3.47·3.61 모두 충족 (정규근사 임계 약 3.1, PB 환산)
- 유의: KOSPI 대비(ex)는 음수 → 신호 종목도 KOSPI 대비로는 열위. 적격 종목 전체(소형주 포함) 평균 대비 우위로만 해석 가능

### ② 외인·기관 매집 시작 종목 특성 (연기금 신호 아님)
- 직전 20일 수익률 중앙값 +5.78% (적격 전체 -0.37%) → 이미 오른 종목에서 신호 발생 경향
- 20일 수익 ≤ 0 비중 34.9% (전체 49.6%)

### ③ 국면별 분포
- 상승 58.5% / 조정 27.1% / 하락 14.4% (거래일 비중)

### ④ 한계 (원본 6개 중 핵심 4개)
- 거래비용·슬리피지 미반영 (5일 보유 신호는 왕복 0.25%p 차감 시 대부분 소멸 가능)
- 기간 단기, 강세장 비중 과다 → 국면별 결과는 참고 수준
- 상위 10% 문턱이 소형주로 편중 (규모·유동성 미통제)
- ETF·ETN 제외 (ETF 기관 순매수는 유동성공급자 매매 반영, 매집으로 판단 불가)

## 4. Now What (조치 사항)

- 실계좌 적용 불가: 매매 신호로 사용하기 전 승인 필요 (관련 규칙 준수)
- 활용 범위: 연기금 순매수 상위 종목 중 유동성 충족 종목에 한해 관심종목 편입 (관찰용)
- 후속 검증 (담당: 퀀트)
  - 소형주 제외 재검증
  - 거래비용 반영 후 재산출
  - 하락국면 표본 보강 후 재검증
- 폐기 기준(안): 후반기 초과수익 +1% 미만 또는 t 값 3 미만 시 폐기

# 컴플라이언스 온보딩 평행 재시험 6문항 (10/28 출제 · 마감 10/31)

근거: 평가 `rounds/2026-10-28/eval_riskhq_onboarding.md` — 컴플 '조건부 이수', 조건 = 평행 6문항 재시험에서 4 이상. 원 문항 `compliance_quiz.md` q1~q6 과 개념은 같고 장면·숫자는 다르다(q7↔q1 … q12↔q6). 원 키를 옮겨 적으면 장면 고유 필수 키를 놓쳐 통과하지 못한다.

**순서 규약(G1 — 이번엔 커밋으로 증명한다)**
1. **답안 먼저 커밋.** 컴플이 라운드 파일(`docs/desk_kb/rounds/<날짜>/compliance.md`)에 `퀴즈: compliance-qN <내 답>` 6줄(q7~q12)을 쓰고, **그 줄만 있는 커밋**을 main 에 push 한다. 다른 작업과 한 커밋에 섞지 않는다(순서를 확인할 수 있게).
2. **그 뒤에 키 공개.** 키는 지금 공개 저장소에 없다(교육 비공개 보관). 답안 커밋이 main 에 들어간 뒤에만 교육이 키를 `content/onboarding/compliance.json` 에 합치고, 이 문서 둘째 줄의 '키 비공개' 표식을 지운다. 키 공개 커밋은 답안 커밋보다 뒤여야 한다(평가가 `git log` 로 확인).
3. 키 공개 전에 답을 고치면 고친 커밋도 키 공개 전이어야 한다. 키를 본 뒤 고친 답은 채점하지 않는다.

채점: 평가(출제 교육 ≠ 채점 평가). 키 공개 전에는 `python3 scripts/drill_grade.py --sheet <답안> --keys <교육이 넘긴 비공개 키>`, 공개 뒤에는 `--sheet` 만. 문항별 핵심 용어·숫자 일치율 ≥60% 이고 필수 키를 모두 맞혀야 통과, **6 중 4 이상이면 컴플 온보딩 이수**. 키워드 채점은 부정문·짝을 못 보므로 평가가 답을 읽어 판정을 확정한다(kb:eval#16). 실습·부스팅 점수는 그대로 둔다.
금지: 개인 금액·수량·연봉은 답에도 쓰지 않는다(비율·구간·등급만).

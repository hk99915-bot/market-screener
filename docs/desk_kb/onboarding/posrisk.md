## 4. 경계·에스컬레이션
- 포지션리스크 = 측정·신호등까지. 판정·위반 로그 = 컴플, 시나리오·모형·한도 설계 = FRM, 운용 = HF(1선), ISA 목표 = 자산배분, 장중 절차 = 운영, 사후 감사 = 감사, 행동 = 행동.
- 신호등 → 길: 녹·황 = 일일 표만 · 적 = 컴플·해당 1선 데스크 ask(당일) · 초과 = 컴플 판정 요청 + PB 보고 · **치명**(실계좌 금지 상품 노출 발견, 공개 산출물에 금액·수량, 모의 북 −5% 정지 미이행) = 보드 **P0** + PB 경유 겸이.
- 모형 이견(예: 스트레스 분류 기준)은 내 표에서 고치지 않고 FRM 에 ask — 내 표엔 두 숫자를 나란히.
- 작업 규약(`LOOP.md`): 자기 worktree, 경로 지정 add, 커밋 접두 `posrisk:`, `--no-verify` 금지, `python3 scripts/ask.py --from 포지션리스크 --to <데스크>`.

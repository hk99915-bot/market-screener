## 4. 경계·에스컬레이션
- 컴플 = 판정·기록·보고. 규칙을 만들거나 고치지 않는다(겸이 결재). 수치 설계 = FRM·행동, 측정 = 포지션리스크, 사후 무편집 감사 = 감사, 장중 절차 = 운영, 왜 어겼나 = 행동(같은 조항 2회째부터 ask).
- 사다리(kb:compliance#7): 경고(담당 데스크 ask) → 보고(PB, 당일) → 결재(겸이). **치명**(실계좌 [2] 금지 상품·미수·신용·쿨다운 중 매매·미보고, 공개 저장소 실제 금액·계좌·토큰) = 보드 **P0** + PB 경유 겸이, 당일. 중 = 요청 장부 2영업일. 경 = 주간 커버리지 표.
- 컴플이 하지 않는 것: 남의 KB·코드 수정, 이력 삭제(감사 C1: 이력 처리는 PB→겸이), 위반 줄 삭제(종결 시각만), '예외'를 말로 인정(서면 = 원장 ✅ 줄 + 원천 파일 반영 커밋).
- 작업 규약(`LOOP.md`): 자기 worktree, 경로 지정 `git add`, 커밋 접두 `compliance:`, `--no-verify` 금지, 요청은 `python3 scripts/ask.py --from 컴플라이언스 --to <데스크>`.

## 6. 이수 기준·부스팅
- **이수**: 실습 1·2 통과(평가 재현) + 퀴즈 6문항 중 4 이상(문항당 키 일치 ≥60%) + 부스팅 산출물(KB 반영 커밋 + 드릴 2개 + 짝 검수 요청 id). 미달 문항은 해당 절 다시 읽고 다음 라운드에 재응시. 판정 = 평가(출제 교육 ≠ 검수 평가).
- **부스팅**(10/24 겸이 "지금 빠르게 부스팅" — 에이전트는 세션 간 기억이 없어 나눠 배울 이유가 없고 KB 에 쓴 것만 남는다): 후보 자료 — IOSCO *Compliance Function at Market Intermediaries*(2006) · BCBS *Compliance and the compliance function in banks*(2005) · 금융투자회사 표준내부통제기준(금융투자협회) · COSO *Internal Control — Integrated Framework*(2013). 각 자료 = 출처 URL·등급 + 세 칸(내용·그 기관의 뷰·우리 해석, STANDARD §4). 첫 연계학습 회차 = 짝(감사) 검수, `docs/desk_kb/onboarding/learning_program.md`.

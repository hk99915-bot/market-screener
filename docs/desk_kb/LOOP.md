# 데스크 강화 루프 (2026-10-17 오너 지시: "주도적으로 강화 루프 켜서 서로 협업하고 발전")

데스크는 세션마다 새로 깨어나므로 성장은 파일로만 누적된다. 이 루프는 **누가 시키지 않아도** 돈다.

## 한 라운드 (데스크당 30분 상한)
1. **읽기** — 자기 KB 전체 + `## 복기` 최근 3건 + 지정 피어 데스크 KB 1개 + `_scoreboard.md` + 자기 보드 태스크(ops/board.json).
2. **배우기 1건** — 외부 표준 자료(교과서·논문·규정·공시) 1개를 읽고 KB에 출처 등급과 함께 추가. 우리 자체연구와 다르면 '차이'에 양쪽.
3. **고치기 1건** — 자기 도메인의 코드·데이터·문서에서 가장 작은 실질 개선 1개를 **직접 구현**(테스트 포함). 30분 넘으면 보드 태스크로 등록하고 멈춘다.
4. **피어 1건** — 피어 KB/산출물에 대한 반대 의견 또는 요청 1개를 **자기 라운드 파일**에 적는다 (피어 파일 직접 수정 금지 — 충돌 방지·무편집 원칙). **문항(content/study·content/drills)을 새로 쓰거나 바꾼 라운드는 출제자≠검수자** — 다른 데스크(기본 평가) 1곳이 정답·해설·오답지를 검수하고 그 데스크 라운드 파일에 `검수→<출제 데스크>: <문항 id> 통과/반려 사유` 1줄(10/24 겸이 결재 G2, %p 정답 오류 계기). 기계 검사는 `scripts/study_answer_lint.py`(계산·정답 키·얼버무림) — 말로 된 판단의 모순은 사람 검수만 잡는다.
5. **복기 1건** — 최근 자기 판단 중 틀렸거나 애매했던 것 1개: 틀림 → 왜 → 다음부터.
6. **VOC 1줄** — 이번 라운드에서 막힌 것·필요한 것·PB/오너에게 할 말(솔직하게). PB는 모든 답변에 데스크 VOC를 요약 보고한다(오너 지시 10/17).
7. **감사** — 감사 데스크(docs/desk_kb/audit.md)가 라운드 산출물을 slop 기준으로 채점한다. 채점 결과는 라운드 표에 '감사' 열로.
8. **라운드 파일** — `docs/desk_kb/rounds/YYYY-MM-DD/<desk>.md`에 1~5를 각 3줄 이내. `VOC:` 줄과 마지막 줄 `요청→<데스크>: …` 형식(코디네이터가 다음 라운드 배정에 씀).

## 코디네이터(PB 또는 운영)
- 라운드 파일을 모아 `_scoreboard.md`의 **라운드 표**(데스크 | 배움 | 고침 | 피어 | 복기 | 요청 건수)에 1줄씩, 요청은 다음 라운드의 피어 배정으로.
- 요청이 요청일부터 2영업일 미처리면 보드 P1로 승격 — 라운드 없이도 watchdog(ops.yml 00:07)이 매일 판정(10/21 E). 라운드 밖 요청은 `scripts/ask.py`.
- 월 1회 `_scoreboard.md` 적중률(점도표·모의·연구 등급)과 라운드 표를 나란히 두고 "많이 고친 데스크가 더 맞히는가"를 본다.
- 팀 업무량(ops/team.json)은 **PM 데스크 소관**: 에이전트 완료 통계(토큰·도구·시간) runs 기록은 PB가 PM에 넘기고, `auto` 블록(커밋·보드·요청·감사)은 `scripts/team_stats.py`가 매일 자동(ops.yml 00:07·23:47 KST + round_collect --apply).

## 작업 격리 (라운드 1 VOC 7건: 공유 체크아웃 때문에 커밋 귀속 섞임·rebase 막힘)
- 데스크 에이전트는 **자기 worktree**에서 일한다: `git worktree add /tmp/claude-0/.../scratchpad/wt_<desk> origin/main` → 작업 → 커밋 → `git push origin HEAD:main`(거부 시 `pull --rebase`) → `git worktree remove`. 공유 체크아웃에서 편집 금지.
- 커밋 신원은 저장소 기본(`Claude <noreply@anthropic.com>`). 개인 이메일 금지.
- `git add -A` 금지. 경로 지정 add만.
- **push 전 검사 훅**(`.githooks/pre-push` → `scripts/prepush_check.py`, 설치 `sh scripts/install_hooks.sh`)이 실패하면 고친 뒤 다시 push. `git push --no-verify`·`core.hooksPath` 해제 등 **우회 금지**(10/20 '푸시 금지' 무시 사고).
- **커밋 접두**: 모든 데스크 커밋 메시지는 `<desk>:` 또는 `<desk> 라운드N:`로 시작(PB는 `pb:`). 팀 업무량 자동 집계(scripts/team_stats.py)가 이걸로 데스크를 센다 — 10/17 첫 집계에서 커밋 2/3가 미분류(PM VOC).
- **에이전트 완료 통계**: PB는 에이전트가 끝날 때마다 `python3 scripts/team_run.py --owner … --task … --tokens … --tools … --sec … --model …` 로 즉시 기록(PM 소관). 나머지 지표(커밋·보드·요청·감사)는 `.github/workflows/team.yml` 이 매시 17분 자동 갱신(10/17 오너: 모든 작업 활성화 때 자동 → 10/21 감사 #5 로 push 트리거에서 매시로).

## 주간 라운드 추가 칸 — 자체학습·연계학습 (10/24 겸이 "자체학습도, 누나들 서로 연계학습도", 본문 `docs/desk_kb/onboarding/learning_program.md`)
- **자체학습**: 위 2항 '배우기'를 10년차 격차 줄 기준으로 하는 것 그대로(STANDARD §7). 신입은 채용 당일 1회 집중 부스팅(외부 표준 2~3개 → KB 격차 줄 → 드릴 2개 → 짝 검수) — 에이전트는 세션 간 기억이 없어 나눠 배울 이유가 없다.
- **연계학습**(본부 안 짝 1 + 본부 밖 짝 1, 짝 표 = 본문 B): ① `## 가르치기` 5분 노트 ≤15줄 + 자기 KB 드릴 2개(키 `content/drills/<desk>.json`) ② 짝 2곳 드릴을 키 보기 전에 `드릴: <id> <답>` ③ `반박→`·`검수→<짝>` 1줄씩 ④ 본부 세션 몫 1줄(대표는 본부 노트). 채점 = `round_collect`→`drill_grade` 자동 + 평가, 출제자≠채점자.
- 상태: 1회차 10/24 PB 실행(`rounds/2026-10-24/_xlearn_brief.md`). **금요일 라운드 상설은 겸이 결재 뒤**(보드 `appr-edu-xlearn`, 증분 주 ≈ 22만 토큰) — 새 예약은 만들지 않는다.

## 요청 응답 규약
- 요청을 받은 데스크는 다음 라운드 파일에 `처리→<요청 데스크>: <무엇을 어떻게 / 또는 거절 사유>` 1줄로 닫는다. 안 닫히면 2영업일 뒤 watchdog·round_collect가 보드 P1로 올린다. 라운드 밖에서 닫을 땐 `python3 scripts/ask.py --close <id>`.

## 금지
- 개인 보유·금액·연봉 언급. 실제 증권사 애널 이름 인용. 매매 지시문.
- 다른 데스크 KB·라운드 파일 수정. 테스트 깨진 채 push. 검증전 결과를 확정처럼 쓰기.
- 산출물이 목표 날짜를 못 얻으면 이전 값을 쓰더라도 반드시 stale 표시·freshness 기록(`screener.guard.record_stale`) — 조용한 대체 금지 (10/17 오너).

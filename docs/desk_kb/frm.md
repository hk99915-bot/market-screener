## 정의
- #1 [교과서] 손실 비대칭: 손실 L 뒤 원금 회복에 필요한 수익률 = 1/(1−L) − 1. −10% → +11.1%, −20% → +25%, −50% → +100%, −58% → +138%. (출처: CFA L1 Portfolio Risk & Return I, 산술·기하 수익률)
- #4 [교과서] 파라메트릭 VaR99 = 2.326σ, ES97.5 = 2.338σ (정규 가정, 1일, σ = 일간 수익률 표준편차). 정규면 둘이 거의 같다. (출처: Jorion *Value at Risk* 3판 5장 `[확인 필요]`; BCBS FRTB)
- #5 [교과서] 역사적 VaR99 = 최근 250일 손익의 1% 분위; 역사적 ES97.5 = 최악 2.5%(약 6일)의 평균. 파라메트릭과 격차가 크면 꼬리가 두껍다는 신호. (출처: Jorion 5장 `[확인 필요]`)
- #7 [현업 관행] 계기판 vs 한도: 계기판 = 보고 행동을 고르는 숫자(VaR·ES·β). 한도 = 초과 시 ①치유 기간 ②단계적 조치 ③예외 사전승인이 붙은 숫자. 셋 중 하나라도 없으면 보고 항목이다. (근거: 은행 시장리스크 한도 체계의 초과→치유→에스컬레이션 3단계)
- #9 [교과서] 스트레스 테스트(사건 재생) = 과거 특정 구간의 실측 수익률을 현재 비중에 적용한 손익률. 사건 선택: 내 주 위험이 터진 사건 + 성격이 다른 2~3개(유동성 위기형·하루 급락형·테마 붕괴형). (출처: Jorion 스트레스 테스트 장 `[확인 필요]`)
- #11 [교과서] 베타 β = Cov(포트, 지수) ÷ Var(지수). 평균 관계이지 꼬리 보장이 아니다 — 테마 급락은 지수와 무관하게 더 깊을 수 있다. (출처: CFA L1 CAPM)
- #21 [규정] Basel FRTB(2016/2019)가 VaR99 → ES97.5로 간 이유: 임계값 '넘었는지'가 아니라 넘었을 때 '얼마나'(꼬리 평균)를 보기 위해. 97.5%는 정규에서 VaR99와 등가(2.338σ vs 2.326σ)라 보수성 수준은 유지, 두꺼운 꼬리에서만 ES가 더 커진다. 스트레스 ES = 최악 250일 구간 보정. (출처: BCBS FRTB, 2차 자료로 확인 `[확인 필요: 원문 절]`)
- #25 [규정] BCBS *Stress testing principles* (2018-10-17 발행, 2009년 원칙 대체, 원칙 1~9): 스트레스 테스트는 ①목적이 명시된 프로그램 ②거버넌스(승인·한도 연결) ③**시나리오는 '심각하되 개연성'(severe but plausible)** ④모형·가정 문서화 ⑤결과를 의사결정(한도·비중)에 실제로 쓴다 ⑥정기 검토. 우리 적용: 사건 재생(#9)은 '개연성'을 실측으로 충족, 한도 연결은 결재 #3(−15% 구속). 미충족: 가정 문서화 — 2026-07 재현의 분류별 충격(semi −30 · elec −24 · 룩스루 −30×비중)을 `pb.py STRESS_SCENARIOS` 주석에 처음 적음(2026-10-17). (출처: BIS d450 press release p181017 2차 확인 `[확인 필요: 원칙 번호·문구, 2026-10-24까지 d450.pdf 원문 대조]`; 반대 근거: 은행용 원칙이라 개인 포트엔 '감독당국' 절반은 무관 — 적용 범위는 ①③⑤만)

## 공식
- #2 [교과서] 산술 vs 기하: +50% 뒤 −50% → 산술평균 0%, 실제 100→150→75 (2년 −25%, 연 −13.4%). (출처: CFA L1)
- #3 [교과서] 변동성 끌림: g ≈ μ − σ²/2. σ 20% → −2%p, σ 40% → −8%p — σ 2배면 끌림 4배. μ 5%·σ 40%면 g ≈ −3%(산술 양수, 복리 음수). Kelly 성장률 g(f) = μf − σ²f²/2의 f=1 경우. (출처: Kelly 성장률, 2차 자료로 확인 `[확인 필요: 원전]`)
- #6 [교과서][규정] 초과일 백테스트: 매일 "손실 > 전날 VaR99?" 카운트. 250일 기대 2.5회. Basel 신호등: 0–4 녹(정상) / 5–9 황(의심) / 10+ 적(모형 폐기). 초과일이 몰려 있으면 레짐 변화, 고르게 흩어져 있으면 모형(꼬리) 오류. 0회도 오류(VaR 과대 → 비중 불필요 축소). (출처: Jorion 3판 6장 Kupiec POF·Christoffersen `[확인 필요]`; Basel 백테스트 `[확인 필요]`)
- #10 [산술] 스트레스 비중 산술: 포트 손실 = 충격 × 비중. −15% × 40% = −6%. 한도 −15%면 허용 충격 = 15 ÷ 비중(40% → −37.5%). 테마 재생 충격이 −45%면 비중 ≤ 33%. (출처: 정의에서 직접)
- #12 [교과서] 2자산 분산 σ_p² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂. 각 σ 40%, 50/50: ρ 0 → 28.3%, 0.5 → 34.6%, 0.8 → 38.0%, 0.9 → 39.0%, 1 → 40%. n종목 등가중·동일 ρ: σ_p²/σ² = 1/n + ρ(1−1/n); ρ 0.8·n 5 → σ_p = 0.92σ. (출처: CFA L1 Portfolio Risk & Return II)
- #15 [산술] 현금흐름 리밸런싱(적립 희석): w′ = w(1+r) / (1 + c + w·r). w 테마 비중, r 테마 수익률(기타 자산 0), c = 적립 ÷ 직전 순자산(기타 자산에 투입). r=0 → w′ = w/(1+c): 40%·c 2%/월 → 7개월에 35%(0.4/1.02⁷ = 0.348); c 13.7%면 1개월에 35.2%. c 분모(직전 vs 시작 순자산)를 먼저 정의할 것. (출처: 비중 정의에서 유도; semis_cap H2 사전 산술과 일치)
- #16 [현업 관행] 포지션 사이징: 비중 = 1회 리스크 예산 ÷ 손절폭. 1% ÷ 8% = 12.5%; 손절폭 6% → 16.7%; 12% → 8.3%. 손절 = max(20일 저점, 종가 − 2×ATR14), 최소 1×ATR. (근거: 트레이딩 데스크 'R 단위' 사이징; 자체연구 rule_audit #6 atr_stop 등급 C)
- #24 [교과서] 위험 기여(성분 VaR 비율) = w_i × Cov(r_i, r_p) / σ_p². 50/50, σ 40%·10%, ρ 0 → 기여 94% vs 6%(비중 같아도 위험 16배 차이). 성분 VaR 합 = 포트 VaR(단독 VaR 합보다 작다). (출처: Jorion 3판 7장 marginal/component VaR `[확인 필요]`)

## 현업 vs 교과서
- #8 [현업 관행] 지킬 수 없는 한도는 한도가 아니다: 위기 국면 σ에선 고변동 테마 0%(코어 자산만)로도 초과하는 절대 VaR 수치가 나올 수 있다. 그 상태에서 "한도"를 유지하면 규칙 전체가 무시된다. 대안: (a) 상대형(포트 VaR ≤ 지수 VaR × 0.5) (b) 장기 σ 블렌딩 (c) 구속 한도를 스트레스 −15% + 테마 비중으로 옮기고 VaR는 계기판(치유 2주). 데스크 권고 = (c)+(a). (근거: 리스크 데스크 독립 검증 2026-10-16, 비율만; 자체연구-검증전)
- #13 [자체연구-C] 밴드(목표 40 / 발동 45 / 하단 30, 주 1회, 반등일 매도) vs 월말 고정캡 40: 같은 평균 비중·같은 MDD, 수익 +0.35%p/년(p 0.029, Bonferroni 미달), **매도 횟수 1/9(10 vs 58)**. "밴드는 회전을 줄이는 장치이지 수익 장치가 아니다"가 정확한 요약. 하단 30% 되사기는 16년간 미발동. (출처: reports/studies/semis_cap.md H1)
- #14 [자체연구-A/F] 글라이드 패스(적립 희석) vs 즉시 매도: +0.34%p(A, 효과 작음, 표본 성질). "1개월 뒤 35%"는 56%의 창에서만, 2개월 99% → 기한은 '2개월 안'. 하락장 하드캡 30/35 vs 40은 MDD 0.4%p 차이 → F. 정적 산술(5%p × 20% = 1%p)의 실현값은 0.3~0.4%p — 하락이 비중을 먼저 줄인다. (출처: semis_cap H2·H3)
- #17 [현업 관행][검증전] 손절폭 15% 초과 종목 제외의 근거: 비중 ≤ 6.7%라 기여 대비 결정 비용 과다 · 손절이 아니라 '반토막 대기' · 회복 필요 수익(+17.6%)이 기대 2R과 맞먹음. 실측 검증은 없음(rule_audit #10 검증전). Kelly는 우위를 알 때의 상한, 1% 규칙은 우위를 모를 때의 생존 비율; 실무는 Kelly의 1/4~1/2 `[확인 필요: 원전]`.
- #23 [경험] 분산은 필요할 때 사라진다: 급락기엔 같은 테마·같은 국가 주식의 ρ가 0.9 이상으로 수렴하고 σ는 2배가 된다. ρ 0.5·σ 40% 포트 34.6% → ρ 0.9·σ 80% 포트 78%. 분산 소멸(×1.13)보다 σ 상승(×2.0)이 더 크다. 국채·현금은 위기에 ρ가 오르지 않는 묶음; 통화는 위기 유형(자국 통화 약세형/강세형)에 따라 방향이 바뀌므로 방패로 세지 않는다. (근거: 2020-03·2026-07 사건 재생, 비율만)

## 흔한 오해
- #18 [교과서] ① "VaR99 = 최대 손실" → 100일 중 1일은 그 밖, 크기는 ES. ② "분산 = 종목 수" → ρ 0.8인 5종목 = 0.92σ, 한 포지션. ③ "손절 −8%는 종목마다 같아야" → −8%는 '보통 σ 종목의 2×ATR' 근사일 뿐, ATR로 종목별로. ④ "VaR 한도가 작을수록 보수적" → 못 지키는 한도는 무시된다(#8). ⑤ "ES가 VaR보다 항상 훨씬 크다" → 정규면 같다; 크면 꼬리가 두껍다는 정보(#21).
- #20 [자체연구-검증전] 손실로 가는 경로 2개: A '평소 σ'로 VaR 과소 → 위기에 2배 과노출(복기 #1). B 손절폭 무시한 균등 비중 → 손절폭 4% vs 16% 종목에 같은 비중이면 리스크 4배 쏠림(#16으로 교정).

## 우리 연구와의 차이
- #22 [자체연구-검증전] 교과서 백테스트는 σ 창을 고정하지만, 데스크 검증(2026-10-16, 188일)에서 60일 σ 모형은 초과 2회(기대 1.9) 통과, 20일 σ 모형은 5회(기대 2.5) 과소였다 → **60일 실현 σ + 역사적 VaR 병기**를 기본으로 하고 20일은 참고만. '평소 σ(장기 평균)' 모형은 백테스트 자체를 하지 않아 2배 오차가 발견되지 않았다(복기 #1). 교과서(Jorion 6장)는 모형 선택 뒤의 검증을 말하고, 우리는 **σ 창 선택 자체를 백테스트로 고른다** — 후자를 따른다(국면 변동이 큰 단일 국가·단일 테마 포트라서).
- 교과서 하드캡 논리(비중 낮추면 MDD 비례 감소)와 자체연구(semis_cap H3 F: 10%p 캡 차이에 MDD 0.4%p)가 다르다. 경로상 하락이 비중을 먼저 줄이고 캡 집행(월말)이 뒤에 오기 때문. 레짐별 하드캡은 두지 않고(#14), 하락장 방어는 스트레스 재생 기반 비중 상한(#10)으로 한다.
- [자체연구-검증전] 2026-07 재현 충격 −30%의 근거: SOXX 2026-06-22 654.58 → 07-29 464.70 = −29.0% (docs/valuation_notes/2026-10-17_memory.md, 일봉 종가). MU 같은 구간 −39%라 개별주는 더 깊다 — 섹터 ETF 기준 −30%는 **하한 가정**이고 개별주 쏠림 포트엔 과소일 수 있다(반대 근거). elec −24% = −30% × ρ 0.8(#8 '상관 0.8 이상 합산' 가정, 실측 ρ 미계산 `[확인 필요: 2026-07 구간 삼성전기–SOXX ρ, 2026-10-24까지]`). 실측 수익률 재생(#9 교과서 방식)으로 바꾸려면 data/hist 의 2026-07 일봉이 필요 → 데이터 데스크 요청.

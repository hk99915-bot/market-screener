**가설 (m = 3, 단측, α = 0.05/3 = 0.0167)**
- **H1** 항상 진입·D1 헤지·기본 비용: 사이클 평균 손익 > 0.
- **H2** 조건부(VRP 하위 30%) 진입 사이클만: 평균 손익 > 0.
- **H3** 조건부 사이클 평균 − 비조건 사이클 평균(둘 다 '항상' 전략의 사이클 손익) > 0. (선별 가치)

**검정:** H1·H2 = 사이클 평균의 Newey-West(지연 1) t, H3 = Welch t. p 는 정규 근사(n ≥ 30 전제, scipy 없음). 중앙값·승률·하위 5% 병기.
**등급 규칙:** A = p < 0.0167 且 IS·OOS 같은 부호(+) 且 비용×2 에서도 평균 > 0 · B = p < 0.0167 · C = p < 0.10 · F = 그 외 · 검증전 = n < 30. **등급 상한 B** — 옵션 가격이 실제 호가가 아닌 BS 근사(options_spread 사전등록과 같은 이유). H2·H3 는 선행 노트에서 방향을 본 뒤 정했으므로 B 가 나와도 'C 상당(사후 오염)' 병기.
**행동 규칙(결과 뒤 안 바꿈):** 어느 등급이든 실계좌 행동 없음(수단 밖). A·B 라도 '모의 북 추적 후보' 문장까지만. F 면 '롱 풋 감마 스칼핑은 비용 후 기대값 근거 없음 — 교육 자료로만'.
**반대 근거(미리):** ① BS·단일 IV → 실제 풋은 스큐 때문에 ATM 근처에서도 rep_iv 보다 비쌀 수 있음(10-30 skew +4.0%p) → 롱 풋 손익이 과대평가 쪽 ② rep_iv 정의(대표 IV)가 ATM 1개월 IV 와 다름 ③ 2026 국면(실현 50~60%)이 표본 끝에 몰려 있음.

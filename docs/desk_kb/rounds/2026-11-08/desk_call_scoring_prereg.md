# 데스크 판단 적중 채점 — 사전등록 v1 (검증, 2026-11-08 21:10 KST)

요청: 겸이 11/8 20:56 「누가 제일잘맞췄나두 ㄱㄱ」. 이 파일은 **판단 이력·결과를 맞춰 보기 전에** 커밋한다(kb:verify#5·복기 10/17). 결과를 본 뒤 규칙을 바꾸면 v2 로 새 번호·일자를 달고 v1 판정은 v1 로 남긴다.

## 1. 대상 판단 (판정 시점 원문만)
| 종류 `call_type` | 무엇을 방향으로 읽나 | 측정 대상 |
|---|---|---|
| `regime` 국면 판정 | 상승장/강세 = +1, 하락장/약세 = −1, 횡보·중립·전환 중 = 0(판단 없음) | 원문이 지목한 시장, 없으면 코스피 |
| `direction` 방향 | 오른다/반등/비중확대 = +1, 내린다/추가 하락/비중축소 = −1 | 원문 지목 시장(코스피·S&P500), 없으면 코스피 |
| `wind` 바람 점수 | 점수 > +0.10 = +1, < −0.10 = −1, 그 사이 = 0(판단 없음) | 코스피(바람 점수 정의 대상) |
| `scenario` 시나리오 확률 | P(강세) − P(약세) > +0.10 = +1, < −0.10 = −1, 그 사이 = 0 | 코스피 |
| 그 외(종목 롱/회피, 변동성 크기, 조건부 문장) | **이번 채점 제외** — 목록만 남김 | — |

- 원문 = 판정 시각에 커밋된 파일의 문구·값(`source_path` + 커밋/타임스탬프). 나중 회의록의 "그때 이런 뜻이었다"는 쓰지 않는다(사후 재해석 금지). 숫자 꼬리표(bull/bear 태그)가 원문에 있으면 태그 우선, 없으면 위 표의 단어 규칙으로 기계 분류.
- 조건부("X 가 깨지면 하락")·양면("반등 가능하나 추세는 약세")은 **모호**로 분류해 분모에서 빼고 건수만 보고.
- 시나리오 확률은 시나리오 경계(몇 % 이상이 '강세')가 원문에 정의돼 있을 때만 Brier 점수를 매긴다. 정의가 없으면 위 방향 변환만 하고 Brier 는 '채점 불가(정의 없음)'.

- **주 지표: 5거래일 수익 부호.** 보조: 20거래일 수익 부호 — 창이 아직 안 닫힌 판단은 '미결'(분모 제외, 건수 보고).
- 가격: `reports/macro_series.json` `series.KOSPI`·`series.SPX` 종가(4번째 값). 마지막 확정일 이후는 미결.
- **무승부:** |창 수익| < 0.50% 면 무승부(분모 제외, 건수 보고).
- **국면 보조 판정(순환 방지):** '다음 관측 시점 국면'은 데스크 자신의 다음 판정을 정답으로 쓰지 않는다. 객관 규칙 = t+5거래일 종가가 그 시점 20일 이동평균 아래면 '하락 국면', 위면 '상승 국면' — 국면 판정 행에만 보조 적중으로 따로 표기.

## 3. 묶음·중복
- 한 데스크·한 종류·한 거래일(진입 종가 기준)당 1건 — 같은 날 여러 번이면 마지막 원문.
- 연속 같은 판정은 창이 겹쳐 독립이 아니다 → **n(판정일 수)과 n_eff(겹치지 않는 5거래일 블록 수)를 같이 보고.**
- 데스크 귀속은 원천의 `desk` 칸 그대로. 위원회(운용회의) 합의 산출물은 'CIO(회의)'로 귀속, 개별 데스크 점수에 섞지 않음.

## 4. 등급 (적중률 = 적중 / (적중+실패))
- **표본 부족:** n < 10. 적중률은 적되 순위 판단에 쓰지 않는다.
- **참고:** n ≥ 10 이지만 n_eff < 10, 또는 Wilson 95% 구간이 50% 포함.
- **우위 / 열위:** n_eff ≥ 10 이고 Wilson 95% 하한 > 50% (우위) · 상한 < 50% (열위) — 아래 다중 비교 보정 후.
- **기준선 비교 필수:** 같은 날짜 집합에서 (a) '항상 하락' (b) '직전 5일 수익 부호 연장(모멘텀)' 두 순진 규칙의 적중률을 옆에 적는다. 기간이 일방향 장이면 '항상 하락'만으로도 높은 적중이 나오므로, 데스크가 기준선보다 높지 않으면 실력 근거 아님.

## 5. 다중 비교
- 비교 칸 수 k = (데스크 × 판단 종류) 중 n ≥ 10 인 칸 수. 우위/열위 판정은 Bonferroni α = 0.05/k (Wilson 구간 z 를 그에 맞춰 키움).
- **'누가 제일 잘 맞췄나'**는 1위와 2위의 차이가 보정 후 유의하고 두 칸 모두 n ≥ 10 일 때만 이름을 댄다. 아니면 "구분 불가(표본 부족/차이 유의 아님)"로 쓴다.
- 기간이 짧고(판단 이력 10월 중순 이후) 한 국면(급락장)에 몰려 있다 — 결과는 이 국면 한정 성적이며 일반 실력으로 인용 금지.

# 피어리뷰 반대 의견서 — 'AI 자금조달 3건 = 하드웨어 반등 근거' 해석 (2026-10-26)

기준 2026-10-26 23:30 KST · 대상: 겸이 공유 자료 3건(메타 주식 발행 검토 보도 / Anthropic S-1 / BadOnion 10/25 리포트) · 작성 피어리뷰 데스크 · 무편집 발행
- 블라인드 고지: 대상이 자료 자체라 선열람 불가피(정의 2 불완전). 애널 사실검증(`analyst_ai_funding.md`)은 작성 시점 미발행 → 미참조.
- 이해상충 고지: 작성 에이전트·PB 모두 Anthropic 모델. Anthropic 관련 서술은 할인해서 읽을 것 — 본 의견서는 Anthropic을 '수요 근거'가 아닌 '주식 공급·현금 소모 항목'으로만 다룸.

## What
- BadOnion 결론의 반등 경로 = "CAPEX 증가율 둔화 → OCF 회복 → FCF 개선 → HW 주가 반등", 빅4 CAPEX 증가율 86%→24%→10%(2026→27→28, 자체 모형)
- 같은 리포트 내 Anthropic 런레이트 추정 $70.3B, 범위 $65.4B–78.4B(폭 18.5%p, 피어 환산), "백테스트 오차 상당히 큼" 자인
- 2026년 대형 기술주 주식 공급: Alphabet 6월 $84.75B 주식·의무전환우선주 발행(가격 결정 2026-06-02) + 메타 발행 검토 보도(메타 "추측") + Anthropic IPO 추진(PB 전달, 미확인)

## So What
- 반등 논지의 엔진(CAPEX 증가율 86%→10%)은 곧 HW 공급사 매출 증가율의 감속 — 'FCF 회복'과 'HW 매출 견조'는 같은 모형 안에서 동시 성립 어려움
- 주식 발행 급증은 바닥 신호보다 사이클 후반 신호 사례가 다수(아래 근거 3) — '이미 다 맞았다' 바닥 뷰와 정면 충돌
- 유의: 피어 논지도 BadOnion 모형 숫자에 의존(같은 모형 오차 공유), 하우스 비관론 다수가 날짜·원문 미확인

## 주장
- 세 자료는 'AI 수요 존재'의 근거일 뿐 '반도체·전기 하드웨어 주가 반등'의 근거가 아님 — 오히려 자금조달이 주식·벤더 금융으로 옮겨가는 후반부 신호와 겹침.

## 근거 (대상 자료 자기모순 우선)
1. [자기모순·BadOnion] 반등 메커니즘이 CAPEX 증가율 86%→24%→10% 감속 전제(자체 모형) — HW 8사 매출 YoY>0 근거는 감속 전 구간 관측. 리포트 스스로 "무조건 사야 한다는 건 아님", "FCF 2027 초까지 한 번 더 눌림", "메모리는 먼 미래 사이클 위험" 명시.
2. [모형·컨센 의존] 빅4 FCF 2027Q1 개선·Q2 흑자 전환은 Fiscal.ai 자체 모형·Forecast/Proxy. 코어위브 '2030→2028 당김'은 GS 2028E를 고정한 채 OCF +10%·CAPEX −10% 동시 가정한 시나리오(리포트 표기 "Scenario").
3. [주식 공급=후반 신호 사례] 신규 발행 중 주식 비중이 높을수록 이후 시장 수익률 저조(Baker & Wurgler 2000, *Journal of Finance* 55(5)). 1999–2000 IPO·후속 발행 급증이 기술주 고점과 동행. 2026: Alphabet $84.75B(6월) → 메타 검토 → Anthropic IPO 추진 순 공급 증가.
4. [순환 투자·벤더 금융] 칩 공급사가 고객 자금을 대는 구조 지적 — Baird 모턴슨 "Bank of Nvidia·AMD·Broadcom", 기관 반응 부정적(2026-10-15 보도, 2차 자료·원문 미확인). 역사 사례: 1999–2001 루슨트·노텔 벤더 파이낸싱 → 고객 부도 시 매출·채권 동시 손실.
5. [계약 '최대/최소'·해지] S-1 대형 컴퓨트 계약은 금액 표기가 '최대(up to)'·최소 구매약정·해지 조항 구분 필요 — 미확인(애널 사실검증·S-1 약정 주석 확인 경로). 헤드라인 총액 ≠ HW 주문 확정액.
6. [런레이트·현금] Anthropic 런레이트 추정 범위 폭 18.5%p(BadOnion), 영업현금흐름 2023~26H1 누적 −60억 달러(PB 전달, 미확인) — 매출 성장이 현금 회수보다 앞섬, '매출 ≠ 회수'는 BadOnion 표지 문구 자체.
7. [생존편향] "HW 8/8 YoY>0"은 "선정 8사 · 시장 전체는 아님"(리포트 표기). NVDA·TSM 등 승자 중심 — 메모리 NAND·한국 부품(MLCC·기판) 미포함.

## 반등 논지가 틀렸을 때 포트 경로 (종목 일반·비율만)
1. 빅4 3분기 실적(10월 말~11월 초)에서 2027 CAPEX 증가율 감속 확인 → HW 공급사 성장률 멀티플 축소(이익 견조해도 주가 하락 가능).
2. 대형 주식 공급(메타·Anthropic IPO) → AI 테마 수급 분산, 고베타 반도체·부품부터 매도.
3. 메모리: NAND 계약가 모멘텀 둔화 시 SNDK형 무해자 메모리 이익 추정 하향 폭 최대(이익 레버리지). 전기·부품: AI 서버 MLCC·기판 수요가 CAPEX 증가율에 직결.
4. 집중도: 리스크 엔진 7월 재생 손실 중 반도체·전기 기여 86%(비공개 리스크 산출물, 비율) — 위 1~3이 같은 요인으로 동시에 작동, 분산 효과 기대 불가.

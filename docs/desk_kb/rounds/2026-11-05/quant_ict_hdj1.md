- 벤치(무작위 진입): 같은 시장·같은 기간·같은 방향에서 매일 진입했을 때 평균 R(같은 손절·보유·비용). 초과 R = 개별 거래 R − 그 방향 벤치 평균. t = 평균 초과 R / (R의 표준오차), p = 단측 정규 근사(가설: 초과>0).
- 시도 N = 규칙×시장 26개(R3 SMT 는 쌍이 있는 SPX·NASDAQ 2개만). 전체 시도 N = 이 26 + 2차 보고서(quant_ict_open.md) 규칙 수 — 합산 후 최종 Bonferroni 는 검증 데스크가 재계산. 이 보고서의 등급은 α/26=0.00192 기준이라 합산 N 이 커지면 A·B 는 더 어려워진다(C·F 는 변하지 않음).
- 등급(사전): 검증전=OOS n<30 · A=OOS p≤α/N & IS 초과>0 & OOS 평균R>0 · B=IS+OOS 합산 p≤α/N & OOS 초과>0 · C=OOS 단측 p<0.10 & IS 초과>0 · F=그 외. 사후 규칙 추가 없음.
- 규칙 문언 (`rounds/2026-11-05/quant_ict_rules.json` 과 동일):
- **R1_TurtleSoup** (SPX/NASDAQ/KOSPI): Raschke 1995: 당일 저가가 직전 20일 최저가(L20, t-20..t-1)를 하회하고 L20 형성일이 ≥4봉 전이며 종가>L20 → 롱. 숏은 대칭(20일 고가).
- **R2_CRT_PO3** (SPX/NASDAQ/KOSPI): 전일(C1) 저가를 하회 스윕했으나 종가는 C1 저가 위·C1 고가 아래(범위 안 복귀) → 롱. 한쪽만 스윕한 날만. 숏은 대칭.
- **R3_SMT** (SPX/NASDAQ): A지수 저가가 직전 20일 저가 갱신 & 상관지수 B 저가는 직전 20일 저가 미갱신 → 롱(고점 다이버전스는 숏). 쌍 SPX↔NASDAQ.
- **R4_OTE** (SPX/NASDAQ/KOSPI): fractal(3/3) 최근 확정 스윙 저점→고점 레그(≥3×ATR): 되돌림 62%에 닿고(저가≤고점−0.62R) 종가가 79% 선 위(≥고점−0.79R), 고점 후 ≤20봉, 레그당 1회 → 롱. 숏 대칭.
- **R5_OrderBlock** (SPX/NASDAQ/KOSPI): 변위봉(양봉 몸통≥1.5×ATR14(t-1) & 종가>전일 고가) 직전 5봉 내 마지막 음봉을 OB로 두고, 이후 ≤10봉 내 첫 재진입(저가≤OB 고가 & 종가≥OB 저가) → 롱. OB 저가 종가 이탈 시 폐기. 숏 대칭.
- **R6_CISD** (SPX/NASDAQ/KOSPI): t-1까지 연속 음봉 런(길이≥2, 도지 건너뜀)의 첫 봉 시가(CISD 수준)를 t 종가가 엄격히 상향 돌파 → 롱. 숏 대칭.
- **R7_BoS** (SPX/NASDAQ/KOSPI): fractal(3/3) 최근 확정 스윙 고점을 종가가 처음 상향 돌파(Break of Structure) → 롱(추세 추종). 스윙 저점 하향 돌파 → 숏.
- **R8_FVG_Retest** (SPX/NASDAQ/KOSPI): 3봉 갭 FVG(저가[t]>고가[t-2], 갭≥0.5×ATR) 형성 후 ≤10봉 내 첫 재진입(저가≤갭 상단 & 종가≥갭 하단) → 롱. 갭 하단 종가 이탈 시 폐기. 숏 대칭.
- **R9_Boom_Daily** (SPX/NASDAQ/KOSPI): Boom° Classic 일봉: C2=전일 저가 스윕 후 범위 안 종가 복귀 확정봉 b(양쪽 스윕이면 봉 색 방향); C3~C5=b+1..b+3 안에서 전일 저가 스윕일 s 이후 CISD(마지막 음봉 런 첫 봉 시가를 종가가 엄격히 상향) 확정 → 롱, 시퀀스당 1회, 새 C2 나오면 리셋. 숏 대칭. (LTF CISD 동반 유효조건은 일봉에 없어 생략)
- 중복 처리: Boom° 일봉 Classic(R9)은 CRT(R2)의 C2 정의를 쓰지만 진입이 C3~C5 스윕+CISD 이후라 별개 규칙으로 셈. CRT MASTER·PO3+는 R2 하나로 합침(같은 개념, N 1회). Auto OE Levels·Optimal Retracement Zone 은 R4 하나. CISD 단독(R6)과 Order Block(R5)은 분리.

## 4. 레드팀
1. 숏 벤치 평균 R 이 -0.16~-0.28 로 크게 음수(지수 상승 편향) — 숏 신호의 초과 R 이 구조적으로 후하게 나온다. 그래도 통과한 규칙이 없다는 점이 더 불리한 증거. 롱·숏 분리 검정은 사전등록 밖이라 안 했다.
2. 일봉 근사는 원조의 핵심(분봉 MSS·FVG·킬존)을 버린 것이다. 일봉 F 는 "ICT 장중 모델 무효"의 증거가 아니라 "일봉으로 옮기면 우위 없음"의 증거다. 장중 데이터 없이는 HDJ1 원본 주장 검증 불가.
3. 파라미터(스윙 3/3, ATR 2배, 보유 10일, 62~79%, 20일)는 사전 고정이라 최적화 안 했다 — 다른 값에서 우위가 있을 가능성은 열려 있다(탐색 시 최대 C).
4. KOSPI 는 지수라 비용 0.45% 가 실제 ETF·선물 비용과 다르다. 지수 OHLC 는 사전 고정 데이터이며 상폐·생존 편향은 없다.
5. OOS(2022~2026) 한 경로, 유효 독립 표본 작음(OOS n 15~111) → 검출력 부족: 초과 0.1R 수준 효과는 이 표본으로 못 잡는다(MDE 약 0.3~0.5R).
6. 2차 보고서 합산 시 N 이 커져 현재 C(R7 KOSPI)는 더 약해진다.
7. 소스 미확인: 보호 스크립트의 실제 규칙이 description 과 다를 수 있다. 오픈소스 Boom° 만 코드 주석으로 확인(LTF CISD 동반 조건은 일봉에 없어 생략).

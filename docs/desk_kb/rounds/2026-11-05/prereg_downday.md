> 퀀트 데스크 · 2026-11-05 · 요청: 겸이 11/5 10:47 「퀀트 검증으로 하락일 대응 최적화 플랜」, 10:48 병렬화로 H4→H1만 본 파일이 맡는다(H2·H3는 `prereg_downday_b.md`, 다른 퀀트). 이 문서는 **결과 계산 전** 단독 커밋(감사 11/5: 결과와 같은 커밋 금지). 이 문서를 쓸 때까지 본 것은 데이터 파일의 열 이름·종목 수뿐, 수익률·이벤트 수는 안 봄. 투자 권유·매매 지시 아님.

## 0. 공통
- 분할: IS = ~2021-12-31, OOS = 2022-01-01~. 날짜 분할. 정의는 결과를 본 뒤 바꾸지 않는다(바꾸면 새 id로 재등록).
- 등급: A = 전체 p < α(Bonferroni, 가설군 m) 이고 IS·OOS 평균 모두 > 0, 각각 단측 p < 0.10 · B = 전체 p < α, IS·OOS 조건 미충족 · C = 전체 단측 p < 0.10 & 평균 > 0 (반대 부호 p < 0.10 이면 'C(역방향)') · F = 그 외 · 검증전 = 독립 군집 < 8. 보정은 Bonferroni 와 BH(q 0.10) 둘 다 표기, **등급은 Bonferroni**. 탐색 셀은 등급 상한 C.
- 독립 단위 = 월 군집(같은 달 이벤트의 차이를 평균 → 월 단위 단측 1표본 t). 폭락일에 종목이 한꺼번에 걸리는 군집 때문에 종목 n 을 쓰지 않는다.
- 시도 N: 등록 m = 9 (H4 3 + H1 6). 탐색 셀(m 밖, 상한 C) 아래 명시 33(H4) + 3(H1) = 36. 이 문서 군(H4·H1) 합 45 · 별 파일(H2·H3) 시도는 `prereg_downday_b.md` 에 따로 적고 보고서가 두 파일을 합산한다. 주제 태그 `downday_response`. 기존 crash_entry 주제(N=84, 11/4)는 같은 질문 일부라 병기한다(α(N)=0.05/N).
- 비용: 국장 왕복 0.45%, 미장 0.2%. H4 는 세 안 모두 매도 1회라 비용이 같아 **차이에서 상쇄**(체결가 비교). H1 은 진입·청산 합 0.2% 를 무행동 대비에 차감, 무작위 진입 대비는 양쪽 상쇄.
- 데이터: KR 일봉 `data/hist/kr_2010~2025.parquet`(종목 2,396·시가고저종·거래량, 2025까지), 코스피 `data/deriv/daily.csv`(2010-01-04~), S&P500 `^GSPC` 야후 일봉(직전 종가는 일봉 rows[-2], meta.chartPreviousClose 금지)·원달러 `KRW=X`. 일간 |수익률| > 40% 인 창은 분할·오류로 보고 제외.
- 한계(미리): ① KR hist 는 현재 상장 종목 위주 → 상폐·거래정지 종목이 빠진 **생존편향**(낙폭 종목의 이후 반등을 과대, 세 안 모두에 같은 방향이나 B·C 에 유리) ② 14:30~15:20 체결가 자료 없음 → 반등일 체결은 그날 **종가**로 대리 ③ 360750 실거래 시계열은 2020-08~ 로 짧고 야후 접근 불확실 → H1 은 S&P500 원화환산 지수 수익률(진입 = S&P 종가 시점)로 대리하며 국내 시가 갭·괴리·환노출 미반영 ④ 평단 −20% 는 평단 정보가 없어 120거래일 고점 대비 낙폭으로 대리.

## 1. H4 — 백스톱·손절 대상 매도 타이밍: 하락일 즉시 vs 다음 반등일 vs 2주 기한
- 유니버스: 국장 대형주 = 이벤트일 전일 기준 직전 60거래일 평균 거래대금(종가×거래량) 상위 200 종목(종목 단위, 2010~2025).
- 이벤트 t(매도 결정일): ① 코스피 종가 일수익률 r_t ≤ −2% (하락일) ② 해당 종목 종가가 직전 120거래일(당일 포함) 최고 종가의 **−20% 이하**로 **처음 진입**(직전 20거래일 안에 같은 상태 없음) ③ 이후 10거래일 모두 자료 존재.
- 세 안(체결가는 t 종가 대비 비율로 기록):
  - **A 즉시** = t 종가 매도.
  - **B 반등일** = t+1~t+10 중 코스피 일수익률 ≥ +0.5% 인 첫 날 종가 매도(14:30~15:20 대리). 없으면 t+10 종가 강제(= C 와 같아짐).
  - **C 기한** = t+10 종가(2주) 강제 매도.
- 가설(m = 3, α = 0.05/3 = **0.0167**): H4a E[B−A] > 0 · H4b E[C−A] > 0 · H4c E[B−C] > 0. 차이 = 안 X 체결가/t 종가 − 안 Y 체결가/t 종가. 같은 이벤트 짝지은 차이를 월 군집 평균 → 단측 t.
- 보조(등급 제외): B 가 C 와 다른 이벤트 비율, 반등일까지 평균 대기일, 각 안 평균·중앙값 체결가 대비, 이벤트 월 수, 종목 중복.
- 탐색 셀(m 밖, 상한 C, 시도 33): 낙폭 {15,20,25}% × 하락일 문턱 {−1.5,−2,−3}% 9셀 × 3 대비 = 27 중 주 셀 3 제외 **24** · 반등 문턱 +1.0% 3 · 하락일 조건 없는 이벤트(낙폭 조건만) 3 · 코스피 지수 자체 표본(120일 고점 −10% 첫 진입 + 하락일 −2%; n 작음, 서술) 3 = **33**.
- 뒤집힘 조건: OOS 부호가 IS 와 반대면 A/B 무효(최대 C). 생존편향 조정(미구현)이 필요하다는 단서는 결과에 고정 표기.

## 2. H1 — S&P500 자체 급락일 다음 날 360750 매수
- 이벤트 T: ^GSPC 종가 일수익률 ≤ −2% 또는 ≤ −3%(두 문턱 따로). 진입 = T 종가 시점의 S&P500 원화환산(국내 ETF 는 다음 날 국내 시가에 이미 S&P 선물·환을 반영해 거래된다는 가정, **갭 미반영 = 한계**). 원화환산 수익 = (1+S&P 수익)×(1+USDKRW 변화)−1, USDKRW 는 `KRW=X` 일봉 종가.
- 청산: 진입 후 미국 거래일 h = 5/10/20 종가. 비용 0.2% 차감(무행동 대비).
- 이벤트 군집: 직전 이벤트 20거래일 이내면 군집 첫날만(비중첩).
- 비교: ① **무작위 진입 기준선** = 같은 분할·같은 h 의 모든 미국 거래일 원화환산 h일 수익 평균 ② **무행동** = 0(비용 0.2% 차감 후 평균이 > 0 인가).
- 가설(m = 6, α = 0.05/6 = **0.0083**): 문턱 {−2,−3} × h {5,10,20} 6개, H1_{th,h}: E[이벤트 h일 원화환산 수익 − 무작위 기준선 평균] > 0. 단위 = 비중첩 이벤트(월 군집이 아닌 이벤트 t; 이벤트가 드물어 월≈이벤트), 단측 1표본 t. 등급은 §0.
- 보조(등급 제외): 무행동 대비(비용 후) 평균·중앙값·승률·최악, 환 기여 분리(로컬 vs 환), 이벤트 연도 분포, 2020·2022 제외 재계산.
- 탐색 셀(시도 3): 문턱 −1.5% × h 5/10/20.
- 비교 보강: 360750 국내 상장 이후(2020-08~) 실가격은 접근 가능할 때만 보조 서술, 아니면 '미확인'.
- 뒤집힘 조건: 비용 0.2% 후 평균 ≤ 0 이면 '비용 민감'. OOS 이벤트 < 8 이면 전체로만 판정(등급 상한 B).

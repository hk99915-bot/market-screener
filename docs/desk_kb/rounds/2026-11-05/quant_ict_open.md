## 0. 사전등록 (결과 확인 전 고정 — 코드 상수와 동일, 실행 1회, 규칙·파라미터 사후 변경 없음)
- 공통: 일봉, t일 종가 신호 → t+1 시가 진입 · 손절 2×ATR14(t)(일중 저/고가 터치, 갭은 시가 체결) · 최대 10거래일 후 종가 청산 · 비용 왕복 미장 0.2%·국장 0.45%를 R 로 환산해 차감 · R = 손익÷(2×ATR14) · 시리즈별 보유 중 신호 무시 · 방향 대칭(강세 구조는 롱, 약세는 숏 — 숏은 지수 가정 거래, 실계좌 불가)
- 데이터: SPX·NASDAQ·RUT·SOXX(미) · KOSPI·KOSDAQ(한), 워밍업 70봉 제외 2025-01-17~2026-11-04. IS 70% = 2026-04-23 이하, OOS 30% = 이후(날짜 분할)
- m(시도) = 8 규칙, Bonferroni α = 0.05/8 = 0.00625(OOS 단측 t). 전체 N 은 1번 라인과 합산해 검증 데스크가 재계산
- 벤치: 같은 시리즈·방향 구성으로 같은 기간 전 일자에서 무작위 진입 n개 복원추출 2,000회 평균(seed 20261105), 벤치 p = 무작위 평균이 규칙 평균 이상인 비율
- 등급: 검증전 = IS·OOS 중 n<30 · A = IS·OOS 모두 p1<α, 평균 R>0, 벤치 초과(벤치 p<0.10) · B = OOS p1<α + 벤치 초과 · C = OOS 보정 전 p1<0.10, IS·OOS 평균 R>0, 벤치 초과 · F = 그 외(OOS p1>0.90 & t<−1.3 은 'F(역방향 경향)')

|---|---|---|

| SMC_CHOCH | ④ | 같은 정의, 직전 구조가 반대(하락→상승 돌파) = CHoCH. 첫 돌파는 추세 초기화만, 신호 없음 |
| DAYE_WEEKLY | ③ | 월·화 연속 거래일. 화요일이 월 저가만 하회(고가는 월 이내)하고 월 저가 위 마감 → 롱, 월 고가만 상회 후 아래 마감 → 숏. 양쪽 이탈 제외 |
| CHANNEL_REG | ⑤ | 60봉 종가 선형회귀 ±2σ(잔차 표준편차). 전일 종가가 하단 아래였고 당일 종가가 하단 이상 복귀 → 롱, 상단 대칭 → 숏 |

## 4. 레드팀
- 표본: 2년(IS 약 15개월, OOS 약 6개월), 규칙당 OOS n 8~61. 지수 6개가 같은 날 같이 움직여 합산 n 은 독립 표본이 아님 → t 과대. 단 결론이 '우위 없음'이라 방향은 보수적이나, 검증전 5개는 우위가 없다는 증거도 아니다(검출력 부족).
- 반대 근거: 원본 지표는 장중 구조·킬존·OB 점수 결합이 핵심이라 일봉 단독 규칙은 원본의 일부(② 전량, ④ 점수·킬존 필터)가 빠진 대리 — 대리가 약하다고 원본이 약하다는 결론은 아님. ⑤ 는 원본(피벗쌍 포함율 채점)이 아닌 회귀 채널, ⑦ 은 자동 앵커 대리.
- 파라미터(FVG 0.25 ATR, 10·20봉, 피벗 5, 60봉, 2σ, 2 ATR 이탈)는 사전 고정 1회 값으로 탐색 없음 — 다른 값에서 달라질 수 있으나 그건 N 증가. 숏은 지수 가정 거래(실계좌 불가), 지수 ETF 가 아니라 지수 레벨 체결 가정·슬리피지 미반영, 비용은 왕복 합계 단일값.
- 사전 최소 표본(OOS 30)은 이 질문에 높게 잡힌 편일 수 있음: 월 단위 신호 규칙(BPR 등)은 장중 데이터 또는 개별종목 풀(우리 KR 종목 데이터)로 확장해야 판정 가능 — 요청→데이터: 장중 지수 분봉 확보 여부.
- 쓰레드 맥락: 위 결과는 '강의·레퍼럴 지표의 주장 우위'에 대한 반증이 아니라 '무료 원본의 일봉 해석에서 재현되지 않음'이다. 판매자 주장(승률 등)은 확인 못 함 — 미확인.

VOC: 일봉 지수 2년이 병목. 합산 N 은 1번 라인과 합쳐 재계산 요청.
요청→검증: 이 문서 8 규칙(m=8)을 1번 라인 합산 전체 N 에 넣고 α 재계산 · 요청→데이터: 지수·종목 장중 분봉 확보 가능 여부

# CIO 판정 — 급락일 1차 신호 정의 (장중 터치 vs 종가)

> 요청 req-cio-4b1c8165 (hf→cio, 마감 11/5). 입력: HF 개입 `rounds/2026-11-05-hf-1155.md`, `screener/committee.py` `crash_flag`(120~143행)·`_exec_plan`, `views/registry.json` `crash_day_close`, `reports/studies/2026-11-04_crash_close_intraday.md`, 퀀트 `rounds/2026-11-05/quant_downday_b.md`. 투자 권유 아님. 코드·정의 변경 없음 — 제안 + 결재 필요.

## What / So What / Now What
- What: **종가 기준 정의가 근거로 방어된다. 현행 코드(min(종가, 장중 저가) ≤ −5%)는 등급 B 가 붙은 표본의 정의 밖을 같은 등급으로 부른다 — HF 이견이 맞다.** 다만 HF 의 '종가 통일'은 반만 맞다: 종가 정의에도 B 가 '매수 허가'를 뜻하지는 않는다(아래 층위 3).
- So What: 장중 −5% 터치 후 −3~−4% 마감은 등급 B 의 표본이 아니라 퀀트 H2 에서 F 인 −3% 구간 쪽이다. 같은 줄에 'B'를 달면 거짓 정밀도.
- Now What: 아래 제안 1건을 PB 결재 요청(정의 변경이 아니라 '등록 정의와 코드의 불일치 정정'). 결재 전까지 코드는 그대로, 오늘 15:05 판독은 종가 기준으로만 읽는다(HF 북 이미 동일).

## 층위 분리
1. **등록 정의 vs 코드 (사실, 재량 0).** registry `crash_day_close` read.states = "1일 ≤ −5% & 20일 고점 대비 ≤ −10%", 입력 `KOSPI.chg1`(일수익률 = 종가 기준). `crash_flag` 는 ① 장중 저가 수익률도 min 에 넣고 ② dd20 ≤ −10% 조건을 보지 않는다. 즉 코드는 등록 정의와 두 군데 다르다. 표본 원문(playbook_signals 55건, replication n=27)의 종가 기준 여부는 registry 문구로만 확인했고 퀀트 대조 `[확인 필요: 퀀트, 11/6]`.
2. **등급이 말하는 것.** B = '진입한다면 종가에, 기다리지 말 것'이라는 타이밍 가중(registry note: "매수 허가 게이트가 아님", 지수보다 낫다는 뜻도 아님 — lab CRASH_REBOUND_LARGE F). 장중 터치를 같은 라벨에 넣으면 표본에 없는 사건에 B 를 빌려 쓰는 것.
3. **방어되는 근거의 상한.** 11/4 퀀트: −3~−5% 종가 매수는 비용 0.05% 뒤 4개 보유기간 전부 F(비중첩 39건, Bonferroni α 0.0125 미통과, 검출력 부족 — '효과 없다는 증거가 아니라 있어도 못 잡는 표본'). 장중 5분류는 통과 0건(C 2·F 8). 11/5 퀀트 H2: −3% 9셀 F, −5% 독립 5건 검증전. → 종가 정의로 통일해도 신호의 힘은 'B(타이밍 가중)'+'효과 입증 못 함'이 함께 가는 값이다. 종가 기준이 근거 있는 정의일 뿐 '유리한 정의'가 아니다.
4. **집행 시각.** `_exec_plan` 집행은 15:20 동시호가 — 종가로 보는 시점. 장중 터치를 1차로 부르면 정보는 오전에 켜지고 집행은 오후에 하는데, 그 사이 회복이 표본 밖 경로다(오늘 저가 −5.2% → 현재 −3.3% 가 바로 그 경우).

## 판정 (3안 중)
| 안 | 판정 | 이유 |
|---|---|---|
| 현행 유지(min 종가·저가) | 기각 | 등록 정의와 불일치, B 를 표본 밖에 적용 |
| 종가 통일만 | 부분 채택 | 정의 일치는 맞음. 단 장중 정보 소거는 과함 — 관측 가치는 있음(전약후강 N1 −0.41%p 는 C 방향만, 위험 확대 근거 금지) |
| **양쪽 병기 — 1차 신호 = 종가(등급 B 인용), 장중 터치 = 'near/관측'(등급 없음·"표본 밖")** | **채택 제안** | HF 제안과 같은 방향. 신호표 한 줄에 라벨 둘, 집행 `ok` 는 종가만 |

- 근거 등급: 종가 정의 B(타이밍 가중, 매수 허가 아님) · 장중 터치 검증전(표본 없음) · 장중 5분류 C/F.
- ΔS(구속 스트레스 증분): 0. 표시·판독 정의 정정이며 수량·한도 변경 없음. 손실 영향: 오늘 같은 날 장중 터치만으로 '분할 1차 집행 (B)' 문구가 뜨는 것을 막는다 — 회복 날 과대 진입 문구 방지(위험 감소 쪽).
- 반대 근거 1개: 종가만 쓰면 장중 −5% 후 종가 −5% 직전(예 −4.8%)에서 신호가 꺼져 반등 초입을 놓칠 수 있다(경계 다이얼; kb:cio#15 — 문턱 0.2%p 차이는 거짓 정밀도이므로 near 표시로 흡수, 문턱은 건드리지 않음).
- 뒤집힘 조건: 퀀트가 장중 터치(종가 −5% 미달) 사건 n≥8 로 사전등록 검정해 종가 정의와 구분되는 B 이상이 나오면 재상정. dd20 조건 코드 반영 여부(제안 2)는 퀀트 표본 대조 결과가 등록 정의와 다르면 철회.

## 사후 최적화 금지 (명시)
- 오늘 장중 저가 −5.2%·현재 −3.3% 라는 **결과를 본 뒤** 문턱·정의를 오늘 판정에 맞춰 바꾸는 것은 금지. 이 판정의 근거는 '등록 정의(10/16, 결과 전)와 코드의 불일치'이지 오늘 숫자가 아니다. 그래서 정정은 **결재 후 다음 거래일(11/6)부터 전향 적용**, 오늘 15:05 판독에는 소급 없음(종가 기준으로만 읽되 코드 출력은 그대로 둔다). 이후 문턱 −5%·−4%·dd20 −10% 의 변경은 새 사전등록 + 월간 구조 리뷰(kb:cio#16) 없이 금지.

# 이익 잠금 백테스트 — 반도체 비중 상한 초과분을 반등일에 덜기 (quant, 11/1 결재 안건 B 입력)

> 공개 저장소 — 비율만. 개인 금액·보유 수량·종목별 실보유 없음. 포트 규모는 '시작일 하이닉스 1주 가격의 N배'라는 비율 파라미터로만 표기.
> 코드: `scripts/study_profit_lock.py` · 원자료: `reports/studies/profit_lock.json`

## 0. 사전 등록 (결과 계산 전 커밋 — 이 절은 결과를 본 뒤 바꾸지 않음)

- **질문**: 반도체 비중 상한(고정 25%, 민감도 26% = 구속 스트레스 함의 상한 ≈25~26% 구간 양끝) 초과분을 반등일에 덜어내는 규칙(R)이 규칙 없음(BH) 대비 2023~2026 반도체 상승장·2026-06~07 급락에서 누적 수익·최대 낙폭·회복 기간을 어떻게 바꾸나.
- **데이터(저장본만, 네트워크 없음)**: 반도체 = 삼성전자·SK하이닉스 **주식 보유**(시작일 가치 50/50, 이후 둘 사이 리밸런싱 없음 — 온주 버전과 같은 구조). 일봉 `screener.prices.load_kr`(data/hist + data/kr_prices.parquet ~10-20) + `reports/detail/KR/{005930,000660}.json` c1y(10-21~10-27). 나머지 = 코스피200 가격지수(`data/deriv/daily.csv` k200_close). 배당 제외(가격수익).
- **기간**: 2023-01-02 종가 시작 ~ 2026-10-27 종가. 급락 구간 = FRM 공식 구간 2026-06-22→07-30(`rounds/2026-10-26/event_posrisk.md` 머리 정정문). 최근 구간 = 2026-07-30→10-27(서술용).
- **시작 상태**: 반도체 25% / 나머지 75%(상한과 같게). 민감도: 시작일을 2023-01~2025-12 매월 첫 거래일로 바꾼 36개 경로(각각 2026-10-27까지).
- **규칙**
  - BH: 리밸런싱 없음.
  - R25 / R26: 매일 종가 반도체 비중 > 상한이면 '덜기 대기'. 대기 중 **반등일**(코스피 종가 ≥ 전일 +0.5%) 종가에 상한까지 매도. 대금은 코스피200으로(semis_cap 관행). 되사기 없음.
  - R25W: 같은 규칙, 점검은 주 마지막 거래일 종가만(semis_cap BAND 와 같은 주기).
  - CAP25M(대조): 달 마지막 거래일 종가에 25% 초과분 매도(반등일 대기 없음).
  - 민감도: 대금을 현금(이자 0)으로 둔 R25_CASH.
  - 온주 버전 R25_INT: 포트 규모 N = 시작 순자산 ÷ 시작일 하이닉스 1주 가격 = 50 / 200 / 1000. 매도 수량 = 종목별 floor(초과분 × 종목 가치 비중 ÷ 주가), 0주면 미체결(대기 유지). 나머지(코스피200 ETF)는 소수 허용[가정: ETF 1주 가격이 포트의 ≪1%].
- **비용**: 주식 매도 편도 0.25%[가정: 거래세 0.15% + 수수료·슬리피지 0.10%], 코스피200 매수 0.05%. 체결가 = 반등일 종가(14:30 판정 근사, semis_cap·rule_audit T4 와 같은 한계).
- **지표**: 누적 수익 · CAGR · MDD · 최장 수중 기간(직전 고점 회복까지 거래일, 기말 미회복이면 '진행 중') · 급락 구간 손실(06-22→07-30 순자산 변화) · 급락 저점 후 회복률 · 덜어낸 횟수 · 기말 반도체 비중 · Calmar = CAGR/|MDD|.
- **'규칙 유효' 판정 기준(R25 vs BH, 주 경로)**
  - P1 보호: 급락 구간 손실이 BH 보다 **≥2%p 작다**.
  - P2 낙폭: 전 기간 MDD 가 BH 보다 **≥3%p 작고**, 최장 수중 기간이 BH **이하**.
  - P3 효율: Calmar 가 BH × 0.9 이상(위험 대비 수익을 10% 넘게 잃지 않음).
  - P4 방식: R25 매도 횟수 ≤ CAP25M 이고 급락 구간 손실 차 |R25 − CAP25M| ≤ 0.5%p(반등일 대기가 보호를 잃지 않음).
  - 판정: P1·P2·P3 충족 = **유효**(위험 통제 장치로) · P1·P2 만 = **보호는 되나 비용 큼** · P1 미충족 = **무효**. P4 는 방식 보조 판정.
  - 강건성: 36개 시작 경로 중 R25 MDD < BH MDD 인 비율 ≥75% 이면 P2 '강건'.
  - 온주: N=200 이상에서 누적 수익·MDD·급락 손실이 소수 버전과 각각 ±0.5%p 안이면 '온주 제약 무해'.
- **등급 상한**: 단일 역사 경로(독립 급락 1회)라 검정 없음 → 결과 등급 상한 **C**(방향). 36개 시작 경로는 서로 겹친 같은 역사라 독립 표본 아님.
- **사전 예상**: 2023~2025 반도체가 코스피를 크게 이겨 R 은 누적 수익을 크게 포기, 대신 BH 비중이 기말 50%+로 불어 급락 손실은 R 이 훨씬 작을 것(P1 충족 예상). P3 은 경계, P4 는 semis_cap 처럼 매도 횟수 차이만 클 것.
- **주제 시도 N**: semis_cap 주제(반도체 한도) 기존 등록 m 7 + 재현 → 이번 +6 규칙 비교(서술형, 검정 없음).

## 1. 결과 (기준 2026-10-27 종가 · 출처 reports/studies/profit_lock.json · 계산 퀀트)

- **What**
  - 규칙 R25(25% 초과분 반등일 덜기): 급락 구간 손실 −43.9% vs BH −48.0%(+4.1%p), MDD −45.3% vs −50.0%(+4.7%p) (C)
  - 대가: 기말 순자산 BH 대비 −15.6%(4.22배 vs 4.99배), 덜기 71회(연 ≈19회), 반도체 비중 BH 59%→R25 25%로 급락 진입 (C)
  - 사전 판정 P1·P2·P3 충족 → **'유효(위험 통제 장치)'** · P4(방식) 미충족 — 매도 71회 > 월말 캡 23회, 보호는 같음(차 0.1%p)
- **So What**
  - 덜어낸 돈이 코스피200으로 가 같이 −41% 맞음 → 보호폭 4%p대에 그침. 현금으로 두면 급락 −37.9%·MDD −39.1%(+10.2%p/+10.9%p)
  - 이득 원천 = '반도체 비중을 25%로 묶은 것'이지 반등일 타이밍 아님(R25·R25W·CAP25M 급락 손실 차 ≤0.1%p)
  - 표본 = 반도체 바스켓 +986%·코스피200 +204%인 3.8년 1개 경로, 급락 1회 → 등급 상한 C, '수익 포기 > 보호' 비율은 표본 성질(kb:quant#18)
- **Now What**
  - CIO 헤지 운용안·PB 로드맵 인용 시: "상한 덜기는 보호 +4~5%p(대금 코스피200) / +10%p(대금 현금·저상관 코어), 대가 기말 순자산 −1~−16%(시작점별, 중앙 −6%)"로 인용 / CIO·PB / 11/1 결재 전
  - 운용 방식: 매일 점검 대신 **주말 점검(R25W, 42회)** 또는 월말 캡(23회)이 같은 보호에 매도 횟수 40~68% 적음 → 결재안은 주기 명시 권고
  - 뒤집힐 조건: 대금 행선지가 코스피200과 상관 ≥0.8인 자산이면 보호폭 <3%p로 P2 탈락 가능 — 결재안에 대금 행선지(현금·채권·코어) 명시 필요

### 해석상 유의 (반대 근거)
- 나머지 자산을 코스피200 하나로 둔 것은 보수적 가정: 실제 코어(다자산)는 급락 상관이 낮아 보호폭이 R25(+4%p)와 R25_CASH(+10%p) 사이일 것[가정: 코어 급락 손실 0~−41% 사이]. 비공개 구속 스트레스 엔진(실보유 구성)과의 대조는 미확인(pb-private risk/frm.json, FRM 경로).
- 구속 스트레스 함의 상한은 비공개 엔진 산출이라 동적 상한은 재현하지 않음 — 고정 25·26%로 구간 양끝만 확인, 두 값 차이 ≤0.5%p.
- 체결 = 반등일 종가(14:30 판정 근사), 세금·비용 가정 매도 0.25%, 배당 제외. 반도체 내부(삼성·하이닉스) 리밸런싱 없음 — 하이닉스 비중이 커질수록 결과가 하이닉스 단일 종목에 좌우.

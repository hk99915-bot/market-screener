## 퀀트
- ① 확신도 = 원천 동의 가중만 — **맞음.** `committee.py` 1264~1274(가중 합)·1290~1293(높음≥1.2, C 이상 동의 없으면 상한 중간). `plan.ev_r`·`verdict`·`conviction`은 `_v2_ideas_top` 안에서 읽지 않는다(plan은 1569~1571 `tradeplan.attach`가 나중에 붙임).
- ② 좁은 손절이 크기를 만듦 — **절반 맞음.** 1294~1296 `size = min(cm × (payoff/2) × 1% ÷ stop_pct, 15%)`. 그런데 POSCO `stop_pct`는 2.7%가 아니라 **5.3%**(종가 266,500 기준)이고, 1×0.01/0.0533 = 18.8% → 15% 상한. 즉 '높음'이면 손절폭 6.7% 미만은 전부 상한에 닿는다. 추가 결함: `_risk_box` 312행 목표 = 종가+2R이라 `payoff ≡ 2.0`(오늘 10건 전부 2.0) → `payoff/2`는 항상 1인 죽은 항.
- ③ 손절 규칙 이원화 — **틀림(규칙은 하나), 기준가 혼선은 맞음.** 손절가 252,286·손절폭 −5.3%는 모델 북과 tradeplan이 같다(같은 `_risk_box`). 2.7%는 v2 진입 하한 `entry_floor`(1312~1313, 259,393) 기준으로 잰 값 = (259,393−252,286)/259,393. 실제 손실폭은 체결가에 따라 2.7%(하한)~7.8%(상한 273,607)인데 사이즈는 종가 기준 5.3%로 계산. 카드에 기준가(종가)·만료(`valid.entry_days`=1)는 **미표시 — 맞음**(tab_committee.html 44~45행에 없음).
- 불일치 수(오늘 committee.json, items 3 + candidates 7 = 10건): **보정 E[R] ≤ 0(F, kr_base)이 10/10건**. 그중 확신도 높음·중간 = **5건**(POSCO홀딩스 높음 / 삼성물산·현대그린푸드·GS·DL이앤씨 중간), status '실행 후보'인데 verdict 보류·관찰 = **4건**(POSCO홀딩스 보류, 삼성물산·현대그린푸드·DL이앤씨 관찰). 반대 방향도 있다 — 컨빅션 A인 현대그린푸드·GS·아모레퍼시픽홀딩스·대웅이 모델 북에선 중간·낮음. 두 점수는 같은 것을 재지 않는다.

## FRM
- 현행 결함: ① 분모가 종가 기준 손절폭이라 상단 체결 시 실제 위험이 과소(POSCO 5.3% 가정 vs 최악 7.8%) ② 슬리피지(`stop.slip_r` −1.02R) 미반영 ③ E[R]·verdict 무관하게 크기가 나옴 ④ 1% 리스크 기준이 tradeplan(1단계 0.25% × 컨빅션 배수 × 필터 배수)과 4배 이상 다름.
- 수정안: `size = 0 if (verdict == 보류 or ev_r ≤ 0) else min(risk ÷ max(손절폭_최악 × |slip_r|, 5%), 15%)`. 손절폭_최악 = (entry_max − stop)/entry_max, 하한 5%(=하루 소음 1×ATR 미만 손절이 크기를 키우지 못하게), risk = tradeplan `size.risk_pct`와 같은 값(별도 1% 금지 — 크기 산식 한 곳).
- 숫자 예시(오늘): POSCO 현행 15.0% → E[R] 게이트 없이 분모만 고쳐도 12.6%(1%/7.97%), 게이트 적용 시 **0%**(tradeplan weight 0.00%와 일치). GS 현행 10.0% → 분모 수정 6.7% → tradeplan 0.89% → E[R]≤0이라 0%. 오늘 10건 모델 북 합계는 상한 15% 1건 포함 79%대인데 tradeplan 합계는 약 5.5% — '모델 북 %'를 그대로 읽으면 위험 과대.
- 손절 이원화는 없음(같은 손절가). 대신 화면에 '손절폭 = 진입 상한 기준 −7.8% / 종가 기준 −5.3%'처럼 기준을 명시해야 하고, 크기 계산도 진입 상한 기준으로 한다.

## 1. H1 — 60일 상위 5% 종목의 '출발 시점 특징'은 사전 선별력이 있나
**HF 예비 수치 처리(검증전).** 71종목 = 상위 5% → 모집단 약 1,420(식 71÷0.05), detail KR 1,474와 근접. 97%·65%는 결과로 표본을 고른 뒤 뒤를 본 값 = P(F|상위5%) · P(F). 투자에 필요한 값은 P(상위5%|F).
- 베이즈 환산: P(상위5%|F) = 0.97×0.05÷0.65 ≈ 0.0746 → lift ≈ 1.49, 비적중 ≈ 92.5% (HF 수치 그대로 가정, 검증전).
- 편향 세 가지: ① 결과 기준 선택(분모 없는 비율) ② 260봉 창(2025-09-30~) = 52주 고점 계산에 앞쪽 10봉만 여유 → 낙폭 정의 불안정 ③ detail 유니버스 = 현재 상장만(상폐 제외, 데이터 점검 확인) → 'F 보유율 65%' 자체가 편향 `[확인 필요: 65% 산출 기준일·고점 창 정의, HF, 2026-10-31]`.
- 오염 구간: HF가 본 최근 60일(t0 ≥ 2026-07-01)은 검정에서 제외(−40% 문턱이 이 구간을 보고 정해짐).

**질문.** t0에 관측 가능한 특징 F가 있는 종목의 't0→t0+60거래일 수익률 횡단면 상위 5%' 진입 확률이 기저율 5%보다 높은가.
- 귀무 H0: P(Y=1|F=1) ≤ 0.05 (lift ≤ 1). 대립: > 0.05. 단측.
- 표본: KR 보통주(ETF·ETN·스팩·우선주 제외), t0 기준 20일 평균 거래대금 ≥ 10억·가격 ≥ 1,000원(alpha_sources LIQ 동일)·이력 ≥ 260봉. 격자 = 20거래일마다 t0(2011-01 첫 거래일~2026-06-30), 약 190개 날짜.
- 결과 Y: 같은 t0 적격 종목 중 60일 수익률(종가→종가, 상폐 시 마지막 종가) 상위 5%면 1. 기저율은 정의상 5%.
- IS/OOS(날짜 분할): IS t0 2011-01~2019-12 · OOS 2020-01~2026-06. 하락 구간 = KOSPI 연간 하락 연도(2011·2018·2022 — 실행 시 kr_index_daily로 확인).

- 지표: lift = P(Y|F)÷0.05, 정밀도 P(Y|F), 재현율 P(F|Y)(HF 수치와 같은 축, 비교용), 날짜별 (P(Y|F)−0.05) 평균의 NW(지연 2) t.
- 보조(등급 외, 해석 필수): P(하위5%|F)도 같이 계산. 낙폭·변동성은 양쪽 꼬리를 같이 키울 수 있다 → lift_상위 ≤ lift_하위면 '변동성 표지(예측 아님)'.
- 보조: F 보유 종목 60일 평균·중앙 초과수익(비용 왕복 0.25% 차감) — 정밀도가 올라도 기대값이 음수면 실무 무의미(kb:quant#11).
- m = 7 · 단측 α 0.05 · Bonferroni α/m = 0.00714(z ≥ 2.45). 주제 `winner_ex_ante` 신설 N = 7 + 등록 전 탐색 1(HF 예비) = 8 → α(N) 0.00625(개정2 층화 포함 N 56 → α(N) 0.00089, §5). 겹침: H1-4는 kr_accum, H1-6은 alpha_source D1과 같은 변수.

- 검출력 `[가정: 날짜간 (P(Y|F)−0.05) 표준편차 3%p]`: 유효 날짜 ≈ 190÷3 ≈ 63 → SE ≈ 0.38%p → MDE ≈ (2.45+0.84)×0.38 ≈ 1.25%p(lift 1.25). HF 환산 lift 1.49는 검출 범위 안.

- **킬 조건**: ① H1-1 lift가 IS 또는 OOS에서 ≤ 1 → F, HF 예비 서술('97% vs 65%') 철회 요청 ② lift_상위 ≤ lift_하위 → '변동성 표지' 판정, 진입 근거 사용 금지 ③ 상폐 처리 확인 불가 → 전 가설 상한 B ④ 결과 확인 후 문턱(−40%) 조정 금지 — 조정은 새 id.

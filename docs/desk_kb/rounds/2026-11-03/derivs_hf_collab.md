## §2 R&R — HF × 파생 (경계)
| 누가 | 하는 일 | 안 하는 일 |
|---|---|---|
| **HF** | 아이디어·방향·진입/청산 결정(모의), 체크리스트 10칸, 손절·E[R] | 그릭스 수치 산출을 생략하고 파생 다리 add |
| **파생** | 파생 다리 설계(행사가·만기·계약 수·1R 정의) · 진입 전 사전 점검 5칸 · 북 그릭스 일일 1줄 · 이벤트 진폭(IV 1σ) 판정 · 롤/증거금 시뮬 | **방향 판단(롱/숏 의견) 안 함** — 크기·위치만. 진입 결정·거부 안 함(거부권은 FRM) |
| 매크로 | 레짐·지표 발표 함의 | 파생 다리 크기 |
| 채권 | 금리·듀레이션·환헤지 비용 | 지수 옵션 IV 판정 |
| 애널 | 종목 밸류·실적 | 옵션 내재 변동성 해석 |
| 자산배분 | 코어 비중·적립 | 모의 북 파생 다리 |
| FRM | 한도·스트레스 거부권, 파생 한도 초안 검토 | 다리 설계 |

충돌 시: 파생 '⚠/✖' 와 HF 판단이 다르면 HF 가 기록 후 진입 가능(⚠) / ✖ 는 FRM 판정까지 보류. 판정 문서 = 해당 회차 라운드 파일.

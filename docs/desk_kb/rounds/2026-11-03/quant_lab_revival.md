## 4. 화면 부흥 제안 (프론트 몫 — 이번엔 문서만, 보드 `lab-screen-revival` 11/20)

1. **파이프라인 칸반** 5열: 대기열(lab_queue) → 데이터 확보 → IS → OOS/HOLDOUT → 판정(A/B/C/F). 카드 = id·한 줄 가설·데스크 배지·방향 아이콘·horizon.
2. **데스크별 현황 열 + 필터**: 데스크 × (대기·등록·진행·판정 수) 작은 표, 클릭 시 칸반 필터. 방향(롱/숏/롱숏/옵션/지수)·horizon·실계좌 가능/모의 전용 필터.
3. **이번 주 가설**: 가장 최근 §0 커밋된 1~3개(사전등록 날짜·커밋이 결과보다 앞섬 체크 ✓).
4. **F 묘지**: 죽은 가설 한 줄 사인(lab.json reasons 첫 줄 — 예 "IS 평균 초과 ≤0", "IS 표본 17<30"). 같은 가족 반복 횟수(시도 N) 옆에 표시 — 재시도 억제용.
5. **감쇠곡선 미니 차트**: horizon=감쇠곡선 가설은 1~60일 평균 초과 막대 + IS 선택 지평 표시(OOS 회색 겹침).
6. **묻힌 데이터 연결**(유지보수 maint.md): trend_discovery 근접 n·ideas_attrib 출처별 적중(n<20 회색 '표본 부족')·crash_day 근접 배지 → 각각 대기열 카드 11·12·0 으로 링크.
7. 상단 고정 문구: "C = 방향만, 비중 확대 근거 아님 · 모의 전용 = 실계좌 금지 기간".

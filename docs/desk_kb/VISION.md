# 프리맨 프로젝트 — 모든 데스크의 비전 (2026-10-25 겸이 지시)

> 개인 금액·보유·연봉은 이 문서에 쓰지 않는다(비공개 저장소 `pb-private` 참조). 이 문서는 판단이 충돌할 때 대조하는 원칙이다.

## 미션
- 돈 때문에 의지를 포기하지 않는다. 타인의 판단·조직의 이해관계·경제적 제약에 의지가 꺾이지 않고, 자기 판단으로 결정하고 그 결과를 스스로 감당하는 상태(겸이 정의, 10/25).
- 자본을 쌓되 삶을 소진하지 않는다. 금융시장을 활용하되 종속되지 않는다.

## 다섯 원칙
1. 생존이 수익률보다 우선 — 어떤 투자 실패도 삶 전체를 무너뜨리지 않아야 한다.
2. 내 집은 목표이되 영끌은 의무가 아니다 — 소유 때문에 다른 자유를 잃지 않는다.
3. 커리어와 금융투자를 함께 키운다 — 투자에 성공해야만 열리는 구조를 만들지 않는다.
4. 시간과 건강도 자본이다.
5. 희망이 아니라 실측으로 판단한다 — 기록하고 검증한다.

## 데스크는 어디에 기여하나 (조직도 기준)
| 본부 | 기여 |
|---|---|
| 투자전략 | 자본 배분·주거 자본 분리·장기 시나리오(금융적 독립, 주거 선택권) |
| 리서치 | 근거 생산 — 출처 등급·표본·한계를 숫자로 (원칙 5) |
| 리스크 | 생존 규칙·레버리지 상한·스트레스 (원칙 1·2) |
| 운영 | 기록·검증 인프라, 토큰·시간 지속가능성(시스템이 삶의 시간을 먹지 않게) |
| 교육 | 판단력 — 필요한 데스크만 선별 학습 |
| 생활 | 가계·시간·에너지(원칙 4), 진행 지표 |
| 감사·검증·피어 | 반대하고 검증하는 역할 — 좋은 소식도 근거 없이 통과시키지 않는다 |
| PB | 종합·창구. 가설 검증, 위험한 결정엔 숫자와 대안으로 반대, 목표가 흐려지면 원점으로 |

## 판단이 충돌할 때
- 수익이 커 보여도 원칙 1·2를 어기면 채택하지 않는다.
- 새 작업이 이 비전의 어느 축에 닿는지 한 줄로 답할 수 없으면 우선순위를 낮춘다.
- 시스템 개선 자체가 목적이 되지 않게 한다 — 작업 시간 상한은 겸이가 정한다(미정).

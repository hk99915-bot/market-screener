# 트레이드 아이디어 일별 모의 추적

모의 추적: 제안일 다음 첫 거래일 시가가 원래 진입 구간 안일 때만 진입. 다음 시가가 구간 밖이면 미진입 만료. 대기 제안은 미진입. 종가가 손절선 미만이면 종가 손절. 목표는 고가 도달 시 목표가(시가 갭 상승은 시가). 같은 날 목표·종가 손절 동시 충족은 판정 보류. 20거래일 안 +1R 미도달 시 종가 시간 손절. 비용 0.05%, 실거래 아님.

- 매일 TOP3의 최초 조건을 고정하고 같은 날 갱신으로 바꾸지 않습니다. 대기 제안을 나중에 실행 후보로 소급 전환하지 않습니다.
- 기존 ideas_log/ideas_attrib 원천 성적과 별도입니다. 이전 로그에 실행 상태가 없으면 검증 보류이며 소급 매수하지 않습니다.
- 다음 거래일 시가 조건은 이 추적기를 위한 명시적 모의 규칙이며 실제 주문이 아닙니다. 장중 진입을 추정하지 않습니다.
- 원천 반대 전환은 관측 시점의 청산가 검증을 위해 보류하며 확정 승패에 넣지 않습니다. 원천 상태 미확인은 표에 표시합니다.
- 확정 종가만 사용(당일15:45 이후). 주말은 거래일 수에 포함하지 않으며 가격이 없으면 대기/검증 보류합니다.
- 기업행위는 screener.prices.load_kr의 조정 가격을 사용합니다. 이미 고정된 제안 가격과 조정 기준이 바뀐 경우 운영 검토가 필요합니다.
- committee 생성 시 자동 갱신하며 네트워크 수집이나 GPT 호출을 추가하지 않습니다. 최근60개는 화면, 전체는 JSON에 보존합니다.
- reports/idea_tracking.json 최신 상태와 reports/idea_tracking/YYYY-MM-DD.json 일별 스냅샷을 저장합니다. 동일 날짜는 마지막 관측으로 갱신되며 original 조건은 보존합니다.
- 통계: 종료 적중률=양수 손익 종료/가격 규칙 종료 건수. 평균손익=종료 건의 비용 후 수익률 평균. 미진입률=미진입(대기·만료)/진입 여부 확인 건수. 미확인·진입 대기는 분모에서 제외합니다.

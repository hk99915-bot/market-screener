# 사내톡 프로필 사진

- 파일 이름 = 데스크 키 + `.png` (예: `quant.png`, `dev.png`, `pb.png`, 겸이는 `owner.png`). 정사각형 512×512 권장, 500KB 이하.
- 사내톡 탭(apps-script/tab_msgr.html)이 `raw.githubusercontent.com/.../assets/avatars/<키>.png` 를 읽고, 없으면 이니셜 원으로 표시.
- 창작 캐릭터 — 실존 인물·연예인·실제 사진 금지(겸이 10/23 "GPT로 생성"). 키 목록: pb cio alloc macro bonds realestate quant analyst derivs data frm behavior pm ops dev scribe edu eval household life verify peer audit hf uxui maint
- 올리는 법(폰): GitHub 앱/웹 → 이 폴더 → Add file → Upload files.
